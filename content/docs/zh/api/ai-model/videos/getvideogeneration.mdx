查询视频生成任务的状态和结果。任务完成后，通过 `output.video_url` 获取生成的视频地址。

**接口地址**：`GET /v1/video/generations/{task_id}`

其中 `{task_id}` 为创建任务时返回的 `id` 字段。

## 任务状态

| status | 含义 |
| --- | --- |
| `queued` | 排队中 |
| `in_progress` | 生成中 |
| `completed` | 成功 |
| `failed` | 失败 |

## 请求示例

```bash
curl -X GET "__apiBaseUrl__/v1/video/generations/task_abc123" \
  -H "Authorization: Bearer <YOUR_API_KEY>"
```

## 成功返回示例

```json
{
  "id": "task_abc123",
  "object": "video.generation",
  "model": "Seedance 2.0/uP",
  "status": "completed",
  "progress": 100,
  "created_at": "2026-06-17T08:00:00Z",
  "completed_at": "2026-06-17T08:01:30Z",
  "output": {
    "video_url": "https://cdn.example.com/output/task_abc123.mp4"
  },
  "error": null
}
```

## 错误处理建议

| 场景 | 处理建议 |
| --- | --- |
| 图生视频未传 `images` | 在 `images` 中补充至少 1 张图片 URL |
| 视频生视频未传 `metadata.video_urls` | 在 `metadata.video_urls` 中补充至少 1 个视频 URL |
| 资源 URL 无法访问 | 确认公网可达、格式正确 |
| 鉴权失败 | 检查 API Key |
| 生成失败 | 简化 `prompt` 或减少参考素材数量 |
