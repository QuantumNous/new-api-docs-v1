---
title: image2 生图计费说明
---

> 适用模型：`image-2`、`gpt-image-2`
>
> 价格单位：下文的 `0.30`、`1.20` 等表示站内余额单位，不是人民币金额。
>
> 实际扣费以使用日志为准。

## 1. 模型名

`image-2` 和 `gpt-image-2` 使用同一套计费规则，填哪个模型名都不会导致价格不同。

---

## 2. 尺寸档位

本站按最终生成图片的真实尺寸计费，不只看请求里写了 `1k`、`2k`、`4k`。

| 档位 | 判断方式 |
| --- | --- |
| `1K` | 最长边不超过 `1024px` |
| `2K` | 最长边大于 `1024px`，且不超过 `2048px` |
| `4K` | 最长边大于 `2048px` |

特殊规则：`2560x1440` 和 `1440x2560` 按 `2K` 计费。

如果请求 `4K`，但上游实际只返回 `2K` 图片，会按实际返回的 `2K` 计费。

---

## 3. 普通 image2 和 image2官图区别

| 对比项 | 普通 image2 | `image2官图` |
| --- | --- | --- |
| 适合场景 | 日常生图、批量出图 | 官方效果、官方质量档位、更高一致性 |
| 上游能力 | 普通 image2 生图渠道 | 能力完全等于官方 image2 Key |
| 是否按 `quality` 计费 | 不看 `quality` | 会看 `quality` |
| 是否按 `n` 多张计费 | 会，按张数累加 | 会，按张数累加 |
| 价格口径 | 只按真实尺寸计费 | 按真实尺寸 + `quality` 计费 |
| 折扣说明 | 固定站内价格 | 约为官方定价的 `0.35` 倍 |

简单说：普通 image2 只看图片尺寸；`image2官图` 同时看图片尺寸和 `quality`。

---

## 4. 普通 image2 价格

普通 image2 不看 `quality`，只看真实尺寸。下表为单张图片价格，多张按张数累加。

| 真实尺寸档位 | 扣费 |
| --- | ---: |
| `1K` | `0.30` |
| `2K` | `0.50` |
| `4K` | `0.70` |

---

## 5. image2官图价格

`image2官图` 能力完全等于官方 image2 Key，会按真实尺寸和 `quality` 计费。下表为单张图片价格，多张按张数累加。

| 真实尺寸档位 | `low` | `medium` / `standard` | `high` | `auto` |
| --- | ---: | ---: | ---: | ---: |
| `1K` | `0.52` | `0.76` | `1.20` | `0.80` |
| `2K` | `0.70` | `1.12` | `2.40` | `1.20` |
| `4K` | `1.12` | `2.26` | `5.20` | `3.20` |

说明：

- 不传 `quality`，或传 `auto`，按 `auto` 档计费。
- `medium` 和 `standard` 按同一档计费。
- `n=2` 通常按 2 张累加，`n=3` 通常按 3 张累加。

---

## 6. 常用尺寸

建议优先使用下面这些尺寸，成功率和计费展示更稳定。

| 档位 | 尺寸 | 比例 |
| --- | ---: | --- |
| `1K` | `1024x1024` | `1:1` |
| `2K` | `1536x1024` | `3:2` |
| `2K` | `1024x1536` | `2:3` |
| `2K` | `2048x2048` | `1:1` |
| `2K` | `2048x1152` | `16:9` |
| `2K` | `2560x1440` | `16:9` |
| `2K` | `1440x2560` | `9:16` |
| `4K` | `3840x2160` | `16:9` |
| `4K` | `2160x3840` | `9:16` |

自定义尺寸请使用英文 `x`，例如 `2560x1440`。
