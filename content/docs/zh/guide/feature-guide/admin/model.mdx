- 仅 Admin 和 Root 可访问，从侧边栏「管理员」→「模型」进入。
- 维护本站的模型资料、名称匹配、模型广场展示、供应商和预填充分组，并提供定价入口、资料与价格同步和 io.net 模型部署。
- 本页只维护模型资料；渠道中的实际模型、分组和路由由<a href="/zh/docs/guide/feature-guide/admin/channel" target="_blank" rel="noopener noreferrer">渠道管理</a>维护。

<Callout type="info" title="提示">
- 页面有「模型」「供应商」「部署」三个标签，页面标题依次为「模型管理」「供应商管理」「部署」。
- 模型资料、供应商、预填充分组和模型部署，Admin 与 Root 都可以管理。
- 模型定价只有 Root 可以修改，见[Admin 与 Root 的差异](#admin-与-root-的差异)。
- 价格规则见<a href="/zh/docs/guide/feature-guide/system-settings/settings-billing" target="_blank" rel="noopener noreferrer">计费与支付配置</a>和<a href="/zh/docs/guide/feature-guide/admin/billing-expression" target="_blank" rel="noopener noreferrer">计费表达式</a>。
- 创建或导入模型资料不会创建可调用的渠道。
- 创建部署也不会新建或绑定渠道。
</Callout>

## 常用操作

本节按使用顺序介绍添加和编辑模型、设置价格、删除、补充缺失模型、同步资料与价格，以及管理预填充分组、供应商和部署。

### 添加与编辑模型

- 模型管理-创建模型

![模型管理-创建模型页面](/assets/guide/feature-guide/model-management-add-model-model-information.png)

**操作流程：**
1. 点击「模型」标签右上角「添加模型」打开「创建模型」抽屉；编辑时点击模型名称、「编辑」或「补充资料」，打开以模型名为标题的抽屉。
2. 在「模型资料」标签中填写字段。
3. 点击「保存资料」。

<Callout type="info" title="提示">
- 抽屉标题下方显示「管理资料、定价及渠道关联，各分区分别保存。」
- 抽屉有「模型资料」「定价」「渠道与分组」三个标签。新建时只能先填写「模型资料」，保存后「定价」「渠道与分组」才可用。
- 从「补充资料」或「缺失的模型 → 配置」进入时，模型名已带入，三个标签都可用。
- 保存失败时，原因显示在抽屉底部。
- 定价有未保存的修改时不能修改模型名称，需先保存或放弃定价修改。
- 关闭抽屉时，资料或定价有未保存的修改会提示「放弃未保存的修改？」。
</Callout>

**模型资料：**
- 模型管理-编辑模型-模型资料

![模型管理-编辑模型-模型资料页面](/assets/guide/feature-guide/model-management-edit-model-model-information.png)

**配置项说明：**

「模型资料」分「基本信息」「匹配规则」「端点」「状态与同步」四个区域，下表按标签中的顺序排列。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 所属区域 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- | --- |
| 模型名称 | 基本信息 | 模型的唯一标识。 | 必填，最长 128 个字符，不能与已有记录重名。<br/>修改名称不会重命名渠道中的模型，也不会迁移定价，已有价格仍归原名称。 | 空（补充资料时带入） |
| 说明信息 | 基本信息 | 模型说明。 | — | 空 |
| 图标 | 基本信息 | 模型图标。 | 最长 128 个字符。可选「继承供应商图标」或「自定义模型图标」；「生效图标」显示实际使用的图标。 | 继承供应商图标 |
| 供应商 | 基本信息 | 模型所属供应商。 | 必须是已存在的供应商。 | 未选择 |
| 标签 | 基本信息 | 模型的标签。 | 合计最长 255 个字符；按 Enter 或逗号添加。 | 空 |
| 名称规则 | 匹配规则 | 哪些模型名称使用这条资料。 | 四选一，见[名称匹配规则](#名称匹配规则)。列表「查看」和同步向导中称「匹配类型」。 | 完全匹配 |
| 端点配置 | 端点 | 向用户展示的端点类型和自定义路径。 | 保存时由后端校验格式，见[端点配置](#端点配置)。 | 空 |
| 广场展示 | 状态与同步 | 允许在模型广场展示。 | 还需有可用渠道并满足用户分组访问条件。不影响 API 访问权限。 | 开启 |
| 允许资料同步 | 状态与同步 | 允许「同步资料」在预览确认后覆盖所选字段。 | 关闭后同步向导显示「已禁止资料同步」，不会修改此模型。开启时也不会自动同步，需手动运行「同步资料」。 | 开启 |

</div>

### 定价

- 模型管理-编辑模型-定价

![模型管理-编辑模型-定价页面](/assets/guide/feature-guide/model-management-edit-model-pricing.png)

**设置价格操作流程：**
1. 点击模型行的「定价」，或在编辑抽屉中点击「定价」标签。
2. 名称规则不是完全匹配时，先在「选择模型」中选择一个匹配到的具体模型。
3. 在下方编辑器中设置价格，字段和计费方式见<a href="/zh/docs/guide/feature-guide/admin/billing-expression" target="_blank" rel="noopener noreferrer">计费表达式</a>。
4. 点击「保存模型价格」。

<Callout type="info" title="提示">
- 只有 Root 可以编辑；Admin 打开此标签只看到「模型定价由超级管理员管理。」
- 顶部显示当前生效的计费摘要。
- 编辑器与<a href="/zh/docs/guide/feature-guide/system-settings/settings-billing#模型价格" target="_blank" rel="noopener noreferrer">计费与支付配置 → 模型价格</a>相同，修改的是同一份配置。
- 打开抽屉后此模型的价格在其他地方被修改时，保存会失败，点击「重新加载定价」后再修改。
</Callout>

**恢复默认定价操作流程：**
1. 点击「恢复默认定价」，在确认框中点击「恢复默认」。

<Callout type="warn" title="注意">
「恢复默认定价」移除此模型的自定义价格并恢复内置默认值，没有默认价格的模型会变为未定价。
</Callout>

### 删除模型

**操作流程：**
1. 在行末的 ⋯ 菜单中点击「删除」，或勾选多个模型后点击「删除选定的模型」（一次 1–1000 个）。
2. 在确认框「删除模型？」中按需勾选两个选项，默认都不勾选。
3. 点击「删除」。

<Callout type="info" title="提示">
- 「缺元数据」行没有模型资料，不能删除。
- 两项都不勾选时，只删除模型资料；渠道中的模型名称、能力和价格都保留。
- 启用的渠道仍引用该名称时，它会重新出现在列表的「缺元数据」行和「缺失的模型」中。
- 删除后可以重新创建同名模型资料。
</Callout>

**选项说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 选项 | 说明 |
| --- | --- |
| 同时从所有渠道移除 | 从每个渠道的模型列表中删除该名称，并同步更新渠道能力。所选模型中有非完全匹配规则时不可用（显示「仅精确匹配可用」）。 |
| 同时移除定价 | 删除该模型名称的自定义价格，勾选后提示「内置定价可能恢复生效。」仅 Root 可勾选。 |

</div>

<Callout type="warn" title="注意">
「同时从所有渠道移除」会直接修改渠道的模型列表，删除后该模型不能再通过这些渠道调用；需要恢复时，要在渠道中重新添加模型名称。
</Callout>

### 补充缺失的模型

- 模型管理-缺失的模型

![模型管理-缺失的模型页面](/assets/guide/feature-guide/model-management-missing-models.png)

「缺失的模型」列出已启用渠道正在使用、但没有**精确同名**模型资料的模型名称；被前缀、包含或后缀规则覆盖的名称仍会列出。

**操作流程：**
1. 在「模型」标签右上角点击 ⋯ →「缺失的模型」。
2. 按名称搜索，找到要补充的模型。
3. 点击行内「配置」，在带有该模型名的创建抽屉中填写并保存；或点击底部「同步缺失资料」，打开[同步资料](#同步资料)向导。

<Callout type="info" title="提示">
- 列表每页 20 条。
- 「缺失的模型」只统计已启用渠道。
- 模型列表中的「缺元数据」行还包括已禁用渠道中的名称，两处数量可能不同。
</Callout>

### 同步资料

点击「同步资料」打开「同步模型资料」向导，从官方元数据目录导入模型资料，必要时新建供应商。向导分 4 步，每次同步都要经过预览和确认，不会自动同步。

<Callout type="info" title="提示">
- 同步只修改模型资料：不会添加渠道、开放模型访问或配置价格，也不会修改模型名称和「允许资料同步」开关。
- 默认数据源为 `https://basellm.github.io/llm-metadata`，部署方可用环境变量 `SYNC_UPSTREAM_BASE` 替换；页面上没有对应设置。
- 服务器需要能访问数据源；向导第 1 步显示实际的模型来源和供应商来源。
- 执行中不能关闭向导。
</Callout>

**选择模型：**
- 模型管理-同步模型资料-选择模型

![模型管理-同步模型资料-选择模型页面](/assets/guide/feature-guide/model-management-sync-information-select-model.png)

**选择模型操作流程：**
1. 选择「资料语言」（中文、英文或日语），点击「加载资料预览」。切换语言会清空已加载的预览和选择。
2. 选择「同步范围」：「本站使用的模型」（默认，即已有资料的模型和缺失的模型）或「上游模型列表」（官方目录中的全部模型）。
3. 按需搜索或勾选「仅看可同步」，勾选模型，或点击「全选可同步项」（跨页）；点击「预览所选变更」。

各模型的「计划操作」见[同步计划操作](#同步计划操作)。

**预览字段：**
- 模型管理-同步模型资料-预览字段

![模型管理-同步模型资料-预览字段页面](/assets/guide/feature-guide/model-management-sync-information-preview-fields.png)

每个已选模型列出「应用」「字段」「当前值」「更改为」。

- 新增资料：导入全部 7 个字段，无需勾选，各字段的影响见[资料同步的覆盖规则](#资料同步的覆盖规则)。
- 资料变更：只列出与官方不同的字段，默认都不勾选；勾选的字段会被「更改为」中的内容替换，未勾选的保持不变。「全选变更字段」「取消全选」作用于所有已选的「资料变更」模型。
- 没有新增模型、也没有勾选任何字段时，「检查并确认」不可用。

**确认变更：**
- 模型管理-同步模型资料-确认变更

![模型管理-同步模型资料-确认变更页面](/assets/guide/feature-guide/model-management-sync-information-confirm-changes.png)

**确认操作流程：**
1. 检查将要创建或更新的模型、字段和新增供应商。
2. 点击「应用 N 个模型的变更」。

<Callout type="info" title="提示">
预览后官方目录或本站模型资料发生变化时，应用会失败并提示重新预览；点击「重新预览」回到第 1 步重新选择。
</Callout>

**同步结果：**
- 模型管理-同步模型资料-同步结果

![模型管理-同步模型资料-同步结果页面](/assets/guide/feature-guide/model-management-sync-information-sync-results.png)

显示「资料同步完成」、创建与更新的模型数量、新增的供应商，以及每个模型已应用的变更。未处理的模型不在结果中列出，原因见第 1 步的「计划操作」。

<Callout type="info" title="提示">
官方目录不是本站已配置的渠道清单。同步后的模型仍需在<a href="/zh/docs/guide/feature-guide/admin/channel" target="_blank" rel="noopener noreferrer">渠道管理</a>中配置渠道才能调用。
</Callout>

### 同步价格

- 模型管理-同步模型定价

![模型管理-同步模型定价页面](/assets/guide/feature-guide/model-management-sync-prices.png)

「同步价格」仅 Root 可见，与<a href="/zh/docs/guide/feature-guide/system-settings/settings-billing#上游价格同步" target="_blank" rel="noopener noreferrer">计费与支付配置 → 上游价格同步</a>是同一功能，字段和操作细节以该页为准。

**选择价格来源：**
- 模型管理-同步模型定价-选择价格来源

![模型管理-同步模型定价-选择价格来源页面](/assets/guide/feature-guide/model-management-sync-prices-select-price-source.png)

**选择来源操作流程：**
1. 点击「同步价格」，打开「同步模型定价」对话框。
2. 点击「选择价格来源」，勾选要对比的预设或渠道，点击「确认选择」。

<Callout type="info" title="提示">
确认选择后，列表按所选来源显示价格。
</Callout>

**预览价格变更：**
- 模型管理-同步模型定价-预览价格变更

![模型管理-同步模型定价-预览价格变更页面](/assets/guide/feature-guide/model-management-sync-prices-apply-sync.png)

**应用操作流程：**
1. 为模型选择来源后点击「应用同步」。
2. 在「预览价格变更」中核对价格来源、当前计费和最终保存价格。
3. 点击「确认更改」保存。

<Callout type="info" title="提示">
保存的价格与「模型价格」、编辑抽屉「定价」标签修改的是同一份配置。
</Callout>

### 管理预填充分组

- 模型管理-预填充分组管理

![模型管理-预填充分组管理页面](/assets/guide/feature-guide/model-management-prefilled-groups.png)

预填充分组保存一组可复用的值，**不是**用户分组或渠道分组，也不影响计费。

**操作流程：**
1. 在「模型」标签右上角点击 ⋯ →「预填充分组」，打开「预填充分组管理」。
2. 点击「新建分组」，或点击分组行的编辑。

## 规则与机制

本节说明 Admin 与 Root 的权限差异、名称匹配规则、端点配置的格式，以及同步资料时各字段的覆盖规则。

### Admin 与 Root 的差异

模型资料、供应商、预填充分组和模型部署，Admin 与 Root 都可以管理；模型定价只有 Root 可以修改。

**差异说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 位置 | Root | Admin |
| --- | --- | --- |
| 「同步价格」按钮 | 显示 | 不显示 |
| 列表「定价」列 | 显示当前价格摘要，点击打开「定价」标签 | 显示「超级管理员」 |
| 行内「定价」按钮 | 显示 | 不显示 |
| 编辑抽屉「定价」标签 | 可编辑并保存 | 只显示「模型定价由超级管理员管理。」 |
| 删除时「同时移除定价」 | 可勾选 | 不可勾选，下方显示「模型定价由超级管理员管理。」 |

</div>

### 名称匹配规则

名称规则决定哪些模型名称使用这条资料。

**规则说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 规则 | 匹配方式 |
| --- | --- |
| 完全匹配 | 只匹配完全相同的模型名称。 |
| 前缀匹配 | 匹配以该名称开头的模型。 |
| 包含匹配 | 匹配名称中包含该字符串的模型。 |
| 后缀匹配 | 匹配以该名称结尾的模型。 |

</div>

**匹配规则：**
- 同一个模型名称命中多条资料时，按完全匹配、前缀、后缀、包含的顺序取第一条。
- 匹配规则只用于模型资料（说明、图标、标签、供应商、端点、广场展示）；价格始终按具体模型名称配置，不会随规则传播。
- 使用非完全匹配规则时，渠道中的具体名称不会写入模型资料，「缺失的模型」中仍可能出现这些名称；删除时也不能「同时从所有渠道移除」。

### 端点配置

端点配置描述模型向用户展示的端点类型和自定义路径。

**填写方式：**
- 按行填写「端点类型」和「配置」。
- 切换「JSON 模式」直接填写 JSON。
- 「加载模板...」用所选模板（`openai`、`openai-response`、`anthropic`、`gemini`、`jina-rerank`、`image-generation`、`embeddings`）**替换**当前全部内容。

**校验规则：**
- 留空表示不设置；否则必须是 JSON 对象（或端点类型字符串数组）。
- 对象的键为端点类型，不能为空；值为以 `/` 开头的路径，或包含 `path`（以 `/` 开头）和可选 `method`（`GET`、`POST`、`PUT`、`PATCH`、`DELETE`、`HEAD`、`OPTIONS`）的对象。

<Callout type="info" title="提示">
端点配置不是渠道 Base URL，也不会创建上游渠道。「渠道与分组」标签中的「支持的端点」由已启用渠道推导，与此处的自定义端点是两回事。
</Callout>

### 资料同步的覆盖规则

同步资料只修改勾选的字段，各字段的影响如下。

**字段影响：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 字段 | 影响 |
| --- | --- |
| 说明信息、图标、标签 | 替换为官方内容。 |
| 供应商 | 本站没有同名供应商时，从官方供应商列表新建。 |
| 自定义端点 | 修改向用户展示的端点类型和自定义路径。 |
| 匹配类型 | 修改哪些模型名称继承此资料，不会继承价格。 |
| 广场展示 | 调整模型在模型广场中的展示，不影响渠道启用状态和已有调用权限。 |

</div>

**同步范围：**
- 关闭「允许资料同步」的模型不处理。
- 资料变更只列出与官方不同的字段，未勾选的保持不变。

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

## 保存与生效

本页各操作提交后立即保存，没有统一的保存按钮。处理该请求的节点立即生效，其他节点的同步方式因对象而异，按下列三组查看。

**模型资料与供应商：**

模型资料、供应商和预填充分组保存在数据库中，管理页列表保存后随即更新。编辑模型资料、隐藏或显示、同步资料和供应商变更后，模型广场在处理该请求的节点立即更新，其他节点约 3 秒内更新，最迟约 1 分钟。用户已打开的模型广场刷新页面后显示新内容。

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 操作 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 编辑模型资料 | 编辑抽屉「模型资料」标签中点击「保存资料」 | 模型广场按本组导语的时机显示新资料。 |
| 隐藏、显示（含批量） | 行 ⋯ 菜单中点击「从模型广场隐藏」或「在模型广场显示」，立即保存 | 只影响广场展示，不影响 API 调用。 |
| 同步资料 | 预览后点击「应用 N 个模型的变更」 | 所选模型一次写入，任一失败则全部不写入；关闭了「允许资料同步」的模型不处理。 |
| 供应商、供应商归属 | 添加、编辑供应商时点击「保存资料」；归属的设置、清除、合并、删除在预览后点击「应用更改」 | 模型广场的供应商筛选和图标随之更新；预览后数据有变化时应用失败，需重新预览。 |
| 删除模型 | 在确认框中点击「删除」 | 立即删除模型资料；渠道中的模型名称、能力和价格都保留，见[删除模型](#删除模型)。 |

</div>

**模型价格：**

模型价格保存为系统设置：处理该请求的节点立即生效，其他节点约 3 秒内随系统设置同步（最迟一个同步周期，默认 60 秒）。

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 操作 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 模型价格 | 「定价」标签中点击「保存模型价格」，或在同步价格中点击「确认更改」（仅 Root） | 下一次请求起按新价格计费，见<a href="/zh/docs/guide/feature-guide/admin/billing-expression#保存与生效" target="_blank" rel="noopener noreferrer">计费表达式</a>。 |
| 删除时勾选「同时移除定价」（仅 Root） | 随删除一并执行 | 内置定价可能恢复生效。 |

</div>

**渠道、预填充分组与部署：**

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 操作 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 删除时勾选「同时从所有渠道移除」 | 随删除一并执行 | 在同一次操作中修改渠道的模型列表和能力；各节点何时按新配置路由，见<a href="/zh/docs/guide/feature-guide/admin/channel#保存与生效" target="_blank" rel="noopener noreferrer">渠道管理</a>。 |
| 预填充分组 | 新建点击「新建」，编辑点击「保存更改」 | 之后打开渠道编辑抽屉时读取新内容；已保存的渠道不受影响。 |
| io.net 部署 | 创建、更新配置、延长、重命名和删除都直接发送到 io.net，不经过 New API 保存 | 以 io.net 返回的结果为准，不会新建或修改渠道。 |

</div>

## 注意事项

- **「同时从所有渠道移除」直接修改渠道**：删除后需在渠道中重新添加模型名称才能恢复，见[删除模型](#删除模型)。
- **部署是外部资源**：删除部署不可撤销；终止或修改前，先把指向它的渠道切换到其他可用渠道，见[查看与管理部署](#查看与管理部署)。
- **模型名称是唯一标识**：修改名称不会重命名渠道中的模型，也不会迁移价格；价格始终按具体模型名称配置，见[添加与编辑模型](#添加与编辑模型)。
- **同步资料会覆盖勾选的字段**：不希望被覆盖的模型，请关闭其「允许资料同步」，见[同步资料](#同步资料)。
- **「广场展示」不决定调用权限**：能否调用由渠道、分组和 API 密钥的限制决定，见[广场展示状态](#广场展示状态)。

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="模型没有出现在模型广场">
**说明**：先查看列表中该模型的「广场展示」状态，见[广场展示状态](#广场展示状态)。

**可能原因**：
- 状态为「已隐藏」：模型资料中的「广场展示」已关闭。
- 状态为「无法展示」：提供该模型的渠道未启用，或渠道模型列表未包含该名称。
- 状态为「正常展示」：用户所在分组无权访问该模型。

**处理方法**：
1. 按状态开启「广场展示」，或检查渠道与用户分组。
</Accordion>

<Accordion title="列表中出现「缺元数据」行">
**提示原文**：勾选这些行后，除「复制模型名称列表」外的批量操作按钮不可用，悬停显示「请先为所有选中模型补充元数据。」（英文 Add metadata to all selected models first.）

**可能原因**：渠道中使用了没有精确同名资料的模型名称。非完全匹配规则不能消除这些行。

**处理方法**：
1. 点击「补充资料」，或用「同步资料」导入。
2. 批量操作时取消勾选「缺元数据」行。
</Accordion>

<Accordion title="删除模型后它又出现在列表中">
**可能原因**：启用的渠道仍引用该名称。

**处理方法**：
1. 需要彻底移除时，删除时勾选「同时从所有渠道移除」（仅完全匹配规则可用）。
</Accordion>

<Accordion title="同步时模型不能勾选">
**可能原因**：
- 「计划操作」为「已禁止资料同步」：该模型的「允许资料同步」已关闭。
- 「计划操作」为「上游未找到」：官方目录中没有该名称。

**处理方法**：
1. 需要同步时，在模型资料中开启「允许资料同步」。
</Accordion>

<Accordion title="点击「加载资料预览」失败">
**提示原文**：「预览元信息失败」（英文 Failed to preview metadata）；服务端返回了原因时显示服务端英文原文。

**可能原因**：服务器无法访问数据源，或部署方通过 `SYNC_UPSTREAM_BASE` 修改了数据源地址。

**处理方法**：
1. 检查服务器能否访问数据源。
</Accordion>

<Accordion title="应用同步时提示重新预览">
**提示原文**：`Upstream metadata changed; preview again` 或 `metadata changed; preview again before applying`（仅英文）

**可能原因**：预览后官方目录或本站模型资料发生了变化。

**处理方法**：
1. 点击「重新预览」，回到第 1 步重新选择。
</Accordion>

<Accordion title="看不到「同步价格」按钮或「定价」标签">
**提示原文**：Admin 打开「定价」标签时显示「模型定价由超级管理员管理。」（英文 Model pricing is managed by a super administrator.）

**可能原因**：当前账户不是 Root。模型定价仅 Root 可以修改。

**处理方法**：
1. 请 Root 操作。
</Accordion>

<Accordion title="修改模型名称后价格消失">
**可能原因**：价格按模型名称保存，修改名称不会迁移价格。

**处理方法**：
1. 请 Root 为新名称配置价格，或改回原名。
</Accordion>

<Accordion title="定价列显示「按匹配模型配置」">
**可能原因**：名称规则不是完全匹配。

**处理方法**：
1. 在「定价」标签中先选择具体模型，再配置价格。
</Accordion>

<Accordion title="供应商无法删除">
**提示原文**：「供应商仍有关联的 … 条模型记录，请先转移或清除归属。」（英文 Vendors still have … linked model records. Transfer or clear their assignments first.）

**可能原因**：仍有模型关联该供应商。

**处理方法**：
1. 在「关联模型」中设置或清除这些模型的供应商。
2. 或改用「合并供应商」。
</Accordion>

<Accordion title="「部署」标签提示未启用或连接失败">
**提示原文**：「模型部署服务未启用」（英文 Model deployment service is disabled）或「连接失败」（英文 Connection failed）

**处理方法**：
1. 请 Root 在「系统设置」→「模型」→「模型部署」中检查开关和 API Key。
2. 点击「重试」。
</Accordion>

<Accordion title="部署被终止或容器异常">
**处理方法**：
1. 查看部署详情、容器状态和日志。
2. 检查是否仍有渠道指向该部署的地址；有则先切换到其他可用渠道。
</Accordion>

</Accordions>
