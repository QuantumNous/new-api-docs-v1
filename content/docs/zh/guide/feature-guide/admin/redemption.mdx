import { Callout } from 'fumadocs-ui/components/callout';

管理员从侧边栏进入「兑换码」，或访问 `/redemption-codes` 管理额度兑换码。该页面要求 Admin 或 Root；兑换码的创建、查询、编辑、启停和删除接口目前统一按管理员角色授权，没有单独的细粒度权限矩阵。

<Callout type="info">
本页说明控制台当前提供的兑换码管理能力。兑换码可以作为一次性的额度凭证分发给用户；额度和有效期由创建时填写，额度的显示单位由平台的计费设置决定。
</Callout>

## 权限与合规前置

1. Root 必须先在[系统设置] → 「计费与支付」 → 「支付网关」中确认当前版本的支付合规条款，管理员才能创建兑换码，用户端也才会启用兑换入口。[详见：计费与支付配置](/zh/docs/guide/feature-guide/system-settings/settings-billing)
2. 合规状态必须同时满足“已确认”和“条款版本为当前版本”；
3. 确认操作只能通过 Root 的控制台会话完成，API Access Token 不能代替该会话。
4. 合规未确认或条款版本与当前版本不匹配时，已有兑换码仍可由管理员查看和维护，但创建操作及用户兑换会被拒绝。

<Callout type="warn">
  - 侧边栏显示设置只影响菜单入口，不等同于撤销后端管理员权限。
  - 需要限制某位 Admin 使用兑换码功能时，应同时结合账户角色(「用户」 → 编辑管理员权限)和部署侧访问控制处理（「系统设置」 → 「站点与品牌」 → 「侧边栏模块」 → 「管理员区域」进行配置）。
</Callout>

## 兑换码管理页面

### 概览

![兑换码管理页面](/assets/guide/feature-guide/redemption-code-management.png)

### 页面顶部控件

| 控件 | 用途与边界 |
| --- | --- |
| 筛选框 | 按名称前缀或 ID 搜索；输入数字时还会匹配精确 ID。不是任意位置包含搜索。 |
| 状态 | 单选筛选未使用、已禁用、已使用或已过期。 |
| 查看/列设置 | 打开“切换列”菜单，控制表格列的显示和隐藏；不会改变查询结果。 |
| 删除无效 | 清理整个平台中已使用、已禁用和已过期的兑换码。 |
| 创建代码 | 打开创建抽屉，按一次请求批量生成 1–100 个兑换码。 |

### 参数说明

| 列 | 说明 |
| --- | --- |
| 选择 | 选择当前页的记录，用于批量复制。 |
| ID | 兑换码记录的唯一编号。 |
| 名称 | 创建时填写的批次或用途标识。 |
| 状态 | 未使用、已禁用、已使用或根据有效期计算出的已过期。 |
| 兑换码 | 默认显示脱敏值；旁边的复制按钮可复制完整值。 |
| 额度 | 按平台当前的额度显示配置格式化。 |
| 创建时间、过期时间 | 按浏览器本地时区显示；过期时间为空时显示“永不过期”。 |
| 兑换用户 | 已兑换时显示用户 ID，悬停可查看兑换时间。 |
| 操作 | 编辑、启用/禁用和单条删除；可用操作取决于状态。 |

## 兑换码状态说明

| 页面状态 | 含义 |
| --- | --- |
| 未使用 | 数据状态为启用，并且尚未过期，可以被用户兑换。 |
| 已禁用 | 管理员已暂停使用；重新启用后，只要仍在有效期内即可兑换。 |
| 已使用 | 已成功绑定一位用户并增加其额度，不能再次兑换。 |
| 已过期 | 数据状态仍为启用，但非零过期时间已经早于当前时间。 |

## 兑换码管理操作

### 查询、筛选

| 功能 | 说明 |
| --- | --- |
| 关键词搜索 | 关键词为数字时，匹配精确 ID 或名称前缀；其他关键词只匹配名称前缀，不是任意位置包含搜索。 |
| 状态筛选 | 可单独选择未使用、已禁用、已使用或已过期。 |

![兑换码查询筛选页面](/assets/guide/feature-guide/redemption-code-management-filter.png)

### 创建兑换码

1. 点击「创建代码」。
2. 填写名称、额度、过期时间和生成数量。
3. 核对额度显示单位及有效期，然后提交创建。
4. 创建成功后，在列表中复制单个或选中的兑换码，并通过安全渠道分发。

![创建兑换码页面](/assets/guide/feature-guide/redemption-code-management-create-redemption-code.png)

<Callout type="warn">
  完整兑换码等同于可转移的额度凭证。不要将其放入公开截图、群聊、工单、日志或代码仓库；批量创建后应记录发放对象和批次，未使用的明文副本也应限制访问。
</Callout>

### 批量复制兑换码

- 勾选当前页的多条记录后，可以批量复制，格式为每行：

```text
名称<Tab>完整兑换码
```

![批量复制兑换码页面](/assets/guide/feature-guide/redemption-code-management-bulk-copy.png)

<Callout type="info">
当前控制台没有兑换码导入、CSV/文件导出或按勾选项批量删除功能。需要保存发放清单时，应在受控环境中处理复制内容，并避免把完整代码长期存放在普通表格或共享文档中。
</Callout>

### 编辑

1. 在列表选中需要编辑的兑换码，点击操作列的铅笔图标。
2. 可对名称、额度和过期时间进行修改后，点击「保存更改」。

### 启用或禁用

1. 点击目标行操作列的「 ... 」菜单。
2. 点击「启用」 或 「禁用」。

![编辑、启用与禁用页面](/assets/guide/feature-guide/redemption-code-management-edit-redemption-code.png)

### 单条删除兑换码

1. 点击目标行操作列的「 ... 」菜单并选择「删除」。
2. 在确认框核对后确认删除。

### 删除无效兑换码

「删除无效」是全局清理操作，会删除所有符合下列任一条件的兑换码：

- 已使用；
- 已禁用；
- 状态为启用，但已经超过有效期。

![删除与清理无效兑换码页面](/assets/guide/feature-guide/redemption-code-management-delete-invalid.png)

<Callout type="warn">
 单条「删除」和「删除无效」都没有恢复入口。若只是暂时停止发放，优先使用“禁用”，不要用删除代替停用。
</Callout>

### 使用兑换码

可在[钱包]页面使用兑换码进行充值。[详见：钱包与订阅](/zh/docs/guide/feature-guide/user/wallet)

<Callout type="info">
1. 只有启用且未过期的兑换码可以使用。
2. 同一个兑换码在重复或并发请求中最多成功一次。
</Callout>

## 审计与故障排查

- 创建、编辑、启用或禁用、删除兑换码会产生审计记录，可在「审计日志」页面查询，不会写入「使用日志」。
- 兑换码日志不包含完整明文兑换码，但当前实现会把失败请求中提交的原始兑换码写入服务端错误日志，部署方应限制日志访问并按自身合规要求做好保护或脱敏。
