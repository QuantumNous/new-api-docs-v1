New API 是一个统一的AI模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持OpenAI、Claude等格式，可供个人或者企业内部管理与分发渠道使用，并提供游乐场、OpenAI 兼容接口、模型与渠道路由、用量日志、计费、订阅和系统运维等能力。

- 本指南按角色区分为用户指南、管理员指南两部分。

### 角色说明

平台根据账号角色控制菜单访问和操作权限，共分为三种角色：

- **普通用户** <br/>
注册后的默认角色，可使用平台开放的个人功能，例如游乐场、聊天预设、概览、数据看板、API 密钥、日志、钱包和个人资料等。<br/>顶部导航、侧边栏模块和签到等入口由 超级管理员（Root）配置控制。

- **管理员（Admin）** <br/>
在普通用户权限基础上，Admin 默认可访问渠道、模型、用户、兑换码和订阅等管理资源。<br/>渠道等资源还区分读取、操作、普通写入、敏感写入和查看密钥等动作，超级管理员（Root）可为管理员（Admin）账号设置权限覆盖以管理可用权限。

- **超级管理员（Root）** <br/>
Root 拥有全部权限，额外可访问**系统信息** `/system-info` 和**系统设置** `/system-settings/site`。<br/>系统设置分为站点与品牌、身份验证、计费与支付、模型与路由、安全与限制、控制台内容、运维七个设置域。
