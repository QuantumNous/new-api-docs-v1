New API 是一个统一的 AI 模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持 OpenAI、Claude 等格式，可供个人或者企业内部管理与分发渠道使用，并提供游乐场、OpenAI 兼容接口、模型与渠道路由、用量日志、计费、订阅和系统运维等能力。

- 本指南按角色和功能分区分为用户指南、管理员指南和系统设置指南三部分。

### 角色说明

平台根据账号角色控制菜单访问和操作权限，共分为三种角色：

- **普通用户** <br/>
注册后的默认角色，可使用平台开放的个人功能，例如游乐场、聊天、概览、数据看板、API 密钥、使用日志、审计日志、任务日志、钱包、个人资料和安全与访问等。<br/>顶部导航、侧边栏模块和签到等入口由超级管理员（Root）配置控制。[「站点与品牌配置」→](/zh/docs/guide/feature-guide/system-settings/settings-site)

- **管理员（Admin）** <br/>
在普通用户权限基础上，Admin 默认可访问渠道、模型、用户、兑换码和订阅等管理资源。<br/>渠道等资源还区分读取、操作、普通写入、敏感写入和查看密钥等动作，超级管理员（Root）可在用户管理中为管理员（Admin）账号设置「管理员权限」，覆盖默认权限。[「管理员权限」→](/zh/docs/guide/feature-guide/admin/user#管理员权限)

- **超级管理员（Root）** <br/>
Root 拥有全部权限，额外可访问**系统信息**、**任务插件**和**系统设置**，并可修改模型价格。<br/>系统设置分为站点与品牌、身份验证、计费与支付、模型、请求策略、安全与限制、控制台内容、运维八个设置域。[「系统设置概览」→](/zh/docs/guide/feature-guide/system-settings/system-setting)

## 管理员指南

适用于 Admin 和 Root，包含八个日常管理页面，其中计费表达式、系统信息和任务插件管理为 Root 专属。系统级选项另归入后面的系统设置指南。

### 计费表达式（Root 专属）

在定价编辑器中用计费表达式为模型定价，定义 Token 单价、阶梯条件、按次价格和请求规则，并用费用估算和请求模拟验证；了解预扣、结算和保存校验规则。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/billing-expression)

### 渠道管理

配置 AI 服务商、插件、网关和自定义渠道，维护凭证、模型、分组、路由映射和优先级，使用多 Key 和参数覆盖，并执行测试、余额查询、上游模型更新和批量操作。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/channel)

### 模型管理

维护模型资料、名称匹配、模型广场展示、供应商和预填充分组，并从上游同步模型资料；Root 还可修改模型定价并同步价格。部署服务已配置时，也可管理 io.net 模型部署。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/model)

### 用户管理

查看和维护用户账户、状态、角色、分组、额度、登录绑定、订阅、Passkey 与 2FA；Root 可为 Admin 账号设置「管理员权限」。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/user)

### 兑换码管理

创建、查看、编辑、启用、禁用和删除额度兑换码，支持批量复制、批量删除和删除无效兑换码；创建时可将兑换码保存为 TXT 或 Markdown 文件。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/redemption)

### 订阅管理

创建和维护订阅套餐，配置有效期、额度重置周期、分组升级与回退和支付方式，启用或禁用套餐，并批量重置订阅额度。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/subscription)

### 系统信息（Root 专属）

查看实例节点状态、资源指标和后台系统任务，并清理失联实例记录和历史系统任务。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-info)

### 任务插件管理（Root 专属）

管理异步任务插件：浏览任务插件市场、上传本地插件、查看插件详情与沙箱能力，并控制插件全局启用状态和任务插件渠道绑定。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/task-plugins)

分组是渠道、用户、API 密钥和计费配置共同使用的路由与计费维度，不再作为独立主导航项。调用和扣费记录请参阅[使用日志](/zh/docs/guide/feature-guide/user/log)，绘图记录和用户异步任务请参阅[任务日志](/zh/docs/guide/feature-guide/user/task-log)。
