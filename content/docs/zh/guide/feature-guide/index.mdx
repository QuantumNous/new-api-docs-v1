New API 是一个统一的AI模型接口管理与分发系统，支持将多种大模型转为统一格式调用，支持OpenAI、Claude等格式，可供个人或者企业内部管理与分发渠道使用，并提供游乐场、OpenAI 兼容接口、模型与渠道路由、用量日志、计费、订阅和系统运维等能力。

- 本指南按角色和功能分区分为用户指南、管理员指南和系统设置指南三部分。

### 角色说明

平台根据账号角色控制菜单访问和操作权限，共分为三种角色：

- **普通用户** <br/>
注册后的默认角色，可使用平台开放的个人功能，例如游乐场、聊天预设、概览、数据看板、API 密钥、日志、钱包和个人资料等。<br/>顶部导航、侧边栏模块和签到等入口由 超级管理员（Root）配置控制。[「站点与品牌配置」→](/zh/docs/guide/feature-guide/system-settings/settings-site)

- **管理员（Admin）** <br/>
在普通用户权限基础上，Admin 默认可访问渠道、模型、用户、兑换码和订阅等管理资源。<br/>渠道等资源还区分读取、操作、普通写入、敏感写入和查看密钥等动作，超级管理员（Root）可为管理员（Admin）账号设置权限覆盖以管理可用权限。[「站点与品牌配置」→](/zh/docs/guide/feature-guide/system-settings/settings-site)

- **超级管理员（Root）** <br/>
Root 拥有全部权限，额外可访问**系统信息** `/system-info`、**任务插件** `/task-plugins` 和**系统设置** `/system-settings/site`。<br/>系统设置分为站点与品牌、身份验证、计费与支付、模型与路由、安全与限制、控制台内容、运维七个设置域。

## 管理员指南

适用于 Admin 和 Root，包含七个日常管理页面。系统级选项另归入后面的系统设置指南；其中系统信息和任务插件为 Root 专属。

### 渠道管理

配置上游 AI 服务商渠道、认证信息、模型、分组和路由可靠性策略，并执行测试、余额刷新、模型同步和批量操作。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/channel)

### 模型管理

维护模型元信息、名称匹配、供应商和官方同步；在部署服务已由 Root 配置时，也可管理托管模型部署。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/model)

### 用户管理

查看和维护用户账户、状态、角色、分组、额度、登录绑定、安全凭证和订阅。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/user)

### 兑换码管理

创建、查看、编辑、启用、禁用和清理额度兑换码。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/redemption)

### 订阅管理

发布和维护订阅套餐，管理用户订阅权益、额度周期、分组升级与回退。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/subscription)

### 系统信息（Root 专属）

查看实例节点状态、资源指标和后台系统任务，并处理失联实例记录。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/system-info)

### 任务插件管理（Root 专属）

管理异步任务插件：浏览任务插件市场、上传本地插件、查看插件详情与沙箱能力，并控制插件全局启用状态和任务插件渠道绑定。

[查看详细文档 →](/zh/docs/guide/feature-guide/admin/task-plugins)

分组是渠道、用户、API 密钥和计费配置共同使用的路由与计费维度，不再作为独立主导航项。调用和扣费记录请参阅[使用日志](/zh/docs/guide/feature-guide/user/log)，绘图记录和用户异步任务请参阅[任务日志](/zh/docs/guide/feature-guide/user/task-log)。
