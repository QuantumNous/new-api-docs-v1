## 配置分区

本节按左侧导航的顺序介绍六个分区，各分区的保存按钮和生效时机见[保存与生效](#保存与生效)。

### 额度设置

- 计费与支付-额度设置

![计费与支付-额度设置页面](/assets/guide/feature-guide/system-settings-billing-and-payments-quota-settings.png)

**操作流程：**
1. 按配额点数换算要填写的额度，默认基准下 `500000` 配额点数为 `$1`。
2. 设置新用户配额、钱包免预扣门槛、输入预扣倍率和免费模型预消耗。
3. 如需发放邀请奖励，先在[支付合规确认](#支付合规确认)中确认合规条款。
4. 设置邀请者奖励和受邀者奖励。
5. 填写充值链接。
6. 点击页头「保存更改」。

<Callout type="warn" title="注意">
- 支付合规未确认时，表单上方显示红色告警「非零邀请奖励需要先在支付网关设置中确认合规条款。」。
- 此时保存大于 `0` 的邀请奖励会被拒绝，提示原文见[常见问题](#常见问题)。
</Callout>

**配置项说明：**

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 新用户配额 | 授予新用户的初始配额，不追补已有用户。 | 非负整数，单位为配额点数；说明文字中实时显示换算后的金额。 | `0` |
| 钱包免预扣门槛（美元） | 用户钱包余额和有限额 API 令牌的余额都超过该金额时，跳过预扣，按实际用量结算；设为 `0` 则始终预扣。订阅和异步任务始终预扣。 | 不小于 `0` 的数，可为小数；小于 `0` 时提示「必须大于或等于 0」。 | `10` |
| 输入预扣倍率 | 按预计输入费用乘以该倍率预扣，不预估输出 Token；最终按实际用量结算。按次计费和任务计费不受影响。 | 大于 `0` 的数，可为小数；否则提示「必须大于 0」。 | `1` |
| 邀请者奖励 | 符合条件的邀请注册后，授予邀请人的配额。奖励先计入邀请人的邀请额度，邀请人在钱包中点击「转移到余额」后才进入余额。 | 非负整数，单位为配额点数；大于 `0` 时需先确认支付合规。 | `0` |
| 受邀者奖励 | 授予被邀请人的配额。 | 非负整数，单位为配额点数；大于 `0` 时需先确认支付合规。 | `0` |
| 免费模型预消耗 | 启用后，零成本模型也会在最终结算前预先消耗配额。 | 开关。 | 开启 |
| 充值链接 | 供用户购买配额的外部链接，不会自动接入本站的支付回调。 | 选填，填写完整 URL，如 `https://example.com/topup`。 | 空 |

</div>

### 货币与展示

- 计费与支付-货币与展示

![计费与支付-货币与展示页面](/assets/guide/feature-guide/system-settings-billing-and-payments-currency-and-display.png)

**操作流程：**
1. 在「显示模式」中选择「USD」「元」或「自定义货币」。
2. 选择「自定义货币」时，填写「自定义货币符号」和「每 USD 单位数」。
3. 填写「美元汇率」，按需开启或关闭「显示 Token 统计信息」。
4. 点击页头「保存更改」。

<Callout type="info" title="提示">
- 内部 `500000` 配额点数在默认基准下为 `$1`。
- 页头「重置」将表单恢复为已保存的值，提示「表单已重置为保存的值」；没有修改时不可用。
</Callout>

**配置项说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 显示模式 | 向用户展示配额值的方式。 | 可选「USD」「元」「自定义货币」。 | `USD` |
| 美元汇率 | 美元与支付网关货币之间的实际汇率。 | 不小于 `0.0001`，否则提示「汇率必须大于 0」。<br/>显示模式为「元」时，名称显示为「人民币兑美元汇率」。 | `7.3` |
| 自定义货币符号 | 显示价格时使用的前缀。 | 仅「自定义货币」模式显示且必填，最多 8 个字符；为空时提示「自定义货币符号为必填项」。 | `¤` |
| 每 USD 单位数 | 美元到自定义货币的换算率，即 `1 USD = X` 个自定义货币单位。 | 仅「自定义货币」模式显示且必填，最小 `0.0001`；为空时提示「汇率为必填项」。 | `1` |
| 显示 Token 统计信息 | 决定 OpenAI 兼容的额度查询接口返回该令牌还是整个账户的额度和用量。 | 开关；界面说明为「在用户界面中显示令牌使用统计信息」。 | 开启 |

</div>

### 模型定价

页头标题右侧有「模型价格」「未设置价格模型」「工具价格」「上游价格同步」四个标签，默认打开「模型价格」。可配置模型计费模式、各类用量价格与计费表达式、工具调用价格，并补全未定价模型、同步上游价格。

**添加或编辑操作流程：**
1. 点击工具栏右侧的「添加模型」，或点击模型行的编辑图标。新建时填写准确模型名，编辑时模型名不可直接更改。

5. 点击「保存模型价格」。
6. 在「确认价格变更」中核对每个模型的「当前价格」和「保存后价格」，点击「确认保存」。

#### 价格待处理

由插件提供的任务模型无法计费时，模型价格列表会标出这些模型。侧边栏「系统设置」、左侧导航的「计费与支付」和「模型定价」也显示待处理的模型数。任务模型的计费规则见<a href="/zh/docs/guide/feature-guide/admin/billing-expression#任务模型" target="_blank" rel="noopener noreferrer">计费表达式</a>。

**统计范围：**
- 启用渠道实际提供的模型。
- 插件已不再提供、但仍保存着价格的模型。
- 插件被停用时保留其价格，这些模型不计为待处理。

**处理操作流程：**
1. 在「模型价格」标签顶部的「有 … 个模型的价格需要处理」中点击「检查价格」，或在工具栏「价格状态」中选择「价格待处理」。
2. 选择模型，在编辑面板顶部「需要修改的内容」中查看各插件的原因和处理方法。
3. 按「原因说明」表处理后，点击「保存模型价格」并确认。

<Callout type="info" title="提示">
- 「检查价格」只列出待处理的模型，并打开第一个模型的编辑面板；点击「显示全部模型」恢复。
- 待处理提示只在「模型价格」标签显示，「未设置价格模型」标签不显示。
- 模型名旁显示「价格待处理」，下方灰字为「插件名：原因」。
- 上传、安装、启用插件或切换插件版本后，如有模型因此无法计费，插件管理页也会提示「以下模型的价格需要处理：」。
</Callout>

**原因说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 原因 | 处理方法 |
| --- | --- |
| 还没设置价格 | 在下方选择对应插件，为该模型设置价格后保存。 |
| 价格用到了插件不再提供的用量 | 在下方选择对应插件，按当前计费字段重新配置价格后保存。 |
| 插件已不再提供这个模型 | 在下方选择对应插件，移除已保存的价格，再保存更改。 |

</div>

#### 未设置价格模型

- 计费与支付-模型定价-未设置价格模型

![计费与支付-模型定价-未设置价格模型页面](/assets/guide/feature-guide/system-settings-billing-and-payments-model-pricing-models-without-prices.png)

列出启用渠道中尚未设置价格的模型，按渠道可用模型及当前定价快照筛选。列表与「模型价格」相同，但没有「添加模型」，也不可删除。

**操作流程：**
1. 点击模型行的编辑图标，在右侧编辑面板中设置价格。
2. 批量设置时，先在右侧打开已核对的源模型，再勾选目标模型，点击底部浮条的「复制 … 定价」。
3. 核对每个目标模型的协议、缓存和媒体计费差异。

**补充说明：**
- **逐项写入**：「保存更改」「保存分组设置」「保存所有设置」「保存签到设置」只提交有修改的项，每项成功提示一次「设置更新成功」；没有修改时，「保存分组设置」不提示，其余提示「没有需要保存的更改」。
- **未保存的修改**：额度设置、货币与展示有未保存的修改时离开页面，会弹出「未保存的更改」确认，可选「离开」或「留下来」。
- **模型价格的确认与提示**：有价格改动时先在「确认价格变更」中确认；成功提示「模型定价已保存」，没有变更时提示「没有模型价格变更需要保存」。
- **价格被他人修改**：打开页面后，同一模型的价格已被他人修改时保存会被拒绝，需点击「重新加载定价」后重新修改。
- **切换易支付签名方式**：同一次保存中先写入私钥和公钥，再写入签名方式；签名方式为 RSA 而密钥无法解析时，保存被拒绝，提示「易支付商户私钥缺失或格式不正确」或「易支付平台公钥缺失或格式不正确」。

## 注意事项

- **「重置价格」清除全部自定义价格**：包括计费表达式，见[模型价格](#模型价格)。
- **估算不等于账单**：「Token 估算器」不含请求规则和分组倍率，实际扣费以使用日志为准。
- **到账以支付通知为准**：钱包到账由支付网关向站点发送的支付通知触发，支付完成后的返回页不作为到账依据；各网关的启用条件见[支付网关](#支付网关)。

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="保存成功但价格没变？">
**可能原因**：
- 未区分编辑草稿与最终保存。
- 模型名、当前模式、提供方覆盖或请求开始时的价格快照与预期不符。
</Accordion>

<Accordion title="关闭某项价格是否就是免费？">
**说明**：不一定。移除覆盖可能恢复默认；工具价格还可能匹配更具体的前缀。显式零值、未配置和删除是不同状态。
</Accordion>

<Accordion title="公开价格接口为什么访问失败？">
**说明**：该接口当前路径为 `/api/ratio_config`。

**可能原因**：「暴露倍率接口」开关未开启。
</Accordion>

<Accordion title="100 的优惠为什么没有用于 200？">
**说明**：金额优惠按原始金额精确匹配，不是最低阈值规则。
</Accordion>

<Accordion title="Stripe 报价与付款页不一致？">
**可能原因**：
- Stripe Price 的货币、单价或数量与预期不符。
- 未区分本地单价、充值倍率、优惠与 Stripe 优惠码。
</Accordion>

<Accordion title="Creem 产品额度填 1 为什么不是到账 1 美元？">
**说明**：该字段是内部配额点数；默认基准下，系统 1 USD 对应 500000 quota。
</Accordion>

<Accordion title="密钥框为空是否未配置？">
**说明**：不一定。密钥不回显的通用规则见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#敏感配置与审计记录" target="_blank" rel="noopener noreferrer">敏感配置与审计记录</a>。注意 Waffo 公钥清空并保存会移除原值，不可当成留空保留的私钥。
</Accordion>

<Accordion title="用户不能选择某个组？">
**可能原因**：
- 公共可用列表、特殊规则、账户自身组、倍率配置或令牌限制不允许选择该组。
- 使用 Auto 时未开放 `auto`。
</Accordion>

<Accordion title="Pancake 创建成功为何没有完成配置？">
**说明**：外部资源创建、当前选择和本地绑定保存是三个阶段。

**处理方法**：核对店铺和产品选择后，点击「保存所有设置」保存绑定。
</Accordion>

<Accordion title="签到每天都是最小值？">
**可能原因**：
- 最大值不大于最小值。
- 输入使用的不是配额点数。
</Accordion>

<Accordion title="保存邀请奖励时提示功能已禁用">
**提示原文**：「支付、兑换码、订阅计划和邀请返利功能已禁用。管理员需先确认合规声明后方可启用。」（英文 Payment, redemption, subscription, and invitation reward features are disabled. The administrator must confirm compliance terms before enabling them.）

**可能原因**：支付合规尚未确认，而「邀请者奖励」或「受邀者奖励」设为了大于 `0` 的值。

**处理方法**：
1. 由 Root 在「支付网关」中确认合规条款，见[支付合规确认](#支付合规确认)。
2. 回到「额度设置」重新保存。
</Accordion>

<Accordion title="保存模型价格时提示价格已被修改">
**提示原文**：提示中包含 `model pricing changed; reload before saving`（仅英文）。

**可能原因**：打开页面后，同一模型的价格已被他人或另一个窗口修改。

**处理方法**：
1. 点击「重新加载定价」。
2. 重新修改后保存。
</Accordion>

</Accordions>
