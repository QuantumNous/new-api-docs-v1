- 站点与品牌配置位于 `/system-settings/site`，仅 Root 可访问。
- 系统信息、公告、关于页、首页内容、用户协议和隐私政策等属于面向未登录访问者的公开内容，其接口无需登录即可读取。

## 站点与品牌配置简介

站点与品牌域下有四个独立分区：

| 分区 | 路径 | 职责 |
| --- | --- | --- |
| [系统信息](#系统信息) | `/system-settings/site/system-info`（默认进入） | 站点身份、公开内容与法律文档。 |
| [系统公告](#系统公告) | `/system-settings/site/notice` | 全局公告内容。 |
| [顶部导航](#顶部导航) | `/system-settings/site/header-navigation` | 顶部导航内置入口的显示与登录要求。 |
| [侧边栏模块](#侧边栏模块) | `/system-settings/site/sidebar-modules` | 侧边栏各区域与模块的显示控制。 |

<Callout type="warn">
  这些信息面向未登录访问者。不要写入 API Key、客户端密钥、内网地址、内部管理员资料或任何不应公开的信息。
</Callout>

## 配置分区

### 系统信息

- 站点与品牌-系统信息

![站点与品牌-系统信息页面](/assets/guide/feature-guide/system-settings-site-brand-system-information.png)

「系统信息」分区集中配置站点身份与公开内容。字段如下：

| 字段 | 必填/校验 | 说明与边界 |
| --- | --- | --- |
| 系统名称 | 必填 | 在整个应用程序中显示的名称。显示在站点标题、浏览器标签、认证页面和品牌组件中。 |
| 服务器地址 | 可选 | 服务器的公开URL，用于OAuth回调、Webhook和其他外部集成。 |
| 异步任务对外地址 | 可选 | 异步任务媒体的公开基础地址。支持独立媒体域名、端口或 Nginx 路径前缀；留空时回退到服务器地址。 |
| 徽标 URL | 可选；须为合法 URL | 您的徽标图片 URL |
| 文档链接 | 可选 | 文档站点地址，顶部导航「文档」入口和首页「文档」按钮跳转到此地址；默认 `https://docs.newapi.pro`。 |
| 页脚 | 可选 | 自定义页脚 HTML，显示在页面底部的页脚文本 |
| 关于 | 可选 | 可填写 HTTP(S) URL、HTML 或 Markdown，决定「关于」页面的内容。 |
| 首页内容 | 可选 | 可填写 HTTP(S) URL、HTML 或 Markdown。决定主页上显示的内容。 |
| 用户协议 | 可选 | 支持完整 URL、HTML 或 Markdown；留空会关闭用户协议入口和同意要求。 |
| 隐私政策 | 可选 | 支持完整 URL、HTML 或 Markdown；留空会关闭隐私政策入口和同意要求。 |

- 异步任务对外地址

「异步任务对外地址」用于构建异步任务产物的公开内容访问地址。当任务结果需要以公开 URL 被访问（例如视频/图像等内容下载）时，后端会以该地址为基址生成 `/v1/tasks/{id}/artifacts/...?access=...` 形式的长期有效能力 URL；未配置时回退使用「服务器地址」。

校验规则（前端与后端均会执行）：

- 可以为空；
- 必须是绝对 `http://` 或 `https://` 地址；
- 不含查询参数（`?`）、片段（`#`）或用户信息（`@`）；
- 不含控制字符、反斜杠或首尾空白；
- 提交时前端会自动移除结尾的 `/`。

<Callout type="warn">
  该地址必须能被最终用户从浏览器公开访问，填错或密钥不一致会导致任务产物 URL 无法访问或校验失败；这里只校验格式，不会探测可达性。
</Callout>

- 法律文档

用户协议或隐私政策字段非空后，登录、注册和页脚会提供相应入口；认证页面还会要求用户勾选同意已配置的文档。清空某一字段会停用对应入口和要求。

<Callout type="info">
该功能用于发布当前内容或外部链接，不是法律版本、签署记录或历史留存系统。如果需要可审计的协议版本和再次同意机制，应在 New API 之外建立相应流程。
</Callout>

### 系统公告

- 站点与品牌-系统公告

![站点与品牌-系统公告页面](/assets/guide/feature-guide/system-settings-site-brand-system-announcement.png)

「系统公告」分区保存系统公告内容，没有独立的启用开关。内容非空时，前端通过公开的 `/api/notice` 接口读取并显示在通知中心；清空内容即可停止发布。

<Callout type="info">
  本分区的系统公告与「控制台内容 › 公告」是两套配置：前者是一段全局通知内容，后者管理可启停的结构化公告列表，不应互相替代。
</Callout>

### 顶部导航

- 站点与品牌-顶部导航

![站点与品牌-顶部导航页面](/assets/guide/feature-guide/system-settings-site-brand-top-navigation.png)

顶部导航控制内置入口的显示，支持以下开关：

| 入口 | 可配置行为 |
| --- | --- |
| 主页、控制台、文档、关于 | 显示或隐藏。 |
| 模型广场、排行榜 | 各自有显示开关和「要求登录才能查看模型」/「要求登录才能查看排行榜」子开关（显示开关打开后才可切换）；子开关开启后，访客必须登录后才能访问，未登录用户点击后会跳转至登录。 |

「文档」入口跳转到「系统信息」中的「文档链接」。「重置为默认」只把表单恢复为全部显示、均不要求登录，点击「保存导航」后才写入。

### 侧边栏模块

- 站点与品牌-侧边栏模块

![站点与品牌-侧边栏模块页面](/assets/guide/feature-guide/system-settings-site-brand-sidebar-module.png)

侧边栏按区域和模块控制内置入口是否显示。当前分区结构与默认模块如下：

| 区域 | 当前内置模块 |
| --- | --- |
| 聊天区域 | 游乐场、聊天。 |
| 控制台区域 | 数据看板、令牌管理、使用日志、审计日志、绘图日志、任务日志。 |
| 个人中心 | 钱包、个人资料、安全与访问。 |
| 管理员区域 | 渠道、模型、兑换码、用户、系统设置、订阅管理。 |

<Callout type="info">
- 关闭整个区域会同时禁用该区域下的所有子模块；重新打开后，各模块仍按自身开关决定是否显示。
- 页面提供「重置为默认」，该按钮先把表单恢复为代码中的默认组合（全部启用），点击「保存侧边栏模块」后才写入服务端。
- 全局侧边栏配置决定模块是否可展示；拥有个人侧边栏设置权限的用户还可以在全局允许范围内进一步隐藏自己的「聊天区域/控制台区域/个人中心」模块（管理员区域的模块由全局配置决定，个人设置不覆盖）。
- **Root 不应用个人侧边栏覆盖**：个人侧边栏配置不会隐藏其任何模块。
</Callout>

## 保存与生效

保存方式见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#保存方式" target="_blank" rel="noopener noreferrer">系统设置概览</a>，生效与多实例同步规则见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#生效范围与多实例同步" target="_blank" rel="noopener noreferrer">生效范围与多实例同步</a>，浏览器何时显示新值见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#前端显示与缓存" target="_blank" rel="noopener noreferrer">前端显示与缓存</a>。未特别说明时，保存后处理该请求的节点立即使用新值，其他节点随系统设置同步（默认 60 秒）；各配置项读取新值的时机如下：

### 品牌、地址与页面内容

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 配置项 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 系统名称、徽标 URL、页脚、文档链接 | 页头「保存更改」，只提交有改动的字段；「重置」恢复表单 | 刷新页面后显示新值，执行保存的浏览器也需刷新。 |
| 服务器地址 | 页头「保存更改」，提交前去掉结尾的 `/` | 下一次使用该地址的请求起按新值；执行保存的浏览器自动更新。 |
| 异步任务对外地址 | 页头「保存更改」，提交前去掉结尾的 `/`；非空时服务端校验格式 | 之后查询任务时返回的产物地址按新地址生成，已发出的地址不变。 |
| 关于 | 页头「保存更改」 | 下一次打开关于页时读取。 |
| 首页内容 | 页头「保存更改」 | 下一次打开首页时，先显示浏览器缓存的内容，随后自动更新为最新内容；清空字段才会恢复内置首页。 |
| 用户协议、隐私政策 | 页头「保存更改」 | 协议正文在打开时读取，未刷新页面时缓存约 10 分钟；登录页、注册页和页脚中的入口刷新页面后更新。 |

</div>

### 公告、导航与侧边栏

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 系统公告 | 「保存通知」，整体写入 | 通知中心的系统公告在浏览器中缓存，刷新页面后读取新内容；内容有任何变化，都会再次显示为未读。 |
| 顶部导航 | 「保存导航」，整体写入；「重置为默认」只恢复表单 | 执行保存的浏览器自动更新，其他浏览器刷新页面后更新；「模型广场」「排行榜」的显示开关和登录要求从下一次请求起由服务端执行。 |
| 侧边栏模块 | 「保存侧边栏模块」，整体写入；「重置为默认」只恢复表单 | 执行保存的浏览器自动更新，其他浏览器刷新页面后更新；只改变侧边栏显示，不改变访问权限。 |

</div>

### 补充说明

- **没有改动**：系统信息没有改动时提示「没有需要保存的更改」。
- **未保存的修改**：有未保存的修改时离开「系统信息」分区，会弹出「未保存的更改」确认。

## 注意事项

- **页脚是裸 HTML**：不要加入不可信脚本、事件属性或第三方注入代码。
- **关于页/首页/法律正文的嵌入 HTML**：DOMPurify 会移除 `<script>` 等标签，脚本不会执行；样式与 iframe 行为也受到隔离与沙箱限制，不要把逻辑依赖在任意脚本上。
- **外部 URL 嵌入**：远端站点可能因 `X-Frame-Options`、CSP、混合内容或证书拒绝显示；这是远端策略，New API 无法绕过。
- **菜单隐藏不等于关闭能力**：「主页」「控制台」「文档」「关于」和侧边栏模块只改变入口显示，仍可通过地址访问；关闭「模型广场」后，服务端拒绝读取模型价格数据（Root 除外），关闭「排行榜」后拒绝读取排行榜数据；开启「要求登录才能查看模型」「要求登录才能查看排行榜」后，拒绝未登录的访问。
- **异步任务对外地址**：仅用于任务产物 URL，需公网可达且各节点共享 `CRYPTO_SECRET`。

<Accordion title="「异步任务对外地址」提示地址格式不正确">
**提示原文**：「请输入不含认证信息、查询参数或片段的 HTTP(S) 绝对 URL」（英文 Enter an absolute HTTP(S) URL without credentials, query parameters, or fragments）

**可能原因**：地址不以 `http://` 或 `https://` 开头，或包含查询参数（`?`）、片段（`#`）、用户信息（`@`）、控制字符、反斜杠或首尾空白。

**处理方法**：
1. 改为绝对地址，可带端口和路径前缀，如 `https://media.example.com/prefix`。
2. 不需要独立地址时留空，使用「服务器地址」。
</Accordion>

<Accordion title="保存系统名称、徽标或页脚后，页面仍显示旧内容">
**说明**：保存后，当前浏览器已加载的站点信息不会自动更新。

**处理方法**：
1. 刷新页面。
2. 多节点部署时，等待一个同步周期（默认 60 秒）后再刷新。
</Accordion>

<Accordion title="保存侧边栏模块后，个别账号的入口与预期不符">
**说明**：侧边栏由两层设置决定：本页的配置决定入口能否显示，用户可在个人资料中进一步隐藏。

**可能原因**：
- 该账号在个人资料的「左侧边栏个人设置」中隐藏了该模块。
- 模块所在的区域在本页被整体关闭。

**处理方法**：
1. 在本页检查区域开关和模块开关。
2. 请该用户在<a href="/zh/docs/guide/feature-guide/user/personal-setting#设置左侧边栏显示的页面" target="_blank" rel="noopener noreferrer">个人资料</a>中检查侧边栏设置。
</Accordion>

</Accordions>
