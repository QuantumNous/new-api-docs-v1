## 配置分区

本节按左侧导航的顺序介绍四个分区，各分区的保存按钮和生效时机见[保存与生效](#保存与生效)。

### 系统信息

- 站点与品牌-系统信息

![站点与品牌-系统信息页面](/assets/guide/feature-guide/system-settings-site-brand-system-information.png)

**操作流程：**
1. 填写系统名称、服务器地址和异步任务对外地址。
2. 按需填写徽标 URL、文档链接、页脚、关于和首页内容。
3. 需要用户同意协议时，填写用户协议和隐私政策。
4. 点击页头「保存更改」。

<Callout type="warn" title="注意">
- 这些内容面向未登录访问者，不要写入 API Key、客户端密钥、内网地址、内部管理员资料或任何不应公开的信息。
- 「异步任务对外地址」必须能被最终用户从浏览器公开访问；这里只检查格式，不探测可达性。
- 地址填错或各节点密钥不一致时，任务产物地址无法访问或校验失败，见[注意事项](#注意事项)。
</Callout>

**法律文档规则：**
- 用户协议或隐私政策非空后，登录、注册和页脚提供相应入口。
- 认证页面要求用户勾选同意已配置的文档。
- 清空某一字段会停用对应入口和同意要求。

<Callout type="info" title="提示">
该功能用于发布当前内容或外部链接，不是法律版本、签署记录或历史留存系统。如果需要可审计的协议版本和再次同意机制，应在 New API 之外建立相应流程。
</Callout>

**名称、徽标与地址配置项：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 系统名称 | 在整个应用程序中显示的名称，显示在站点标题、浏览器标签、认证页面和品牌组件中。 | 必填，为空时提示「系统名称为必填项」。 | `New API` |
| 服务器地址 | 服务器的公开 URL，用于 OAuth 回调、Webhook 和其他外部集成。 | 选填；提交前去掉结尾的 `/`。 | 空 |
| 异步任务对外地址 | 异步任务产物（如视频、图像）公开访问地址的基础地址，生成的地址带访问凭证。支持独立媒体域名、端口或 Nginx 路径前缀。 | 选填，留空时回退到服务器地址。<br/>须为 `http://` 或 `https://` 开头的绝对地址；不含查询参数（`?`）、片段（`#`）、用户信息（`@`）、控制字符、反斜杠或首尾空白；提交前去掉结尾的 `/`。<br/>提示原文：「请输入不含认证信息、查询参数或片段的 HTTP(S) 绝对 URL」。 | 空 |
| 徽标 URL | 站点徽标图片的地址。 | 选填；非空时须为合法 URL。界面说明为「您的徽标图片 URL（可选）」。 | 空 |
| 文档链接 | 顶部导航「文档」入口和首页「文档」按钮跳转的地址。 | 选填。 | `https://docs.newapi.pro` |

</div>

**页面内容与法律文档配置项：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 页脚 | 显示在页面底部的页脚文本。 | 选填，按 HTML 显示，见[注意事项](#注意事项)。 | 空 |

### 系统公告

- 站点与品牌-系统公告

![站点与品牌-系统公告页面](/assets/guide/feature-guide/system-settings-site-brand-system-announcement.png)

系统公告没有独立的启用开关，内容非空时显示在通知中心的「通知」标签。

**操作流程：**
1. 在「公告内容」中填写公告。
2. 点击页头「保存通知」。
3. 需要停止发布时，清空「公告内容」后保存。

<Callout type="info" title="提示">
  本分区的系统公告与「控制台内容 › 公告」是两套配置：前者是一段全局通知内容，后者管理可启停的结构化公告列表，不应互相替代。
</Callout>

### 顶部导航

- 站点与品牌-顶部导航

![站点与品牌-顶部导航页面](/assets/guide/feature-guide/system-settings-site-brand-top-navigation.png)

**操作流程：**
1. 打开或关闭各入口的显示开关。
2. 「模型广场」「排行榜」需要访客先登录时，打开其下的「要求登录才能查看模型」或「要求登录才能查看排行榜」。
3. 点击页头「保存导航」。

<Callout type="info" title="提示">
- 子开关在所属入口关闭时不可切换。
- 「文档」入口跳转到「系统信息」中的「文档链接」。
- 页头「重置为默认」只把表单恢复为全部显示、均不要求登录，点击「保存导航」后才写入。
</Callout>

**配置项说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 主页 | 带有系统概览的登陆页面。 | 开关。 | 开启 |
| 控制台 | 用户仪表板和配额控制。 | 开关。 | 开启 |
| 文档 | 文档或外部知识库。 | 开关。 | 开启 |
| 关于 | 描述平台的静态页面。 | 开关。 | 开启 |
| 模型广场 | 公开模型目录和价格页面。 | 开关；关闭后服务端拒绝读取模型价格数据（Root 除外）。 | 开启 |
| 要求登录才能查看模型 | 访客必须先进行身份验证才能访问定价目录。 | 开关；仅「模型广场」开启时可切换。未登录访问者点击后跳转登录。 | 关闭 |
| 排行榜 | 基于真实用量数据的公开排行榜页面。 | 开关；关闭后服务端拒绝读取排行榜数据。 | 开启 |
| 要求登录才能查看排行榜 | 访客必须先进行身份验证才能访问排行榜页面。 | 开关；仅「排行榜」开启时可切换。未登录访问者点击后跳转登录。 | 关闭 |

</div>

### 侧边栏模块

- 站点与品牌-侧边栏模块

![站点与品牌-侧边栏模块页面](/assets/guide/feature-guide/system-settings-site-brand-sidebar-module.png)

侧边栏按区域和模块控制内置入口是否显示。

**操作流程：**
1. 打开或关闭区域开关。
2. 在开启的区域中打开或关闭各模块。
3. 点击页头「保存侧边栏模块」。

<Callout type="info" title="提示">
- 关闭整个区域会同时禁用该区域下的所有模块开关；重新打开后，各模块仍按自身开关决定是否显示。
- 页头「重置为默认」把表单恢复为全部启用，点击「保存侧边栏模块」后才写入。
- 本页决定模块能否显示；有个人侧边栏设置权限的用户还可以在此范围内隐藏自己的「聊天区域」「控制台区域」「个人中心」模块，管理员区域的模块不受个人设置影响。
- Root 不应用个人侧边栏设置。
</Callout>

**模块说明：**

| 区域 | 区域说明 | 模块 |
| --- | --- | --- |
| 聊天区域 | Playground 实验和实时对话。 | 游乐场、聊天 |
| 控制台区域 | 仪表板、令牌和使用分析。 | 数据看板、令牌管理、使用日志、审计日志、绘制日志、任务日志 |
| 个人中心 | 钱包管理和个人偏好设置。 | 钱包、个人资料、安全与访问 |
| 管理员区域 | 全局配置和管理工具。 | 渠道、模型、兑换码、用户、系统设置、订阅管理 |

</div>

## 保存与生效

保存方式见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#保存方式" target="_blank" rel="noopener noreferrer">系统设置概览</a>，生效与多实例同步规则见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#生效范围与多实例同步" target="_blank" rel="noopener noreferrer">生效范围与多实例同步</a>，浏览器何时显示新值见<a href="/zh/docs/guide/feature-guide/system-settings/system-setting#前端显示与缓存" target="_blank" rel="noopener noreferrer">前端显示与缓存</a>。未特别说明时，保存后处理该请求的节点立即使用新值，其他节点约 3 秒内随系统设置同步（最迟一个同步周期，默认 60 秒）。同步周期由环境变量 `SYNC_FREQUENCY` 调整，单位为秒，默认 60 秒，修改后需重启 New API。各配置项读取新值的时机如下：

**品牌、地址与页面内容：**

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 配置项 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 系统名称、徽标 URL、页脚、文档链接 | 页头「保存更改」，只提交有改动的字段；「重置」恢复表单 | 刷新页面后显示新值，执行保存的浏览器也需刷新。 |
| 服务器地址 | 页头「保存更改」，提交前去掉结尾的 `/` | 下一次使用该地址的请求起按新值；执行保存的浏览器自动更新。 |
| 异步任务对外地址 | 页头「保存更改」，提交前去掉结尾的 `/`；非空时服务端校验格式 | 之后查询任务时返回的产物地址按新地址生成，已发出的地址不变。 |
| 关于 | 页头「保存更改」 | 下一次打开关于页时读取。 |
| 首页内容 | 页头「保存更改」 | 下一次打开首页时，先显示浏览器缓存的内容，随后自动更新为最新内容；清空字段才会恢复内置首页。 |
| 用户协议、隐私政策 | 页头「保存更改」 | 协议正文在打开时读取，未刷新页面时缓存约 10 分钟；登录页、注册页和页脚中的入口刷新页面后更新。 |

</div>

**公告、导航与侧边栏：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 配置项 | 保存方式 | 生效时机 |
| --- | --- | --- |
| 系统公告 | 「保存通知」，整体写入 | 通知中心的系统公告在浏览器中缓存，刷新页面后读取新内容；内容有任何变化，都会再次显示为未读。 |
| 顶部导航 | 「保存导航」，整体写入；「重置为默认」只恢复表单 | 执行保存的浏览器自动更新，其他浏览器刷新页面后更新；「模型广场」「排行榜」的显示开关和登录要求从下一次请求起由服务端执行。 |
| 侧边栏模块 | 「保存侧边栏模块」，整体写入；「重置为默认」只恢复表单 | 执行保存的浏览器自动更新，其他浏览器刷新页面后更新；只改变侧边栏显示，不改变访问权限。 |

</div>

**补充说明：**
- **逐项写入**：「系统信息」只提交有改动的字段，每项成功提示一次「设置更新成功」；没有改动时提示「没有需要保存的更改」。
- **整体写入**：「系统公告」「顶部导航」「侧边栏模块」各自整体写入；内容没有变化时不提交，也不提示。
- **未保存的修改**：「系统信息」有未保存的修改时离开分区，会弹出「未保存的更改」确认，可选「离开」或「留下来」。

## 注意事项

- **页脚是裸 HTML**：不要加入不可信脚本、事件属性或第三方注入代码。
- **关于页/首页/法律正文的嵌入 HTML**：DOMPurify 会移除 `<script>` 等标签，脚本不会执行；样式与 iframe 行为也受到隔离与沙箱限制，不要把逻辑依赖在任意脚本上。
- **外部 URL 嵌入**：远端站点可能因 `X-Frame-Options`、CSP、混合内容或证书拒绝显示；这是远端策略，New API 无法绕过。
- **菜单隐藏不等于关闭能力**：「主页」「控制台」「文档」「关于」和侧边栏模块只改变入口显示，仍可通过地址访问；关闭「模型广场」后，服务端拒绝读取模型价格数据（Root 除外），关闭「排行榜」后拒绝读取排行榜数据；开启「要求登录才能查看模型」「要求登录才能查看排行榜」后，拒绝未登录的访问。
- **异步任务对外地址**：仅用于任务产物地址，需公网可达；多实例部署时各节点需设置相同的 `CRYPTO_SECRET`。未设置时使用 `SESSION_SECRET`，两者都未设置时每次启动随机生成，重启后已发出的产物地址无法通过校验。

## 常见问题

<Accordion title="「异步任务对外地址」提示地址格式不正确">
**提示原文**：「请输入不含认证信息、查询参数或片段的 HTTP(S) 绝对 URL」（英文 Enter an absolute HTTP(S) URL without credentials, query parameters, or fragments）

**可能原因**：地址不以 `http://` 或 `https://` 开头，或包含查询参数（`?`）、片段（`#`）、用户信息（`@`）、控制字符、反斜杠或首尾空白。

**处理方法**：
1. 改为绝对地址，可带端口和路径前缀，如 `https://media.example.com/prefix`。
2. 不需要独立地址时留空，使用「服务器地址」。
</Accordion>

<Accordion title="保存系统名称、徽标或页脚后，页面仍显示旧内容">
**说明**：保存后，执行保存的浏览器已加载的站点信息不会自动更新。

**处理方法**：
1. 刷新页面。
2. 多实例部署时，等待几秒后再刷新；仍为旧值时，最迟等待一个同步周期（默认 60 秒）。
</Accordion>

<Accordion title="保存侧边栏模块后，个别账号的入口与预期不符">
**说明**：侧边栏由两层设置决定：本页的配置决定入口能否显示，用户可在个人资料中进一步隐藏。

**可能原因**：
- 该账号在个人资料的「左侧边栏个人设置」中隐藏了该模块。
- 模块所在的区域在本页被整体关闭。

**处理方法**：
1. 在本页检查区域开关和模块开关。
2. 请该用户在<a href="/zh/docs/guide/feature-guide/user/personal-setting#设置左侧边栏显示的页面" target="_blank" rel="noopener noreferrer">个人资料</a>中检查侧边栏设置。
</Accordion>

</Accordions>
