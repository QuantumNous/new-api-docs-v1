- 「系统设置」的地址为 `/system-settings`，仅 Root 可访问。
- 本页说明系统设置的各设置域通用的保存、生效、敏感配置和变更验证规则；具体字段说明见对应设置域的文档。

## 入口与权限

仅Root 可以从以下三处进入系统设置，都会打开「站点与品牌 › 系统信息」：

1. 侧边栏「管理员」分组末尾的「系统设置」。
2. 右上角头像菜单中的「系统设置」。
3. 顶栏「搜索」或快捷键 ⌘/Ctrl+K 打开的命令面板，其中列出的页面与侧边栏相同。

## 保存与生效

### 保存方式

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 保存方式 | 适用分区 | 表现 | 详见 |
| --- | --- | --- | --- |
| 逐项保存（默认） | 下列以外的所有分区 | 见表后说明。 | — |
| 整体保存 | 请求策略的三个分区（各自保存） | 每次提交的修改项先整体校验，再在一个事务中写入；任一项不合法，全部不写入。成功提示「保存成功」。没有版本冲突检测，后保存的覆盖先保存的。 | [请求策略配置](./settings-request-policies#保存与生效) |
| 批量保存并检测冲突 | 计费与支付 › 模型定价中的模型价格 | 多个模型的价格修改一次提交，在一个事务中写入；如果打开页面后价格已被他人修改，保存会被拒绝，需要重新加载后再修改。成功提示「模型定价已保存」。 | [计费与支付配置](./settings-billing) |
| 开关即时保存，列表单独保存 | 控制台内容 › 公告、API 地址、常见问答、Uptime Kuma | 「启用」开关切换后立即保存；列表中的新增、编辑、删除只修改页面数据，点击卡片内的「保存设置」后才写入。 | [控制台内容配置](./settings-content) |
| 按条目保存 | 身份验证 › 自定义 OAuth | 在列表和对话框中逐个新增、编辑、删除提供商，页头没有保存按钮。生效范围见[生效范围与多实例同步](#生效范围与多实例同步)。 | [身份验证配置](./settings-auth) |
| 保存前确认 | 身份验证 › 通行密钥认证中的域名设置 | 修改域名设置时，如果会使已有通行密钥失效，需要先确认才会写入。 | [身份验证配置](./settings-auth) |
| 无保存按钮 | 运维 › 系统维护 | 只显示当前版本、启动时间和更新检查。 | [运维配置](./settings-operations) |

</div>

<Callout type="info">
- 「设置更新成功」「保存成功」等提示只表示服务端已接受这次保存，不代表 OAuth、SMTP、支付网关、Webhook、Worker 等外部服务已经连通。
- 必须通过实际登录、发信、支付沙箱、回调或业务请求进行验证。
</Callout>

### 生效范围与多实例同步

1. 设置以键值形式保存在主数据库中。处理保存请求的节点写入数据库后立即更新内存中的值，不需要重启。
2. 其他节点每隔 `SYNC_FREQUENCY` 秒（默认 60 秒）从数据库重新载入全部设置，也包括请求策略、模型价格、通行密钥域名等使用专用保存方式写入的设置。
   - 这项同步与是否启用 Redis 无关，前提是所有节点连接同一个主数据库。
   - 同步完成前，各节点读到的值可能不一致。
3. 主节点和从节点（`NODE_TYPE`）在保存和同步设置时没有区别，可以在任一节点保存。

以下修改不随同步生效，需要重启：

1. 「身份验证 › 自定义 OAuth」的新增、编辑、删除只在处理该请求的节点生效；其他节点需要重启后才会加载。详见[身份验证配置](./settings-auth)。
2. 「请求策略 › 会话与重试」中的「最多缓存会话数」修改后需要重启（使用 Redis 时不涉及），详见[请求策略配置](./settings-request-policies#保存与生效)。
3. 部署环境变量只在启动时读取，修改后需要重启，界面中也不显示，例如 `SYNC_FREQUENCY`、`NODE_TYPE` 和 `GLOBAL_API_RATE_LIMIT` 等全局限流变量。
   - 少数环境变量会覆盖界面中的值，例如 `CHANNEL_TEST_FREQUENCY`、`CHANNEL_TEST_ENABLED`，详见[渠道健康](./settings-request-policies#渠道健康)。

## 敏感配置与审计记录

**敏感配置**

- 配置键名以 `Token`、`Secret`、`Key`、`secret` 或 `api_key` 结尾的设置（主要是各类密钥、令牌和凭证字段）不会通过设置读取接口返回：整项省略，而不是打码显示，因此界面中这些字段始终为空。
- 这类字段通常留空表示保留已保存的值，只有输入新值才会提交；部分字段下方提示「留空以保留现有密钥」「留空以保留现有凭证」或「除非正在轮换密钥，否则留空」。例外：「运维 › Worker 代理」中的「Worker URL」为空时保存，「Worker 访问密钥」会被一并清空。自定义 OAuth 的客户端密钥同样不回显，编辑时留空即保留。
- 设置值在数据库中以明文保存，应同等保护数据库和备份。

**审计记录**

- 逐项保存成功时，每个字段记录一条审计日志，显示为「修改系统设置」加配置键名，只记录配置键名，不记录值。
- 使用专用保存方式的设置记录方式不同：请求策略只记录请求方法和路径；模型定价记录改动的模型名；通行密钥域名（含「系统信息」中的「服务器地址」）记录被移除的域名和受影响的凭证数量；自定义 OAuth 只记录新增、编辑或删除的操作类型。
- 保存失败的请求也会留下记录，但不包含配置键名。
- 审计日志位于侧边栏「常规 › 审计日志」。Root 的操作记录只有 Root 能看到。
- 审计日志不保存旧值，不能用来恢复配置，也不能代替外部的密钥管理和变更记录。

<Callout type="warn">
不要在截图、工单或普通日志中记录客户端密钥、SMTP Token、支付密钥等敏感值。读取接口不回显明文，不代表浏览器、代理、数据库备份或运维环境可以不保护凭证。
</Callout>

## 变更前记录与验证

系统设置没有配置快照、历史版本对比或一键回滚。生产环境修改前应自行记录原值，并准备按原配置逐项恢复。建议至少记录：

- 修改的设置域、分区和字段；
- 修改前的非敏感值，以及敏感凭证在密钥管理系统中的版本；
- 预期影响的页面、接口、角色和外部服务；
- 测试步骤、通过标准和恢复条件；
- 多实例环境需要等待的同步时间，以及需要重启的项。

保存后按以下步骤验证：

1. 确认提示。逐项保存时，每个修改的字段都应有一条「设置更新成功」；出现失败提示时，失败的字段及其后的字段都没有保存。
2. 刷新页面，核对非敏感字段；敏感字段始终为空，无法通过刷新核对。重要修改在一个同步周期后再刷新复核。
3. 到真正受影响的入口验证，例如登录、发信、支付沙箱、回调和模型请求。
4. 多实例部署时，等待一个同步周期后在其他节点验证；修改自定义 OAuth 后，需要先重启其他节点再验证。
5. 涉及身份验证、支付、计费、请求策略、SSRF 或对外回调的修改，先在测试实例或维护窗口验证。

## 常见问题

- **侧边栏找不到「系统设置」**：非 Root 账号看不到该入口。Root 也看不到时，检查「站点与品牌 › 侧边栏模块」中的「管理员区域」和「系统设置」开关；此时仍可从头像菜单进入。
- **Admin 点击「前往设置」后显示「禁止访问」**：系统设置仅 Root 可访问，请联系 Root 修改。
- **一次保存弹出多条「设置更新成功」**：逐项保存时，每个修改的字段各提示一次。
- **保存后只有部分字段生效**：某个字段失败后，后续字段不会提交。根据失败提示修正后再次保存，然后刷新页面核对各字段。
- **点击保存没有任何提示**：该分区没有检测到修改；部分分区在没有改动时不做提示。请确认确实修改了字段。
- **多个节点表现暂时不一致**：等待一个同步周期（默认 60 秒），并检查各节点是否连接同一个主数据库以及 `SYNC_FREQUENCY` 的设置。服务端日志每个周期输出一行 `syncing options from database`（设置 `DEFAULT_LANGUAGE=zh-CN` 时为「正在从数据库同步配置项」）。修改自定义 OAuth 后，需要重启其他节点。
- **密钥字段为空**：敏感配置不回显是设计行为；留空即保留原值，更换时输入新值。
- **外部集成保存后仍然失败**：保存时不测试连通性。检查公网地址、回调、DNS、证书、网络、凭证权限和第三方服务日志。
- **需要恢复旧配置**：按修改前自行记录的原值逐项填回并保存；系统设置没有历史版本恢复功能。
- **「系统设置」入口旁出现数字**：表示有多少个任务插件提供的模型存在价格问题、需要处理，见[计费与支付配置](./settings-billing)中的模型定价。
