## 查找和筛选模型

**操作流程：**
1. 在页面顶部的搜索框中输入关键词，占位文字为「搜索模型名称、供应商、端点或标签...」。
2. 在左侧「筛选」栏中点击分组、供应商、标签、定价类型或端点类型。
3. 在工具栏的排序下拉列表中选择排序方式。
4. 需要清除筛选条件时，点击「筛选」栏的「重置」。

<Callout type="info" title="提示">
- 搜索不区分大小写，匹配模型名称、描述、标签和供应商，不匹配端点；按接口类型查找时，请使用「端点类型」筛选。
- 多个筛选条件同时生效，有筛选条件时显示「筛选已启用」。「重置」不清除搜索框中的文字。
- 搜索、筛选、排序和视图仅在当前页面有效，刷新页面后恢复默认。
- 窗口较窄时（如手机、平板或缩小的浏览器窗口），「筛选」栏收在工具栏的「筛选」按钮中。
- 无匹配的模型时显示「未找到模型」。
</Callout>

## 读懂模型价格

列表中的价格已按分组倍率计算（未选择分组时为可用分组中的最低倍率），模型详情「概览」中的「基础价格」为倍率 1 时的价格。实际扣费按调用时 API 密钥所用的分组计算。

**计费方式说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 计费方式 | 卡片和表格中的价格 | 模型详情「概览」中的价格 | 扣费方式 |
| --- | --- | --- | --- |
| 按量计费 | 「输入」「输出」每 1M（或 1K）Token 的价格；设置了缓存价格时另显示缓存价格。 | 「基础价格」中列出输入、输出，以及已设置的「缓存输入」「缓存写入」「图片输入」「音频输入」「音频输出」价格。 | 按请求的输入、输出 Token 数分别计费；命中缓存、包含图片或音频的部分按对应的价格计费。 |
| 按次计费 | 每次请求的价格。 | 「基础价格」中显示「每次请求」的价格。 | 每次请求按固定价格计费，与 Token 数无关。 |
| 动态计费 | 表格中另显示档位数，如「2 档」；按时段计价的模型另显示「当前时段价格」。 | 另有「动态计费」，说明为「价格根据用量档位和请求条件动态调整」，下方为「分档价格表」，部分模型还有「条件乘数」；缓存价格显示为「缓存读取」。 | 价格随请求的输入长度等条件或时段变化，按请求实际命中的档位计费。无法按档位列出时显示「特殊计费表达式」和「原始表达式」。 |
| 任务计费 | 按每秒、每张图片、每次等用量单位显示价格。 | 可能显示「价格示例」，列出「规格」和「示例价格」，说明为「常见规格的参考价。」。 | 视频、图片等异步任务按任务的实际用量计费。 |
</div>

<Callout type="info" title="提示">
- 模型广场只显示单价，不估算一次调用的总费用。每次调用的实际扣费见<a href="/zh/docs/guide/feature-guide/user/log#查看日志详情" target="_blank" rel="noopener noreferrer">使用日志</a>。
- 按量计费的模型未设置价格时，按系统默认价格显示（以美元显示、分组倍率为 1 时输入为 $75 / 1M Token，输出价格因模型而异），调用时提示价格尚未配置，见[常见问题](#常见问题)。
- 任务计费的模型未设置价格时，显示「按用量计费 · 尚未配置价格」或「未配置」；部分服务方未设置时显示「部分服务方未配置定价」。
</Callout>

## 查看模型详情

**操作流程：**
1. 点击卡片右下角的「详情」，或表格中模型所在的行，页面右侧打开「模型详情」。
2. 点击「概览」「性能」「API」切换标签。
3. 需要复制模型名称时，点击名称右侧的复制按钮。
4. 点击右上角的 × 关闭。

<Callout type="info" title="提示">
- 在排行榜中点击模型名称，打开整页的模型详情，内容相同；点击左上角「返回」回到模型广场。
- 整页详情中找不到该模型时显示「模型未找到」，如模型已不在模型广场中，或账户无权使用。
</Callout>

- 无统计数据时仅显示「该模型暂无性能数据。」，如最近 24 小时无调用，或管理员关闭了性能统计。

## 查看排行榜

- 模型广场与排行榜-排行榜

![模型广场与排行榜-排行榜页面](/assets/guide/feature-guide/top-navigation-leaderboard.png)

排行榜按全站所有用户调用的 Token 用量，对模型和厂商排名，不区分账户，也不显示用户信息。

**操作流程：**
1. 点击顶部导航的「排行榜」。
2. 点击标题下方的「今天」「本周」「本月」或「今年」。
3. 鼠标悬停在图表上，查看各模型或厂商的用量。
4. 点击模型名称，查看该模型的详情；点击厂商名称，打开模型广场并只显示该厂商的模型。

<Callout type="info" title="提示">
- 时间范围为截至当前的滚动区间：「今天」为最近 24 小时，「本周」为最近 7 天，「本月」为最近 30 天，「今年」为最近 365 天，不是自然日、周、月、年。
- 默认显示「本周」；截图中选中的是「今天」，因此图表按小时显示。
- 用量为输入和输出 Token 数之和。新的调用默认约 5～10 分钟后计入。
- 仅在管理员开启数据看板的统计后有数据，见<a href="/zh/docs/guide/feature-guide/system-settings/settings-content#数据仪表板" target="_blank" rel="noopener noreferrer">控制台内容配置</a>。
- 排行榜中的模型可能已不在模型广场中，或账户无权使用，点击名称时显示「模型未找到」。
</Callout>

**区块说明：**

下表按页面中从上到下的顺序排列。

| 区块 | 内容 | 阅读提示 |
| --- | --- | --- |
| 热门模型 | 各时间段各模型的 Token 用量（堆叠柱状图），右上角为合计用量。 | 「今天」按小时、「本周」「本月」按天、「今年」按周显示。单独显示用量最多的 10 个模型，其余合并为「Others」。 |
| LLM 排行榜 | 用量最多的 20 个模型，分两列显示名次、模型名称、厂商（「by …」）、用量和增长率。 | 增长率为与上一个同样长度的时间段相比的变化，绿色向上为增长，红色向下为下降；上一时间段无用量时显示 100%。 |
| 市场份额 | 各时间段各厂商的用量占比（100% 堆叠图）。 | 单独显示用量最多的 5 个厂商，其余合并为「Others」。 |
| 按模型厂商 | 用量最多的 12 个厂商，显示名次、用量和占比，说明为「厂商按聚合 Token 用量排序」。 | 占比低于 0.1% 时显示 `<0.1%`；无数据时显示「暂无厂商数据」。 |
| 上升趋势、下降趋势 | 与上一时间段相比名次上升、下降的模型，各最多 6 个，显示「#当前名次 · 厂商」和名次变化。 | 上一时间段未上榜的模型不列入；无变化时显示「当前没有显著上升的模型」「当前没有显著下降的模型」。 |
</div>

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="顶部导航没有「模型广场」「排行榜」，或打开后回到首页">
**可能原因**：管理员关闭了对应的入口。入口关闭后，打开收藏的地址也会回到首页。

**处理方法**：
1. 窄屏（如手机）时，在首页等公开页面展开顶部导航的菜单查看；控制台内窗口宽度小于 1024px 时不显示顶部导航。
2. 需要使用时，请联系管理员开启。
</Accordion>

<Accordion title="点击「模型广场」或「排行榜」后提示「需要登录」">
**提示原文**：「请登录后查看 …。」（英文 Please sign in to view ….），下方显示「将在 … 秒后跳转到登录页。」

**可能原因**：管理员设置了需登录才能查看，当前未登录。

**处理方法**：
1. 点击「立即登录」，或等待 5 秒自动进入登录页。
2. 登录后自动回到原页面。
</Accordion>

<Accordion title="模型广场中的价格与实际扣费不一致">
**可能原因**：
- 未选择分组时，列表按可用分组中倍率最低的分组显示价格，调用时按 API 密钥所用的分组计费。
- 账户对某些分组设有专属倍率，登录后显示的才是账户的价格。
- 动态计费的模型按请求命中的档位或时段计费，缓存、图片、音频部分按对应的价格计费。
- 选择了「充值」，显示的是按充值付款金额换算的价格，不含分组的充值倍率和充值折扣。

**处理方法**：
1. 登录后在「筛选」栏的「分组」中选择 API 密钥所用的分组，查看该分组的价格。
2. 在模型详情「概览」的「按分组定价」中核对倍率。
3. 在<a href="/zh/docs/guide/feature-guide/user/log#查看日志详情" target="_blank" rel="noopener noreferrer">使用日志</a>中查看该次调用的计费明细。
</Accordion>

<Accordion title="模型显示了价格，调用时提示价格尚未配置">
**提示原文**：「模型 … 的价格尚未由管理员配置，暂时无法使用，请联系站点管理员开启该模型」（英文 Model … has not been priced by the administrator yet. Please contact the site administrator to enable this model.）

**说明**：管理员尚未给该模型设置价格时，模型广场按系统默认价格显示（以美元显示、分组倍率为 1 时输入为 $75 / 1M Token，输出价格因模型而异），并非管理员设置的价格。账户在<a href="/zh/docs/guide/feature-guide/user/personal-setting#设置通知和行为偏好" target="_blank" rel="noopener noreferrer">个人资料</a>中开启「接受未定价模型」后可调用这类模型，并按该默认价格扣费。

**处理方法**：
1. 改用其他模型。
2. 需要使用该模型时，请联系管理员设置价格。
</Accordion>

<Accordion title="模型在模型广场中，但调用失败">
**说明**：模型出现在模型广场中，表示站点有可用的渠道提供该模型，且账户的某个分组可调用，不保证每个分组、每次调用都成功。请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「该令牌无权访问模型 …」（英文 This token has no access to model …） | API 密钥设置了「模型限制」，不含该模型。 | 编辑密钥的「模型限制」，见<a href="/zh/docs/guide/feature-guide/user/token#常见问题" target="_blank" rel="noopener noreferrer">API 密钥</a>。 |
| 「分组 … 下模型 … 无可用渠道（distributor）」（英文 No available channel for model … under group … (distributor)） | API 密钥所用的分组不能调用该模型。 | 在模型详情的「按分组定价」中查看可用的分组，修改密钥的分组。 |
| 「用户额度不足, 剩余额度: …」（英文 Insufficient user quota, remaining quota: …） | 账户余额不足。 | 前往<a href="/zh/docs/guide/feature-guide/user/wallet" target="_blank" rel="noopener noreferrer">钱包</a>充值或兑换。 |
| 其他上游错误 | 模型的上游服务暂时异常。 | 查看卡片的「状态」和模型详情的「性能」，稍后重试或改用其他模型。 |
</Accordion>

<Accordion title="看不到某个模型，或登录前后看到的模型和价格不同">
**可能原因**：
- 模型广场只列出账户可用分组能调用的模型。未登录时按站点对所有用户开放的分组显示，登录后按账户可用的分组显示。
- 管理员停用了该模型，或提供该模型的渠道已全部停用。
- 管理员刚修改了设置，模型广场约 1 分钟后更新。

**处理方法**：
1. 登录后刷新页面。
2. 清除搜索关键词，点击「筛选」栏的「重置」。
3. 如仍找不到，请联系管理员确认该模型是否对账户的分组开放。
</Accordion>

<Accordion title="模型的「分组」中有账户无法使用的分组">
**说明**：卡片、表格和模型详情「模型」中的「分组」列出可调用该模型的全部分组，「性能」的「各分组性能」列出最近 24 小时有调用的分组，均可能包含账户无权使用的分组；「筛选」栏的「分组」和「按分组定价」仅列出账户可用的分组。

**处理方法**：
1. 以「按分组定价」中的分组和价格为准。
2. 需要使用其他分组时，请联系管理员。
</Accordion>

<Accordion title="性能数据为空，或「状态」显示「—」">
**提示原文**：「该模型暂无性能数据。」（英文 Performance data is not yet available for this model.）

**可能原因**：
- 最近 24 小时该模型无可统计的调用。请求参数错误、余额不足等由请求本身导致的失败不计入统计。
- 管理员关闭了模型性能统计。
- 数据加载失败。

**处理方法**：
1. 稍后刷新页面。
2. 如长期无数据，请联系管理员确认是否开启了性能统计。
</Accordion>

<Accordion title="「API」中的「支持的参数」「速率限制」与实际不符">
**说明**：这两部分为按模型类型生成的参考示例，不代表该模型实际支持的参数，也不代表本站的实际限制。

**处理方法**：
1. 请求参数以 <a href="/zh/docs/api" target="_blank" rel="noopener noreferrer">API 参考</a>和模型提供方的说明为准。
2. 实际的调用频率限制请咨询管理员。
</Accordion>

<Accordion title="调用示例中的地址为 http://localhost:3000">
**可能原因**：示例中的地址为管理员设置的服务器地址，未设置时为 `http://localhost:3000`。

**处理方法**：
1. 将地址替换为<a href="/zh/docs/guide/feature-guide/user/token#复制密钥并调用模型" target="_blank" rel="noopener noreferrer">API 密钥</a>页「API 地址」中的地址。
2. 请联系管理员设置服务器地址。
</Accordion>

<Accordion title="排行榜没有数据、不更新，或提示「无法加载排行榜」">
**提示原文**：「无法加载排行榜」（英文 Unable to load rankings），下方显示具体原因。

**可能原因**：
- 管理员未开启数据看板的统计，或统计开启前的调用不计入。
- 所选时间范围内无调用。
- 新的调用默认约 5～10 分钟后才计入。
- 网络或服务暂时异常。

**处理方法**：
1. 切换到更长的时间范围，如「本月」。
2. 稍后刷新页面。
3. 如仍无数据，请联系管理员确认是否开启了数据看板的统计。
</Accordion>

<Accordion title="在排行榜中点击模型名称后显示「模型未找到」">
**提示原文**：「模型未找到」（英文 Model not found），说明为「您查找的模型不存在。」

**可能原因**：排行榜按历史用量统计，该模型已不在模型广场中，或账户的分组无法调用该模型。

**处理方法**：
1. 点击「返回模型」，在模型广场中查找可用的替代模型。
</Accordion>

</Accordions>
