## 模型广场

- 点击右上角「模型广场」或访问 `/pricing` ，进入模型广场。页面展示的是当前平台对用户公开的价格，不等同于上游服务商的原始价格。
- 模型广场用于浏览平台已启用的 AI 模型，并对比不同模型的供应商、计费价格、性能及运行状态，帮助用户选择适合业务场景的模型。

1. **模型搜索**：支持根据模型名称、供应商、端点或标签快速查找目标模型。
2. **模型筛选**：支持按照分组、供应商、模型类型和标签等条件筛选模型，也可重置全部筛选条件。
3. **价格查看**：展示模型的输入、输出及缓存价格，并标明按量计费等计费方式。
4. **计价切换**：支持切换标准价格与充值价格，并可按每 1M Tokens 或每 1K Tokens 查看价格。
5. **模型排序**：支持按照模型名称等条件调整模型的展示顺序。
6. **展示方式**：支持在宫格视图与列表视图之间切换。
7. **性能信息**：展示模型的延迟、吞吐量及当前运行状态，便于评估模型的可用性与响应能力。
8. **模型详情**：点击“详情”可查看模型的完整介绍、能力和相关配置信息。
9. **复制模型名称**：点击复制按钮，可快速复制模型名称，方便在接口调用或系统配置中使用。

## 排行榜

- 点击右上角「排行榜」或访问 `/rankings` ，进入排行榜。
- 排行榜用于查看平台模型及供应商的使用量排名与变化趋势，数据基于 Token 用量实时更新。

1. **时间范围切换**：支持按今天、本周、本月和今年查看不同时间范围内的排行数据。
2. **热门模型**：通过图表展示各模型每日 Token 用量，便于对比模型的使用热度。
3. **LLM 排行榜**：按照 Token 用量展示平台中最受欢迎的模型及其排名。
4. **市场份额**：展示不同模型供应商的 Token 用量占比及每日变化情况。
5. **模型厂商排行**：根据 Token 总用量对模型供应商进行排序，便于了解各厂商的使用规模。
6. **上升趋势**：展示排名正在提升的模型及其名次变化。
7. **下降趋势**：展示排名出现下滑的模型及其名次变化。
