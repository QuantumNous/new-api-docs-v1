## 完成安全验证

- 安全与访问-安全验证

![安全与访问-安全验证页面](/assets/guide/feature-guide/personal-security-and-access-security-verification.png)

执行下表中的操作时弹出「安全验证」窗口，说明为「执行此敏感操作前，请先验证身份。」；删除账户时窗口标题为「删除账户」。截图为该窗口在不同账户状态下的三种样子。

**操作流程：**
1. 有多种验证方式时，在「安全验证」窗口顶部选择验证方式。
2. 按所选方式填写验证码或密码，或按设备提示完成 Passkey 验证。
3. 点击「验证」；选择「已绑定账号」时，点击「使用 … 继续」并在弹出的窗口中完成授权。

<Callout type="info" title="提示">
- 验证通过后，请在 1 分钟内完成本次操作。每次验证仅可用于一次操作，修改了操作内容（如权限、邮箱）时需重新验证。
- 账户已启用两步验证或已注册 Passkey 时，仅可使用这两种方式验证，不可使用密码。
- 账户已注册 Passkey 时，默认选中「Passkey」。
</Callout>

**验证方式说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 验证方式 | 出现条件 | 填写内容 |
| --- | --- | --- |
| 身份验证器代码 | 账户已启用两步验证。 | 在「认证器验证码或备用码」中填写验证器中的 6 位验证码，或一个未使用的备用码。重新生成备用码时仅可填写 6 位验证码。连续输错 5 次后锁定 5 分钟。 |
| Passkey | 账户已注册 Passkey，且管理员开启了 Passkey。 | 按浏览器或系统的提示完成指纹、面容、PIN 或安全密钥确认。站点有多个通行密钥域名时，可点击「使用其他网站的通行密钥」选择域名。 |
| 密码 | 账户未启用两步验证、未注册 Passkey，且有密码。 | 当前的登录密码。更改密码时直接使用窗口中填写的「当前密码」验证，不再弹出「安全验证」窗口。 |
| 已绑定账号 | 账户未启用两步验证、未注册 Passkey，且无密码。 | 点击「使用 … 继续」，在弹出的窗口中用已绑定的第三方账号授权。 |
</div>

**需要安全验证的操作：**


| 操作 | 可用的验证方式 |
| --- | --- |
| 设置或更改密码、绑定邮箱和第三方账号、解绑第三方账号、启用两步验证、启用 Passkey、创建访问令牌、修改访问令牌权限、撤销访问令牌、删除账户 | 已启用两步验证或已注册 Passkey 时，使用这两种方式；否则使用密码，无密码时使用已绑定账号。 |
| 解绑 Passkey | 仅两步验证或 Passkey。 |
| 重新生成备用码、禁用两步验证 | 仅两步验证或 Passkey。重新生成备用码时，两步验证仅可填写 6 位验证码，不可使用备用码。 |
| 仅修改访问令牌名称、退出登录会话、保存「记录 IP 地址」、查看访问记录 | 不需要安全验证。 |


## 更改或设置密码

- 安全与访问-更改密码

![安全与访问-更改密码页面](/assets/guide/feature-guide/personal-security-and-access-change-password.png)

**操作流程：**
1. 点击「登录与认证」中的「更改密码」；账户无密码时点击「设置密码」。
2. 在窗口中填写「当前密码」「新密码」和「确认新密码」；设置密码时不显示「当前密码」。
3. 点击窗口底部的「更改密码」或「设置密码」。
4. 弹出「安全验证」窗口时完成验证。

<Callout type="info" title="提示">
- 更改密码时，账户未启用两步验证、未注册 Passkey 的，直接用填写的「当前密码」验证，不弹出「安全验证」窗口；已启用两步验证或已注册 Passkey 的，弹出「安全验证」窗口，需使用这两种方式验证。设置密码时在弹出的「安全验证」窗口中验证。
- 修改成功后，其他设备上的登录会话全部退出，当前设备保持登录；系统向账户邮箱发送通知邮件。
- 管理员关闭密码登录时，「安全验证」窗口中的「密码」方式不可用。
</Callout>

**配置项说明：**

「更改密码」「设置密码」窗口的配置项如下，下表按窗口中的顺序排列。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 配置项 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- |
| 当前密码 | 账户现在的登录密码。 | 仅更改密码时显示，必填；为空时提示「请输入当前密码」，错误时提示「当前密码不正确。」。 | 空 |
| 新密码 | 要设置的登录密码。 | 必填，8–128 个字符，窗口提示「使用 8–128 个字符。」；长度不符时提示「密码长度必须为 8–128 个字符。」，与当前密码相同时提示「新密码必须与当前密码不同」。 | 空 |
| 确认新密码 | 再次输入新密码。 | 必填，与「新密码」不一致时提示「密码不匹配」。 | 空 |
</div>

## 绑定邮箱和第三方账号

- 安全与访问-绑定邮箱

![安全与访问-绑定邮箱页面](/assets/guide/feature-guide/personal-security-and-access-account-binding.png)

「账户绑定」中始终显示「邮箱」；GitHub、Discord、OIDC、Telegram、LinuxDO、微信和管理员添加的其他登录方式，仅在管理员开启后显示。

**绑定或更改邮箱操作流程：**
1. 点击「邮箱」右侧的「绑定」；已绑定时点击「更改」。
2. 在「电子邮件地址」中填写邮箱，点击「继续」。
3. 在「安全验证」窗口中完成验证。
4. 在「新邮箱验证码」中填写新邮箱收到的 6 位验证码；更改邮箱且未使用两步验证或 Passkey 验证时，还需在「当前邮箱验证码」中填写原邮箱收到的验证码。
5. 点击「确认邮箱」。

**绑定第三方账号操作流程：**
1. 点击第三方账号右侧的「绑定」。
2. 在「安全验证」窗口中完成验证。
3. 在「继续绑定账户」窗口中点击「继续」。
4. 在弹出的授权窗口中登录第三方账号并授权。

**绑定微信操作流程：**
1. 点击「微信」右侧的「绑定」。
2. 扫描「绑定微信」窗口中的二维码，按提示获取验证码。
3. 在「验证码」中填写验证码，点击「绑定」。
4. 在「安全验证」窗口中完成验证。

**解绑第三方账号操作流程：**
1. 点击已绑定账号右侧的「解绑」。
2. 在「确认解绑」窗口中确认。
3. 在「安全验证」窗口中完成验证。

<Callout type="info" title="提示">
- 邮箱验证码 10 分钟内有效，60 秒后可点击「重新发送验证码」；连续输错 5 次需点击「重新开始」。绑定完成后，系统向新、旧邮箱发送通知邮件。
- GitHub、Discord、OIDC、Telegram、LinuxDO 和微信绑定后，按钮显示「已绑定」且不可点击，页面不提供解绑，如需解除请联系管理员。仅管理员添加的其他登录方式显示「解绑」。
- 不可解绑账户的最后一种登录方式，否则提示「请先添加其他登录方式，再解除此账户绑定。」。
- 每个第三方账号仅可绑定一个账户。
</Callout>

## 启用两步验证

- 安全与访问-两步验证未启用

![安全与访问-两步验证未启用页面](/assets/guide/feature-guide/personal-security-and-access-2fa-not-enabled.png)

- 安全与访问-设置双重身份验证

![安全与访问-设置双重身份验证页面](/assets/guide/feature-guide/personal-security-and-access-enable-2fa.png)

**操作流程：**
1. 点击「两步验证」中的「启用」。
2. 在「安全验证」窗口中完成验证。
3. 第 1 步「扫描二维码」：用身份验证器应用（如 Google Authenticator、Microsoft Authenticator）扫描二维码，或点击密钥旁的复制按钮后在应用中手动添加，点击「下一步」。
4. 第 2 步「保存备份代码」：点击「复制所有代码」，将 4 个备用码保存到安全的地方，点击「下一步」。
5. 第 3 步「验证设置」：在「验证码」中填写验证器中的 6 位数字，点击「启用 2FA」。

<Callout type="warn" title="保存备用码">
- 每个备用码仅可使用一次。验证器不可用时，可在登录或「安全验证」窗口中用备用码代替验证码。
- 关闭窗口后无法再次查看这些备用码，丢失后请重新生成。
</Callout>

<Callout type="info" title="提示">
- 完成安全验证后，请在 5 分钟内完成三步；超时时提示「设置已过期，请扫描新的二维码并保存新的备用码。」，并生成新的二维码和备用码，旧的作废。
- 验证码每 30 秒更新一次，手机时间不准确时可能验证失败。
- 启用成功后，其他设备上的登录会话全部退出。
</Callout>

## 重新生成备用码

- 安全与访问-两步验证已启用

![安全与访问-两步验证已启用页面](/assets/guide/feature-guide/personal-security-and-access-2fa-enabled.png)

- 安全与访问-重新生成备用代码

![安全与访问-重新生成备用代码页面](/assets/guide/feature-guide/personal-security-and-access-2fa-regenerate-backup-codes.png)

**操作流程：**
1. 点击「两步验证」中的「重新生成备用代码」。
2. 在确认窗口中点击「生成新代码」。
3. 在「安全验证」窗口中填写验证器中的 6 位验证码，或使用 Passkey 验证。
4. 在「您的新备份代码已准备就绪」窗口中点击「复制所有代码」并保存，点击「完成」。

<Callout type="info" title="提示">
- 生成后旧的备用码全部失效，新的备用码为 4 个；关闭窗口后无法再次查看。
- 此处不可使用备用码验证。
- 生成后，其他设备上的登录会话全部退出。
</Callout>

## 禁用两步验证

- 安全与访问-禁用双重身份验证

![安全与访问-禁用双重身份验证页面](/assets/guide/feature-guide/personal-security-and-access-2fa-disable-2fa.png)

**操作流程：**
1. 点击「两步验证」中的「禁用 2FA」。
2. 在「禁用双重身份验证」窗口中勾选「我了解，关闭 2FA 将移除身份验证器验证方式及其备用码。」。
3. 点击「禁用 2FA」。
4. 在「安全验证」窗口中填写验证码或备用码，或使用 Passkey 验证。

<Callout type="warn" title="注意">
- 禁用后，验证器密钥和所有备用码被删除，登录时不再需要验证码，账户的安全性降低。
- 禁用后，其他设备上的登录会话全部退出。如需重新启用，验证器中需添加新的二维码。
</Callout>

## 启用 Passkey

- 安全与访问-Passkey 未启用

![安全与访问-Passkey 未启用页面](/assets/guide/feature-guide/personal-security-and-access-passkey-not-enabled.png)

- 安全与访问-启用 Passkey

![安全与访问-启用 Passkey 页面](/assets/guide/feature-guide/personal-security-and-access-enable-passkey.png)

**操作流程：**
1. 点击「Passkey 登录」中的「启用 Passkey」。
2. 在「安全验证」窗口中完成验证。
3. 按浏览器或系统的提示，用指纹、面容、PIN 或安全密钥完成确认。

<Callout type="info" title="提示">
- 仅在管理员开启 Passkey 后可用；未开启时「安全验证」窗口提示「Passkey 认证已关闭。」，见<a href="/zh/docs/guide/feature-guide/system-settings/settings-auth#通行密钥认证" target="_blank" rel="noopener noreferrer">身份验证配置</a>。
- 浏览器和系统的提示窗口因设备而异，截图中为 Windows 的提示。
- 设备或浏览器不支持时，显示「此设备不支持通行密钥」，「启用 Passkey」不可点击。站点未通过 HTTPS 访问时可能无法注册，请联系管理员。
- 每个账户仅可注册 1 个 Passkey；更换设备时，请先解绑再重新注册。Passkey 与注册时的网站域名绑定，站点更换地址后可能无法使用。
- 注册成功后，其他设备上的登录会话全部退出。
</Callout>

## 解绑 Passkey

- 安全与访问-Passkey 已启用

![安全与访问-Passkey 已启用页面](/assets/guide/feature-guide/personal-security-and-access-passkey-enabled.png)

- 安全与访问-解绑 Passkey

![安全与访问-解绑 Passkey 页面](/assets/guide/feature-guide/personal-security-and-access-passkey-unbind.png)

**操作流程：**
1. 点击「Passkey 登录」中的「解绑 Passkey」。
2. 在「移除通行密钥？」窗口中点击「移除」。
3. 在「安全验证」窗口中使用两步验证或 Passkey 完成验证。

</Callout>

## 创建和管理访问令牌

- 安全与访问-访问令牌

![安全与访问-访问令牌页面](/assets/guide/feature-guide/personal-security-and-access-access-token.png)

- 安全与访问-创建访问令牌

![安全与访问-创建访问令牌页面](/assets/guide/feature-guide/personal-security-and-access-access-token-create.png)

访问令牌用于在脚本中调用面板 API（即账户管理接口），如查询个人资料、余额和日志，每个令牌仅拥有创建时勾选的权限，不可用于调用模型。

**创建操作流程：**
1. 点击「访问令牌」右上角的「创建访问令牌」。
2. 填写「令牌名称」，选择「过期时间」。
3. 在「权限」中点击需要授予的动作，如「个人资料」的「查看」。
4. 点击窗口底部的「创建访问令牌」。
5. 在「安全验证」窗口中完成验证。
6. 在「访问令牌」窗口中点击「复制令牌」，保存后点击「关闭」。

<Callout type="warn" title="注意保管访问令牌">
- 令牌仅在创建时显示一次，关闭窗口后无法再次查看；丢失时请撤销后重新创建。
- 获得访问令牌的人可在其权限范围内操作该账户。「账户安全」的「编辑」包含修改密码、两步验证设置和删除账户等操作，请谨慎授予。
</Callout>

<Callout type="info" title="提示">
- 调用时在请求头中填写 `Authorization: Bearer nap_…`。
- 每个账户最多 20 个访问令牌，已过期 7 天内的令牌仍计入；达到上限时「创建访问令牌」不可点击。
- 访问令牌不可用于管理访问令牌和登录会话，这些操作需登录网页后进行。
</Callout>

**编辑操作流程：**
1. 点击令牌右侧的 ⋯，选择「编辑」。
2. 在「编辑访问令牌」窗口中修改「令牌名称」或「权限」。
3. 点击「保存」；修改了权限时，在「安全验证」窗口中完成验证。

**撤销操作流程：**
1. 点击令牌右侧的 ⋯，选择「撤销」。
2. 在确认窗口中核对提示「撤销此访问令牌？使用它的脚本会立即失效。」，确认撤销。
3. 在「安全验证」窗口中完成验证。

<Callout type="warn" title="注意">
撤销后令牌立即失效并被删除，无法恢复，使用该令牌的脚本立即无法调用。
</Callout>

<Callout type="info" title="提示">
升级前创建的旧版令牌显示在列表顶部，带「旧版令牌」标记，并提示「旧版令牌将于 … 停用，请创建新令牌替换。」。停用后无法使用，请创建新令牌替换并撤销旧版令牌。
</Callout>

## 删除账户

**操作流程：**
1. 点击「账户操作」中的「删除账户」。
2. 在确认窗口的输入框中输入完整的用户名（区分大小写）。
3. 点击「删除账户」。
4. 在标题为「删除账户」的「安全验证」窗口中完成验证。

<Callout type="warn" title="注意">
- 删除后无法恢复。账户的所有登录会话和访问令牌立即失效，页面退出到登录页。
- 已删除账户的用户名不可再次注册；站点开启邮箱验证时，该账户的邮箱也不可再用于注册。注册时提示「用户名已存在，或已注销」。
- 删除前，请确认账户的余额和订阅已不再需要。
- Root 账户不可删除，执行时提示「你没有执行此操作的权限。」。
</Callout>

<Accordion title="「安全验证」窗口提示「此操作没有可用的验证方式。」">
**提示原文**：「此操作没有可用的验证方式。」（英文 No verification method is available for this action.），其后列出各方式不可用的原因。

**说明**：请根据列出的原因处理：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「密码认证已禁用。」（英文 Password authentication is disabled.） | 管理员关闭了密码登录，且账户未启用两步验证、未注册 Passkey。 | 联系管理员；能登录时先启用两步验证。 |
| 「Passkey 认证已关闭。」（英文 Passkey authentication is disabled.） | 管理员未开启 Passkey。 | 改用其他验证方式，或联系管理员。 |
| 「没有可用的已绑定 OAuth 提供方。」（英文 No linked OAuth provider is available.） | 账户无密码，且无已绑定并开启的第三方账号。 | 联系管理员。 |
| 「两步验证已暂时锁定。」（英文 Two-factor authentication is temporarily locked.） | 连续 5 次验证失败。 | 等待 5 分钟后重试，或改用 Passkey。 |
</Accordion>

<Accordion title="验证时提示「验证失败，请重试。」">
**提示原文**：「验证失败，请重试。」（英文 Verification failed. Please try again.）

**可能原因**：
- 验证码、备用码或密码填写错误。
- 手机时间不准确，验证器生成的验证码已失效。

**处理方法**：
1. 核对后重新填写；验证码每 30 秒更新一次，请填写最新的验证码。
2. 校准手机时间后重试。连续失败 5 次将锁定 5 分钟。
</Accordion>

<Accordion title="提示「安全验证已过期，请重新验证。」">
**说明**：验证通过后需在 1 分钟内完成操作，每次验证仅可用于一次操作。请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「安全验证已过期，请重新验证。」（英文 Security verification has expired. Please verify again.） | 验证后超过 1 分钟才完成操作。 | 重新验证后立即完成操作。 |
| 「安全验证已失效，请重新验证。」（英文 Security verification is no longer valid. Please verify again.） | 本次验证已被使用。 | 重新执行操作并验证。 |
| 「验证与本次操作的具体内容不匹配，请重新验证。」（英文 Verification does not match this action's details. Please verify again.） | 验证后修改了操作内容，如权限或邮箱。 | 确认操作内容后重新验证。 |
</Accordion>

<Accordion title="丢失验证器设备，无法输入验证码">
**说明**：登录和「安全验证」窗口中，可用未使用的备用码代替验证码，每个备用码仅可使用一次。

**处理方法**：
1. 登录时，在两步验证页填写一个未使用的备用码。
2. 在本页执行「禁用 2FA」，在「安全验证」窗口中填写另一个备用码。
3. 用新设备重新启用两步验证，并保存新的备用码。
4. 备用码已用完或丢失时，请联系管理员重置两步验证。
</Accordion>

<Accordion title="启用两步验证时提示「设置已过期…」或「认证器验证码错误。」">
**说明**：请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「设置已过期，请扫描新的二维码并保存新的备用码。」（英文 Setup expired. Scan the new QR code and save the new backup codes.）<br/>「两步验证设置已过期或变更，请重新设置。」（英文 The two-factor setup has expired or changed. Start setup again.） | 完成安全验证后超过 5 分钟，或重新发起了设置。 | 删除验证器中刚添加的条目，扫描新的二维码并保存新的备用码。 |
| 「认证器验证码错误。」（英文 The authenticator code is incorrect.） | 验证码填写错误或已过期。 | 填写验证器中最新的 6 位验证码；仍失败时校准手机时间。 |
</Accordion>

<Accordion title="无法启用 Passkey">
**说明**：请根据提示原文或现象判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「此设备不支持通行密钥」（英文 Passkey not supported on this device） | 浏览器或设备不支持通行密钥。 | 改用支持生物识别或安全密钥的浏览器和设备。 |
| 「Passkey 认证已关闭。」（英文 Passkey authentication is disabled.） | 管理员未开启 Passkey。 | 联系管理员。 |

| 「注册流程已过期，请重试。」（英文 Registration flow expired. Please try again.） | 注册流程未能正常开始。 | 重新点击「启用 Passkey」；仍失败时联系管理员。 |
| 站点地址以 http:// 开头时注册失败 | 站点未使用 HTTPS。 | 联系管理员。 |
</Accordion>

<Accordion title="更换网址后 Passkey 无法使用">
**提示原文**：「此通行密钥域名无法在当前网站使用。请前往原网站或选择其他验证方式。」（英文 This Passkey domain is not available on this website. Use its original website or another verification method.）

**可能原因**：Passkey 与注册时的网站域名绑定，当前网址与注册时不同。

**处理方法**：

<Accordion title="无法解绑第三方账号">
