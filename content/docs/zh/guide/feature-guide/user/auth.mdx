## 使用账号密码登录

**操作流程：**
1. 点击站点右上角的「登录」，打开登录页。
2. 在「用户名或电子邮件」中填写用户名或账户绑定的邮箱。
3. 在「密码」中填写密码。
4. 页面显示人机验证时，按提示完成验证，直到显示「成功!」。
5. 页面显示协议勾选框时，勾选「我已阅读并同意 …」。
6. 点击「登录」。
7. 账户已启用两步验证或已注册 Passkey 时，按[完成登录验证](#完成登录验证)操作。

<Callout type="info" title="提示">
- 登录成功后提示「欢迎回来！」并进入控制台；从需要登录的页面跳转过来时，登录后回到原页面。
- 登录页不提供「记住我」。登录状态自登录起保持 30 天，由系统固定，不可修改，到期后需重新登录。
- 每次点击「登录」后，人机验证需重新通过。
- 管理员关闭密码登录时，登录页不显示「用户名或电子邮件」「密码」和「忘记密码？」，请使用其他登录方式。
</Callout>

## 使用第三方账号或 Passkey 登录

**操作流程：**
1. 页面显示协议勾选框时，先勾选「我已阅读并同意 …」。
2. 点击「使用 Passkey 登录」，或「或继续使用」下方的「使用 … 继续」。
3. 按下表完成验证或授权。
4. 账户已启用两步验证或已注册 Passkey 时（使用 Passkey 登录除外），按[完成登录验证](#完成登录验证)操作。

## 完成登录验证

账户已启用两步验证或已注册 Passkey 时，用账号密码、微信或第三方账号登录后，页面显示「安全验证」并弹出「完成登录」窗口，说明为「请验证身份以完成登录。」。

**操作流程：**
1. 在窗口顶部选择「身份验证器代码」或「Passkey」，仅显示账户已启用的方式。
2. 选择「身份验证器代码」时，在「认证器验证码或备用码」中填写验证器中的 6 位验证码，或一个未使用的备用码。
3. 点击「验证」；选择「Passkey」时，再按浏览器或系统的提示完成确认。

<Callout type="info" title="提示">
- 请在 5 分钟内完成验证，超时提示「登录流程已过期，请重新登录。」。刷新页面后回到登录页，需重新登录。
- 连续输错 5 次后锁定 5 分钟，提示「两步验证已暂时锁定。」。
- 每个备用码仅可使用一次。启用两步验证和保存备用码见<a href="/zh/docs/guide/feature-guide/user/security#启用两步验证" target="_blank" rel="noopener noreferrer">安全与访问</a>。
</Callout>

## 注册账户

- 注册与登录-注册

![注册与登录-注册页面](/assets/guide/feature-guide/registration-and-login-register.png)

**操作流程：**
1. 点击登录页标题下方的「注册」，或首页的「开始使用」，打开「创建一个账户」页。
2. 填写「用户名」「密码」和「确认密码」。
3. 页面显示「电子邮件（验证必需）」时，填写邮箱，点击「发送验证码」，再填写邮件中的验证码。
4. 页面显示人机验证时，按提示完成验证。
5. 页面显示协议勾选框时，勾选「我已阅读并同意 …」。
6. 点击「创建账户」。
7. 在跳转后的登录页中，用刚注册的用户名和密码登录。

<Callout type="info" title="提示">
- 邮箱和验证码仅在管理员开启邮箱验证后显示，位于「确认密码」下方；截图中未开启邮箱验证，因此无这两项。
- 注册成功后提示「账户已创建！请登录」，不自动登录。注册的账户均为普通用户。
- 注册页不提供邀请码输入框。通过他人的邀请链接打开注册页并注册时，自动记录邀请关系，见<a href="/zh/docs/guide/feature-guide/user/wallet#转移邀请奖励" target="_blank" rel="noopener noreferrer">钱包</a>。
- 也可点击「创建账户」下方的第三方账号按钮，首次登录即创建账户，见[使用第三方账号或 Passkey 登录](#使用第三方账号或-passkey-登录)。
- 站点未开启邮箱验证时，账户不绑定邮箱，忘记密码时无法通过邮箱重置。请在登录后到<a href="/zh/docs/guide/feature-guide/user/security#绑定邮箱和第三方账号" target="_blank" rel="noopener noreferrer">安全与访问</a>绑定邮箱。
</Callout>

## 重置忘记的密码

- 注册与登录-忘记密码

![注册与登录-忘记密码页面](/assets/guide/feature-guide/registration-and-login-forgot-password-reset.png)

**操作流程：**
1. 点击登录页「密码」右上方的「忘记密码？」，打开「忘记密码」页。
2. 在「Email」中填写账户绑定的邮箱。
3. 页面显示人机验证时，按提示完成验证。
4. 点击「发送重置邮件」。
5. 打开主题为「… 密码重置」的邮件，点击邮件中的「此处」。
6. 在「重置密码」页核对「邮箱」，点击「确认重置密码」。
7. 点击「新密码」右侧的复制按钮，保存系统生成的新密码。
8. 点击「返回登录」，用新密码登录。
9. 登录后到<a href="/zh/docs/guide/feature-guide/user/security#更改或设置密码" target="_blank" rel="noopener noreferrer">安全与访问</a>将密码修改为自己的密码。

<Callout type="warn" title="注意">
- 新密码由系统生成，为 12 位字母和数字，不可自行设置；点击「确认重置密码」后旧密码立即失效。
- 新密码仅在「重置密码」页显示，系统会尝试自动复制到剪贴板，离开页面前请确认已保存。
- 重置后，该账户在所有设备上的登录会话全部退出。两步验证和 Passkey 不受影响，登录时仍需验证。
</Callout>

<Callout type="info" title="提示">
- 重置链接 10 分钟内有效，仅可使用一次；重新发送重置邮件后，之前的链接失效。
- 无论邮箱是否绑定了账户，页面都提示「重置邮件已发送，请检查您的收件箱」，仅绑定了账户的邮箱会收到邮件。
- 「忘记密码？」仅在管理员未关闭密码登录时显示；管理员配置了邮件服务后才能发出邮件。
</Callout>

## 查看和退出登录会话

- 注册与登录-登录会话

![注册与登录-登录会话页面](/assets/guide/feature-guide/registration-and-login-login-session-management.png)

每次登录都会为当前设备建立一个登录会话。登录后，在侧边栏「个人」→「安全与访问」的「登录会话」中，可查看正在登录该账户的设备，点击其他设备右侧的「撤销」、当前设备右侧的「登出」，或点击「退出其他会话」。操作方法和各列含义见<a href="/zh/docs/guide/feature-guide/user/security#管理登录会话" target="_blank" rel="noopener noreferrer">安全与访问</a>。

<Callout type="info" title="提示">
- 发现不认识的设备时，请撤销该会话并修改密码。
- 重置密码后，所有设备的登录会话全部退出。
- 同时登录的设备过多时无法再登录，处理方法见[常见问题](#常见问题)。
</Callout>

<Accordion title="登录时提示「用户名或密码错误，或用户已被封禁」">
**提示原文**：「用户名或密码错误，或用户已被封禁」（英文 Username or password is incorrect, or user has been banned）

**可能原因**：
- 用户名、邮箱或密码填写错误，提示不区分具体原因。
- 账户已被管理员禁用，或已注销。
- 账户无密码，如通过第三方账号注册且未设置密码。
- 使用邮箱登录时，邮箱中含大写字母，部分站点区分邮箱的大小写。

**处理方法**：
1. 核对用户名和密码后重试；使用邮箱登录时，请全部使用小写字母，或改用用户名登录。
2. 通过第三方账号注册的账户，请使用原第三方账号登录。
3. 忘记密码时，按[重置忘记的密码](#重置忘记的密码)操作。
4. 如仍无法解决，请联系管理员确认账户状态。
</Accordion>

<Accordion title="登录页没有「注册」，或注册时提示注册已关闭">
**提示原文**：「管理员关闭了新用户注册」（英文 New user registration has been disabled by administrator）或「管理员关闭了通过密码进行注册，请使用第三方账户验证的形式进行注册」（英文 Password registration has been disabled by administrator, please use third-party account verification）

**可能原因**：
- 站点未开放注册。从首页「开始使用」等入口仍可打开注册页，但提交后提示注册已关闭。
- 站点仅允许通过第三方账号注册。
- 管理员开启了自用模式，登录页不显示「注册」，从首页「开始使用」仍可打开注册页。

**处理方法**：
1. 仅关闭了密码注册时，点击注册页或登录页上的第三方账号按钮完成注册。
2. 需要账户时，请联系管理员创建。
</Accordion>

<Accordion title="提示「重置邮件已发送」，但收不到邮件">
**提示原文**：「重置邮件已发送，请检查您的收件箱」（英文 Reset email sent, please check your inbox）

**说明**：为保护账户信息，无论邮箱是否绑定了账户，页面都显示此提示。

**可能原因**：
- 该邮箱未绑定任何账户，如注册时站点未开启邮箱验证，之后也未绑定邮箱。
- 邮件被归入垃圾邮件。
- 站点未配置邮件服务，或发送失败。

**处理方法**：
1. 确认填写的是账户绑定的邮箱，并检查垃圾邮件。
2. 等待倒计时结束后重新发送；提示「Turnstile 校验失败，请刷新重试！」时，刷新页面后重新发送。
3. 能用第三方账号或 Passkey 登录时，登录后在「安全与访问」页设置密码并绑定邮箱。
4. 如仍无法解决，请联系管理员。
</Accordion>

<Accordion title="打开重置链接后提示链接无效，或链接无法打开">
**说明**：请根据提示原文或现象判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「重置链接非法或已过期」（英文 Password reset link is invalid or has expired） | 链接超过 10 分钟、已使用过，或之后又发送过新的重置邮件。 | 回到忘记密码页重新发送，使用最新邮件中的链接。 |
| 「无效的重置链接，请请求新的密码重置。」（英文 Invalid reset link, please request a new password reset.） | 链接不完整，如复制时被截断。 | 点击邮件中的「此处」，或完整复制邮件中的链接。 |
| 链接以 `http://localhost:3000` 等非本站地址开头，无法打开 | 管理员未设置站点的服务器地址。 | 将链接开头的地址替换为当前站点的网址后打开，或联系管理员。 |
</Accordion>

<Accordion title="重置后没有保存新密码">
**说明**：新密码仅在「重置密码」页显示，重置链接仅可使用一次，旧密码已失效。

**处理方法**：
1. 回到忘记密码页，重新发送重置邮件。
2. 按[重置忘记的密码](#重置忘记的密码)再次重置，并在离开页面前复制新密码。
</Accordion>
