- 从侧边栏「个人」→「钱包」进入。

<Callout type="info" title="提示">

</Callout>

## 在线充值

- 钱包-确认付款

![钱包-确认付款页面](/assets/guide/feature-guide/personal-wallet-add-funds-payment.png)

**操作流程：**
1. 在「添加资金」的「金额」中点击预设数量，或在「自定义金额」中填写数量。
2. 在「付款方式」中点击要使用的付款方式。
3. 在「确认付款」窗口中核对「充值金额」「您支付」和「付款方式」，点击「确认付款」。
4. 在打开的支付页面中完成付款。
5. 返回本站，点击「添加资金」右上角的「订单历史」，确认订单状态为「成功」。

**Creem 支付操作流程：**
1. 在「Creem 支付」区域点击要购买的产品。
2. 在「确认 Creem 购买」窗口中核对产品、价格和额度，点击确认按钮。
3. 在打开的支付页面中完成付款。

<Callout type="info" title="提示">
- 支付页面通常在新标签页中打开，浏览器拦截弹出窗口时，请允许本站弹出窗口后重试；Waffo Pancake 在当前页面跳转。
- 付款完成后返回的页面因付款方式而异，可能是钱包页或使用日志页。
- 支付平台确认付款后余额才会增加，可能有延迟。页面不会自动刷新，请稍后刷新页面或打开「订单历史」查看。
- 短时间内操作次数过多时会被暂时限制，请稍后重试。
</Callout>

<Callout type="warn" title="注意">
付款后余额长时间未增加时，请勿重复付款。请保留订单号、付款凭证和付款时间，联系管理员核对。
</Callout>

## 兑换码

「添加资金」卡片底部的「有兑换码吗？」区域用于兑换管理员发放的兑换码，兑换按钮为「兑换额度」。

**操作流程：**
1. 在「输入您的兑换码」中粘贴兑换码。
2. 点击「兑换额度」。
3. 提示「兑换成功！已添加：…」后，在「当前余额」中查看增加的额度。

<Callout type="info" title="提示">
- 请完整粘贴兑换码，前后不可带空格或换行。点击「兑换额度」后可能需要等待几秒。
- 每个兑换码仅可成功兑换一次。不存在、已使用、已过期或已禁用的兑换码均提示「兑换失败，请稍后重试」，不提示具体原因，见[常见问题](#常见问题)。
- 管理员设置了获取地址时，输入框下方显示「需要兑换码？点此获取」，点击后在新标签页打开。
- 兑换成功后，在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中产生一条「充值」记录，不出现在「计费历史」中。
</Callout>

## 查看订单历史

- 钱包-计费历史

![钱包-计费历史页面](/assets/guide/feature-guide/personal-wallet-add-funds-order-history.png)

**操作流程：**
1. 点击「添加资金」右上角的「订单历史」，打开「计费历史」窗口。
2. 在「按订单号搜索...」中填写订单号查找，或翻页查看订单。
3. 需要联系管理员核对时，点击订单号右侧的复制按钮复制订单号。

<Callout type="info" title="提示">
- 普通用户仅可查看本账户最近 30 天创建的订单，搜索仅匹配订单号。管理员可查看所有用户的订单，不限时间，每个订单另显示「用户 ID: …」（仅管理员可见）。
- 列表包含在线充值订单和通过第三方支付购买订阅的订单。用余额购买的订阅、兑换码兑换和邀请奖励转移不在此列表中。

## 订阅计划

- 钱包-购买订阅套餐

![钱包-购买订阅套餐页面](/assets/guide/feature-guide/personal-wallet-subscription-plans-subscribe-now.png)

「订阅套餐」卡片列出管理员发布的套餐，购买后获得订阅额度，卡片上方的「我的订阅」显示已购买的订阅。管理员未发布套餐且账户无订阅记录时，不显示该卡片。

**使用余额购买操作流程：**
1. 点击套餐卡底部的「立即订阅」，打开「购买订阅套餐」窗口。
2. 核对套餐名称、有效期、套餐额度和「应付金额」。
3. 确认「必需」不高于「可用」，点击「使用余额支付」。

**使用其他付款方式购买操作流程：**
1. 点击套餐卡底部的「立即订阅」，打开「购买订阅套餐」窗口。
2. 在「选择支付方式」中点击「Stripe」「Creem」或「Waffo Pancake」；使用易支付时，在下拉列表中选择付款方式后点击「支付」。
3. 在打开的支付页面中完成付款。
4. 返回钱包，点击「我的订阅」右侧的刷新图标，确认新订阅的状态为「生效」。

**查看订阅操作流程：**
1. 在「订阅套餐」卡片上方的「我的订阅」中，查看每份订阅的状态、剩余天数和额度。
2. 点击「我的订阅」右侧的刷新图标，更新订阅列表。

<Callout type="info" title="提示">
- 使用余额支付时立即创建订阅，从「当前余额」中扣除「必需」所示的额度，并在使用日志中产生一条「充值」记录。
- 使用其他付款方式时，支付平台确认付款后才创建订阅，订单出现在「计费历史」中。
- 「使用余额支付」不可点击的原因：余额不足（显示「余额不足」）、该套餐不允许使用余额支付（显示「该套餐不允许使用余额兑换」），或已达到限购次数（显示「已达到购买上限 (…)」）。
- 「选择支付方式」中仅显示管理员为该套餐配置的付款方式，无可用方式时不显示该区域，仅可使用余额支付。
</Callout>

<Callout type="warn" title="注意">
- 订阅到期后不会自动续订，需要继续使用时请重新购买。
- 通过 Stripe 购买的套餐，Stripe 会按周期自动续费扣款，直到订阅被取消；这些续费扣款不会在 New API 中创建或延长订阅，订阅仍按套餐的有效期到期。如需停止后续扣款，请联系管理员。
</Callout>

<Callout type="info" title="订阅与分组">
- 套餐设置了「升级分组」时，购买成功后账户立即切换到该分组。
- 订阅到期或被管理员作废后：账户还有其他生效且设置了升级分组的订阅时，分组不变；否则，套餐设置了降级分组时切换到降级分组；未设置时，仅当账户仍在该升级分组中，才恢复购买前的分组。
- 到期后状态和分组的变化可能延迟约 1 分钟。
</Callout>

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="付款后余额未增加">
**说明**：支付平台通知站点付款成功后，余额才会增加，订单状态随之变为「成功」。

**可能原因**：
- 支付平台的通知尚未送达，或有延迟。
- 付款未完成或失败，订单仍显示「待确认」。
- 站点的支付配置有误，通知无法送达。

**处理方法**：
1. 请勿重复付款。
2. 稍后刷新页面，点击「订单历史」查看订单状态。
3. 订单长时间仍为「待确认」时，复制订单号，连同付款凭证和付款时间发给管理员核对。
</Accordion>

<Accordion title="点击付款方式后提示「支付请求失败」或支付页面未打开">
**说明**：请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「支付请求失败」（英文 Payment request failed） | 网络中断、服务端出错，或浏览器拦截了新标签页。 | 允许本站弹出窗口后重试；如仍失败，请联系管理员。 |
| 「当前管理员未配置支付信息」（英文 Payment information has not been configured by administrator） | 该付款方式的配置不完整。 | 改用其他付款方式，或联系管理员。 |
| 「支付方式不存在」（英文 Payment method does not exist） | 所选付款方式已被管理员移除，或不适用于当前操作。 | 刷新页面后重新选择付款方式。 |
| 「拉起支付失败」（英文 Failed to start payment）<br/>「创建订单失败」（英文 Failed to create order） | 支付平台或服务端出错。 | 稍后重试；如仍失败，请联系管理员。 |
</Accordion>

<Accordion title="付款方式置灰，或提示「充值数量不能小于 …」">

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |

<Accordion title="兑换时提示「兑换失败，请稍后重试」">
**提示原文**：「兑换失败，请稍后重试」（英文 Redemption failed, please try again later）

**可能原因**：
- 兑换码不存在、已被使用、已过期或已被禁用，提示不区分具体原因。
- 粘贴时带了空格或换行。

**处理方法**：
1. 重新复制完整的兑换码，确认前后无空格或换行后重试。
2. 如仍失败，请向发放兑换码的管理员确认兑换码状态。请勿连续多次尝试，操作过多时会被暂时限制。

**提示原文**：「充值处理中，请稍后重试」（英文 Top-up is processing, please try again later）

**可能原因**：本账户的上一次兑换仍在处理中。

**处理方法**：
1. 等待几秒，查看「当前余额」是否已增加。
2. 未增加时再点击一次「兑换额度」，请勿连续点击。
</Accordion>

**可能原因**：
- 套餐未设置「升级分组」，或购买前账户已在该分组中。
- 使用其他付款方式时，支付平台尚未确认付款，订阅还未创建。
- 到期后，账户还有其他生效且设置了升级分组的订阅；或套餐未设置降级分组，且账户的分组已被修改。
- 到期处理有约 1 分钟的延迟。

**处理方法**：
1. 在「我的订阅」中确认订阅的状态。
2. 等待几分钟后刷新页面。
3. 如仍不符合预期，请联系管理员。
</Accordion>

<Accordion title="订阅额度用完后调用失败">
**说明**：计费偏好为「仅用订阅」且无生效订阅时，「我的订阅」中显示「已保存偏好为…，当前无生效订阅，请求将被拒绝」（英文 Preference saved as …, but no active subscription. Requests will be rejected.）；订阅仍生效但额度不足时不显示该提示。

**可能原因**：
- 计费偏好为「仅用订阅」，订阅已到期或额度已用完。
- 计费偏好为「优先订阅」，但有一份生效订阅的套餐不允许额度用尽后使用钱包余额。

**处理方法**：
1. 将计费偏好改为「优先钱包」或「仅用钱包」。
2. 需要继续使用订阅额度时，重新购买订阅套餐。
</Accordion>

<Accordion title="通过 Stripe 购买的套餐到期后仍被扣款">
**说明**：Stripe 会按周期自动续费扣款，直到订阅被取消；续费扣款不会在 New API 中创建或延长订阅。

**处理方法**：
1. 保留扣款记录，联系管理员取消后续扣款，并核对已扣款项的处理方式。
</Accordion>

<Accordion title="邀请奖励无法使用，或「转移」不可点击">
**说明**：请根据现象或提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「待确认」有金额，但调用时提示额度不足 | 邀请奖励需先转移到余额。 | 点击「转移到余额」。 |
| 「转移」置灰，输入框下方显示「最低：…」 | 「可用奖励」不足 1 个额度单位，或「转移金额」超出范围。 | 调整「转移金额」；奖励不足时等待累计。 |
| 「转移额度最小为…！」（英文 Minimum transfer quota is …!） | 转移数量低于 1 个额度单位。 | 调高「转移金额」。 |
| 「邀请额度不足！」（英文 Invitation quota is insufficient!） | 转移数量超过「待确认」。 | 调低「转移金额」。 |
</Accordion>

<Accordion title="邀请的用户注册后未获得奖励">
**可能原因**：
- 管理员未设置邀请奖励额度（默认不发放），或尚未确认支付合规条款。
- 被邀请人未通过邀请链接打开注册页，或通过微信登录创建账户。
- 被邀请人注册前已有账户。
- 邀请人的奖励在「待确认」中，尚未转移到余额。

**处理方法**：
1. 在「推荐计划」中查看「邀请」人数和「待确认」。
2. 「邀请」人数未增加时，请联系管理员确认邀请奖励设置。
</Accordion>

<Accordion title="「计费历史」中找不到某笔记录">
**可能原因**：
- 普通用户仅可查看最近 30 天创建的订单。
- 用余额购买的订阅、兑换码兑换和邀请奖励转移不产生订单。
- 搜索仅匹配订单号。

**处理方法**：
1. 清空搜索框后翻页查找。
2. 兑换码兑换和用余额购买订阅的记录，在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中将类型选择为「充值」查看。
3. 订阅以「我的订阅」中的显示为准。
</Accordion>

</Accordions>
