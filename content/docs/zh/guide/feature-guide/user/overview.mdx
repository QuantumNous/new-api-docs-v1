## 按设置引导开始使用

**操作流程：**
1. 点击步骤「1. 创建 API 密钥」，在「API 密钥」页创建密钥。
2. 点击步骤「2. 添加额度」，在「钱包」页充值或兑换额度。
3. 点击步骤「3. 发送请求」，在「游乐场」中发送一条消息；也可复制「首个 API 请求」中的命令，在终端中运行。
4. 返回「概览」页，刷新浏览器页面，查看各步骤是否显示绿色对勾。
5. 不需要设置引导时，点击右上角「隐藏设置引导」。

<Callout type="info" title="提示">
- 步骤是否完成取自登录时获取的账户信息，完成操作后请刷新浏览器页面。
- 展开或收起的选择保存在当前浏览器中，之后不再随完成情况自动变化。
- 收起后：未全部完成时显示一行「设置进度：…/3」，点击「显示设置引导」重新展开；全部完成时，点击页面标题右侧的「设置引导」重新展开。
</Callout>

**步骤说明：**

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 步骤 | 说明 | 完成条件 | 点击后打开 |
| --- | --- | --- | --- |
| 1. 创建 API 密钥 | 「为你的应用或服务创建密钥」 | 账户中至少有一个 API 密钥，已禁用、已过期的密钥也计入。 | 「API 密钥」页 |
| 2. 添加额度 | 「生产流量前保持充足余额」 | 钱包余额大于 0，或账户曾消耗过额度。注册时获得赠送额度的账户，该步骤一开始即为完成。 | 「钱包」页 |
| 3. 发送请求 | 「使用 Playground 或你的客户端验证路由」 | 账户至少有一次成功的调用，失败的调用不计入。 | 「游乐场」页；管理员关闭游乐场时回到「概览」页 |
</div>

## 复制示例命令发送第一个请求

**操作流程：**
1. 账户尚无 API 密钥时，点击「首个 API 请求」右上角「创建 API 密钥」，创建密钥后返回「概览」页。
2. 点击「首个 API 请求」右上角「复制」。
3. 在终端中粘贴并运行命令。

<Callout type="warn" title="注意保管密钥">
复制的命令包含完整的 API 密钥，请勿发送到聊天群，或包含在截图、公开的代码仓库中。
</Callout>

<Callout type="info" title="提示">
- 命令适用于 macOS、Linux 终端和 Windows 的 Git Bash。
- 「复制」会读取完整密钥，与在「API 密钥」页查看完整密钥一样受频率限制，审计日志中记为「查看 API 令牌「…」的密钥」。
- 需要使用其他密钥或模型时，请在「API 密钥」页复制密钥和 API 地址，调用方式见 <a href="/zh/docs/guide/feature-guide/user/token#复制密钥并调用模型" target="_blank" rel="noopener noreferrer">API 密钥</a>。
</Callout>

**命令说明：**

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 组成部分 | 取值 | 备注 |
| --- | --- | --- |
| 请求地址 | 「API 信息」中第 1 条地址加 `/v1/chat/completions`；管理员未配置或关闭 API 信息时，为当前浏览器访问的站点地址加 `/v1/chat/completions`。 | 「路由已启用」显示「在线」表示使用了 API 信息中的地址，显示「当前域名」表示使用当前站点地址。「在线」不表示已检测该地址可以访问。 |
| API 密钥 | 「API 密钥」列表中排在最前的已启用密钥；无已启用的密钥时，为排在最前的密钥。 | 卡片副标题显示该密钥的名称，命令中仅显示密钥首尾几位，点击「复制」后才复制完整密钥。「认证已配置」显示「已保护」表示已有密钥，「需要 API 密钥」表示尚未创建。卡片中不可选择其他密钥。 |
| 模型 | 账户可用模型中的第一个。 | 显示在「已选择模型」中。未获取到可用模型时，「已选择模型」显示「加载中」，命令中的模型为 gpt-4o-mini。 |
| 请求内容 | 一条英文对话消息，使用 ChatCompletions 格式。 | 其他参数见 <a href="/zh/docs/api/ai-model/chat/openai/createchatcompletion" target="_blank" rel="noopener noreferrer">ChatCompletions 格式</a>。 |
</div>

## 查看额度和用量

**操作流程：**
1. 在「用量概览」中查看当前账户最近一天的消耗、累计消耗和累计调用次数。
2. 在右侧「剩余额度」中查看钱包余额、余额状态和「可用时长」。
3. 余额不足时，点击「钱包」充值或兑换额度。

<Callout type="info" title="提示">
- 「剩余额度」「历史使用情况」「请求计数」取自登录时获取的账户信息，在其他页面充值或调用后不会立即更新，刷新浏览器页面后显示最新数值。
- 「剩余额度」仅为钱包余额，订阅的剩余额度在<a href="/zh/docs/guide/feature-guide/user/wallet#订阅计划" target="_blank" rel="noopener noreferrer">钱包</a>页的「我的订阅」中查看。
- 「近 24 小时消耗」与<a href="/zh/docs/guide/feature-guide/user/dashboard" target="_blank" rel="noopener noreferrer">数据看板</a>使用同一份汇总数据，新的调用通常几分钟后计入（默认每 5 分钟汇总一次）。
</Callout>

**统计项说明：**

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 统计项 | 定义 | 统计范围 | 备注 |
| --- | --- | --- | --- |
| 近 24 小时消耗 | 当前账户最近一天消耗的额度。 | 按整点小时汇总，包含当前小时和之前的 22 个小时，略短于 24 小时；含钱包余额和订阅额度支付的消耗。管理员关闭数据看板的统计后不再增加。 | 下方显示「近 24 小时消耗量」，按货币显示时后接单位，如「(USD)」。卡片底部的折线为这段时间的消耗变化。「剩余额度」中的「近 24 小时消耗」与此相同。 |
| 历史使用情况 | 当前账户累计消耗的额度。 | 自账户创建起，含钱包余额和订阅额度支付的消耗。 | 下方显示「总消耗 (…)」，额度按 Token 显示时为「总消耗额度」。卡片底部的折线为最近一天的消耗变化，不是累计走势。 |
| 请求计数 | 当前账户累计成功的调用次数。 | 自账户创建起，失败的调用不计入。 | 下方显示「总请求数」。卡片底部的折线为最近一天的调用次数变化。 |
| 剩余额度 | 当前账户的钱包余额。 | 不含订阅额度。 | 右上角显示余额状态，见[余额状态](#余额状态)。 |
| 可用时长 | 按最近一天的消耗速度估算的余额可用天数，即「剩余额度」除以「近 24 小时消耗」。 | 与「剩余额度」「近 24 小时消耗」相同。 | 显示「~… 天」（向下取整）、「999+ 天」或「剩余不足 1 天」；钱包余额不大于 0 时显示「余额已耗尽」；最近一天无消耗时显示「暂无使用记录」。 |
</div>

## 查看公告、API 信息、常见问答和运行时间

**查看公告操作流程：**
1. 点击「公告」中的一条公告。
2. 在「公告详情」窗口中查看「内容」；有附加信息时，下方显示「附加信息」。

**测试 API 地址延迟操作流程：**
1. 点击「API 信息」中地址右侧的闪电图标（鼠标悬停显示「测试延迟」）。
2. 查看图标左侧显示的耗时，如「120毫秒」，颜色的含义见 [API 地址延迟](#api-地址延迟)。

**查看运行时间操作流程：**
1. 在「运行时间」中按分组查看各监控项的圆点颜色和近 24 小时在线率。
2. 需要最新状态时，点击面板右上角的刷新图标。

<Callout type="info" title="提示">
- 四个面板的内容由管理员在<a href="/zh/docs/guide/feature-guide/system-settings/settings-content" target="_blank" rel="noopener noreferrer">控制台内容配置</a>中设置，管理员修改后，可能需要几分钟或刷新浏览器页面后才显示。
- 「测试延迟」测量的是浏览器到该地址的往返时间，不代表模型的响应速度。「外部速度测试」在新标签页中打开第三方测速网站。
</Callout>

## 状态项说明

### 余额状态

「剩余额度」右上角显示的三种状态：

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 状态 | 含义 | 备注 |
| --- | --- | --- |
| 正常 | 钱包余额大于 0，且按最近一天的消耗估算可用 3 天及以上，或最近一天无消耗。 | 绿色圆点。 |
| 余额偏低 | 钱包余额大于 0，但按最近一天的消耗估算可用不足 3 天。 | 黄色圆点，「可用时长」以黄色显示。3 天为固定值，与「个人资料」中的「余额不足提醒」无关。请前往钱包充值。 |
| 余额已耗尽 | 钱包余额不大于 0。 | 红色圆点，「可用时长」以红色显示。不含订阅额度：有生效的订阅时，调用仍可按计费偏好从订阅额度中扣除。 |
</div>

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="「设置引导」一直显示，或收起后找不到">
**可能原因**：
- 三个步骤未全部完成，设置引导自动展开。
- 曾手动展开过设置引导，浏览器记住了该选择，全部完成后也不会自动收起。
- 全部完成后设置引导自动收起，页面上只在标题右侧显示「设置引导」按钮。

**处理方法**：
1. 不需要时，点击设置引导右上角「隐藏设置引导」。
2. 需要重新查看时，点击页面标题右侧的「设置引导」，或收起后一行中的「显示设置引导」。
</Accordion>

<Accordion title="充值或调用后数值没有变化，或步骤未显示对勾">
**可能原因**：
- 「剩余额度」「历史使用情况」「请求计数」和步骤是否完成，取自登录时获取的账户信息，在其他页面操作后不会立即更新。
- 「3. 发送请求」仅计入成功的调用，调用失败时不显示对勾。
- 「近 24 小时消耗」需要几分钟后才计入新的调用。

**处理方法**：
1. 刷新浏览器页面。
2. 在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中确认是否有该次调用的「消耗」记录，或充值的「充值」记录。
3. 如仍不一致，请联系管理员。
</Accordion>

<Accordion title="「近 24 小时消耗」为 0，或与使用日志不一致">
**可能原因**：
- 新的调用通常几分钟后才计入（默认每 5 分钟汇总一次）。
- 按整点小时汇总，统计范围略短于 24 小时，与使用日志逐条统计的结果不同。
- 管理员未开启或关闭了数据看板的统计，「近 24 小时消耗」不再增加，「可用时长」显示「暂无使用记录」；「历史使用情况」「请求计数」不受影响。

**处理方法**：
1. 等待几分钟后刷新浏览器页面。
2. 在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中选择相同的时间段，以「消耗」记录为准核对。
3. 长时间为 0 时，请联系管理员确认站点已开启数据看板的统计。
</Accordion>

<Accordion title="显示「余额已耗尽」，但仍可正常调用">
**说明**：「剩余额度」和余额状态仅按钱包余额计算，不含订阅额度；「历史使用情况」「近 24 小时消耗」则包含订阅额度支付的消耗。钱包余额不大于 0 时显示「余额已耗尽」，有生效的订阅时，调用仍按计费偏好从订阅额度中扣除。

**处理方法**：
1. 在<a href="/zh/docs/guide/feature-guide/user/wallet#订阅计划" target="_blank" rel="noopener noreferrer">钱包</a>页的「我的订阅」中查看订阅的剩余额度。
2. 需要使用钱包余额调用时，请充值或兑换额度。
</Accordion>

<Accordion title="运行示例命令时报错">
**说明**：命令使用「API 密钥」列表中排在最前的已启用密钥和账户可用模型中的第一个，调用失败的原因与其他客户端相同。「已选择模型」显示「加载中」时，表示未获取到可用模型，命令中的 gpt-4o-mini 不一定可用。请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「无效的令牌」（英文 Invalid token） | 密钥已禁用、已过期或额度已用尽。 | 在「API 密钥」页检查该密钥，见 <a href="/zh/docs/guide/feature-guide/user/token#api-密钥状态" target="_blank" rel="noopener noreferrer">API 密钥状态</a>。 |
| 「该令牌无权访问模型 …」（英文 This token has no access to model …） | 该密钥设置了「模型限制」，不含命令中的模型。 | 将命令中的模型改为该密钥可用的模型，或编辑该密钥的「模型限制」。 |
| 「用户额度不足」（英文 Insufficient user quota） | 账户余额不足。 | 前往<a href="/zh/docs/guide/feature-guide/user/wallet" target="_blank" rel="noopener noreferrer">钱包</a>充值或兑换。 |
| 连接失败或超时，无提示原文 | 命令中的请求地址无法从当前设备访问。 | 在「API 密钥」页右上角「API 地址」中复制可用的地址，替换命令中的地址。 |
</Accordion>

<Accordion title="点击「复制」后提示失败">
**提示原文**：「复制到剪贴板失败」（英文 Failed to copy to clipboard），或服务端返回的原因。

**可能原因**：
- 浏览器禁止网页写入剪贴板。
- 短时间内查看或复制完整密钥的次数过多。
- 网络中断或登录已过期。

**处理方法**：
1. 允许浏览器访问剪贴板后重试。
2. 等待一段时间（可能长达十几分钟）后重试。
3. 如仍失败，请在「API 密钥」页复制密钥，按 <a href="/zh/docs/guide/feature-guide/user/token#复制密钥并调用模型" target="_blank" rel="noopener noreferrer">API 密钥</a>中的调用方式填写命令。
</Accordion>

<Accordion title="看不到公告、API 信息、常见问答或运行时间">
**可能原因**：
- 管理员关闭了该面板。
- 管理员未配置内容，面板中显示「目前暂无公告」「未配置 API 路由」「暂无 FAQ 条目」或「未配置正常运行时间监控」。
- 管理员刚修改了内容，页面几分钟后才更新。
- 站点无法获取监控状态时，「运行时间」同样显示「未配置正常运行时间监控」，或分组下不显示监控项。

**处理方法**：
1. 刷新浏览器页面。
2. 如仍不显示，请联系管理员。
</Accordion>

<Accordion title="点击「3. 发送请求」后回到了「概览」页">
**可能原因**：管理员关闭了「游乐场」。

**处理方法**：
1. 复制「首个 API 请求」中的命令在终端中运行，或使用其他客户端调用。
2. 需要使用游乐场时，请联系管理员。
</Accordion>

<Accordion title="审计日志中出现「查看 API 令牌「…」的密钥」记录">
**说明**：点击「首个 API 请求」中的「复制」会读取完整的 API 密钥，审计日志中记为「查看 API 令牌「…」的密钥」，属于正常记录。

**处理方法**：
1. 核对该记录的时间、IP 和客户端是否为本人操作。
2. 不是本人操作时，请按<a href="/zh/docs/guide/feature-guide/user/audit-log" target="_blank" rel="noopener noreferrer">审计日志</a>常见问题中的方法处理。
</Accordion>
