- 从侧边栏「常规」→「数据看板」进入。
- 按时间范围查看模型的调用次数、Token 和额度消耗，以及调用的分流情况。
- 数据按整点小时汇总，新的调用通常几分钟后显示。

<Callout type="info" title="提示">
- 页面标题显示为当前标签的名称，从侧边栏进入时为「模型调用分析」。
- 普通用户仅可查看本账户的数据。管理员查看的是全站所有用户的数据，可在「筛选」中按用户名查看单个用户（仅管理员可见）。
- 仅在管理员开启数据看板的统计后有数据，开启前或关闭期间的调用不会补录。看板数据不会自动清理，清理历史日志不影响看板。
- 数据看板的统计在「系统设置」→「控制台内容」→「数据仪表板」（仅 Root 可见）中设置：「启用数据仪表板」控制是否记录新的调用，「刷新间隔 (分钟)」控制新的调用每隔多久汇总一次，默认 5 分钟，见<a href="/zh/docs/guide/feature-guide/system-settings/settings-content#数据仪表板" target="_blank" rel="noopener noreferrer">控制台内容配置</a>。
- 额度的单位由站点决定，金额按站点的货币显示方式显示。
- 左侧边栏无「数据看板」页时：<br/>到「个人资料」页的「左侧边栏个人设置」区域中，开启「控制台区域」和「数据看板」并保存。「数据看板」开关同时控制「概览」和「数据看板」两个入口。
</Callout>

## 筛选数据

- 数据看板-模型分析筛选

![数据看板-模型分析筛选页面](/assets/guide/feature-guide/general-dashboard-filters.png)

**操作流程：**
1. 在「模型调用分析」或「分流」标签中，点击页面右上角「筛选」。
2. 在「快速范围」中点击「1 天」「7 天」「14 天」或「29 天」，或在「自定义时间范围」中设置「起始时间」「结束时间」。
3. 按需在「时间粒度」中选择「小时」「天」或「本周」。
4. 管理员查看单个用户时，在「用户名」中填写完整的用户名（仅管理员可见）。
5. 点击「应用筛选器」。
6. 需要恢复默认条件时，点击「重置」。

<Callout type="info" title="提示">
- 「模型调用分析」「分流」共用筛选条件，切换标签后仍然生效；刷新浏览器页面后恢复为「偏好设置」中的默认值。
- 时间范围从打开页面的时刻往前计算，如「1 天」为之前的 24 小时。页面不会自动刷新，查看最新数据请点击「重置」或刷新浏览器页面。
- 「分流」标签中的筛选窗口标题为「分流筛选」，内容相同。分流图按整个时间范围汇总，「时间粒度」对分流图无影响。
</Callout>

## 查看模型调用分析

**操作流程：**
1. 点击「模型调用分析」标签。
2. 在统计卡中查看所选时间范围内的合计和平均值。
3. 在「消耗分布」右上角选择「柱状图」或「面积图」，查看各模型的额度消耗。
4. 在「模型调用分析」图表右上角选择「调用趋势」「调用次数分布」或「调用次数排行」。
5. 鼠标悬停在图表上查看具体数值；点击图例中的模型名称，图表仅显示该模型。

<Callout type="info" title="提示">
- 管理员看到的是全站所有用户的合计，普通用户仅为本账户的数据。
- 统计卡和图表仅统计「消耗」记录，不含「错误」「退款」「充值」等记录。
</Callout>

## 查看分流

- 数据看板-分流

![数据看板-分流页面](/assets/guide/feature-guide/general-dashboard-routing.png)

分流图从左到右展示调用依次经过的环节：每一列是一个环节，每个方块是该环节中的一个对象，两列之间的连线越粗，表示经过该路径的额度、Token 或调用次数越多。

**操作流程：**
1. 点击「分流」标签。
2. 在「连线粗细」中选择「按额度」「按 Token」或「按请求数」。
3. 从左到右查看各列，鼠标悬停在连线上，查看该路径的额度、Token、请求数和「占比」。
4. 点击某个方块或连线，突出显示经过它的所有路径；再次点击或点击空白处取消。
5. 需要只看部分对象时，在「节点筛选」中选择，或点击图表右上方的列名隐藏该列。
6. 截图或共享屏幕前，点击页面右上角的眼睛图标「隐藏敏感数据」。

<Callout type="info" title="提示">
- 「占比」为该连线的数值占所选时间范围内总量的比例。
- 分流图按整个时间范围汇总，不按时间展开。
- 分流图仅统计记录了分组的调用。站点开始记录分流数据之前的调用不在分流图中，但仍计入「模型调用分析」。
</Callout>

**列说明：**

各角色看到的列不同，从左到右依次为：
- 普通用户：令牌 → 分组 → 模型。
- 管理员：用户 → 分组 → 模型 → 渠道，截图为此视图。
- Root：用户 → 节点 → 令牌 → 分组 → 模型 → 渠道。

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 列 | 含义 |
| --- | --- |
| 用户（仅管理员可见） | 发起调用的用户。 |
| 节点（仅 Root 可见） | 处理调用的部署节点。 |
| 令牌 | 调用使用的 API 密钥，显示密钥名称；已删除的密钥显示「已删除(…)」。 |
| 分组 | 调用使用的分组。 |
| 模型 | 调用的模型。 |
| 渠道（仅管理员可见） | 处理调用的上游渠道。 |
</div>

## 查看用户统计

- 数据看板-用户统计

![数据看板-用户统计页面](/assets/guide/feature-guide/general-dashboard-user-statistics.png)

「用户统计」标签（仅管理员可见）按用户汇总全站的额度消耗，不受「筛选」中的条件影响。

**操作流程：**
1. 点击「用户统计」标签。
2. 点击时间范围「1 天」「7 天」「14 天」或「29 天」。
3. 点击时间粒度「小时」「天」或「本周」。
4. 在「热门用户」中选择「前 5」「前 10」「前 20」或「前 50」。
5. 在「用户消耗排行」「用户消耗趋势」中查看各用户的额度消耗。

<Callout type="info" title="提示">
- 切换时间粒度时，时间范围恢复为该粒度的默认范围（「小时」1 天、「天」7 天、「本周」29 天），并同时保存为「偏好设置」中的「默认时间粒度」。
- 两张图只统计额度，不含调用次数和 Token。「总计：」为所显示用户的合计，不是全站的总额。
</Callout>

**图表说明：**

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 图表 | 内容 | 阅读提示 |
| --- | --- | --- |
| 用户消耗排行 | 所选时间范围内额度消耗最多的用户（横向柱状图）。 | 显示的用户数由「热门用户」决定。 |
| 用户消耗趋势 | 这些用户的额度消耗随时间的变化（面积图）。 | 不显示其他用户，也不合并为「其他」。 |

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="图表为空，统计卡显示 0 或「--」">
**可能原因**：
- 所选时间范围内没有调用。
- 新的调用尚未汇总，通常几分钟后显示（默认每 5 分钟汇总一次）。
- 管理员未开启或关闭了数据看板的统计，开启前和关闭期间的调用不会补录。
- 管理员关闭了「记录配额使用量」，调用不再产生「消耗」记录。
- 普通用户选择的时间跨度超过上限（默认 365 天），此时统计卡显示 0，不另行提示。
- 统计卡显示「--」表示数据加载失败，如网络中断。

**处理方法**：
1. 点击「筛选」，选择「1 天」后点击「应用筛选器」。
2. 等待几分钟后刷新浏览器页面。
3. 如仍为空，请联系管理员确认站点已开启数据看板的统计。
</Accordion>

<Accordion title="数据看板与使用日志的数据不一致">
**说明**：数据看板按整点小时汇总，使用日志逐条记录，两者的统计方式不同。

**可能原因**：
- 起始时间不在整点时，起始时间所在的那一小时不计入数据看板。
- 最近几分钟的调用尚未汇总。
- 数据看板仅统计「消耗」记录，不含「错误」「退款」「充值」等记录，退款不会从数据看板中扣除。
- 管理员开启数据看板的统计之前的调用不在数据看板中；使用日志被清理后，数据看板仍保留当时的汇总。
- 管理员在数据看板中默认查看全站数据，而使用日志可能选择了「仅自己」或设置了其他筛选条件。

**处理方法**：
1. 将两边的时间范围设为相同的整点，如 08:00 至 10:00。
2. 核对扣费明细时，以<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>为准。
</Accordion>

<Accordion title="「缓存读取」「缓存写入」为 0">
**可能原因**：
- 所选时间段在站点开始记录缓存用量之前。
- 调用的模型或上游未返回缓存信息，或未命中缓存。
- 视频、音乐等异步任务不统计 Token。

**处理方法**：
1. 选择最近的时间范围后重新查看。
2. 单次调用的缓存用量可在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>的「Token」列中查看。
</Accordion>

<Accordion title="「分流」显示「暂无分流数据」或缺少较早的调用">
**提示原文**：「暂无分流数据」（英文 No flow data available）

**可能原因**：
- 所选时间范围内没有调用。
- 分流图仅统计记录了分组的调用，站点开始记录分流数据之前的调用不显示。
- 「节点筛选」或「用户」中选择的对象在所选时间范围内没有调用。

**处理方法**：
1. 在「筛选」中选择最近的时间范围。
2. 在「节点筛选」中点击「清空」。
</Accordion>

<Accordion title="「分流」提示「加载失败」">
**提示原文**：「加载失败」（英文 Failed to load），下方显示原因，如「时间跨度不能超过 … 天」（英文 The time range cannot exceed … days）

**可能原因**：
- 普通用户选择的时间跨度超过上限（默认 365 天）。
- 网络中断或服务端出错。

**处理方法**：
1. 缩小时间范围后重试。
2. 刷新浏览器页面。
3. 如仍失败，请联系管理员。
</Accordion>

<Accordion title="分流图中的名称显示为 ••••">
**可能原因**：开启了「隐藏敏感数据」。

**处理方法**：
1. 点击页面右上角的眼睛图标「显示敏感数据」。
</Accordion>

<Accordion title="选择「本周」后，各点的日期区间相互重叠">
**说明**：选择「本周」时，每个点的标签为 7 天的日期区间，但数据为标签起始日当天的合计，因此相邻的点区间重叠。

**处理方法**：
1. 需要按天查看时，将「时间粒度」改为「天」。
2. 需要某一周的合计时，将时间范围设为该周，查看统计卡中的合计。
</Accordion>

<Accordion title="看不到「用户统计」标签、「性能健康」或「用户名」筛选">
**说明**：这些内容仅管理员可见。普通用户的数据看板仅显示本账户的数据，标签为「模型调用分析」「分流」。
</Accordion>

<Accordion title="「偏好设置」没有保留">
**可能原因**：
- 偏好保存在浏览器中，更换浏览器、设备或清除浏览器数据后恢复默认。
- 管理员在「用户统计」中切换时间粒度，会同时修改「默认时间粒度」。

**处理方法**：
1. 在当前浏览器中重新设置，点击「保存偏好设置」。
</Accordion>

</Accordions>
