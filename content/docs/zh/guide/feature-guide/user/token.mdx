<Callout type="info" title="提示">

## 创建 API 密钥

- API 密钥-创建 API 密钥

![API 密钥-创建 API 密钥页面](/assets/guide/feature-guide/general-api-key-create.png)

**操作流程：**
1. 点击页面右上角「创建 API 密钥」。
2. 填写密钥名称，便于区分应用或环境。
3. 按需设置额度、过期时间、模型限制、IP 限制和分组等配置信息。
4. 点击「保存更改」。

**配置项说明：**

窗口分「基本信息」「额度设置」「高级设置」三个区域，「高级设置」默认折叠，点击标题展开。下表按窗口中的顺序排列。

<div id="创建配置项说明" className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 配置项 | 所属区域 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- | --- |
| 名称 | 基本信息 | 密钥的名称，用于区分密钥的用途或使用环境。 | 必填，建议注明使用该密钥的应用或环境。最长 50 个英文字符或约 16 个汉字，超出时提示「令牌名称过长」。 | 空 |
| 分组 | 基本信息 | 调用时使用的分组，决定可用的线路和计费倍率。 | 选填。下拉列表仅列出账户有权使用的分组，每个分组附有说明和倍率；选择 auto 时，由系统自动选择可用分组。 | 未选择（显示「选择一个分组」），即使用账户所在的分组。部分站点默认选择 auto。 |
| 自动分组顺序 | 基本信息 | 使用 auto 分组时，该密钥依次尝试的分组及顺序。 | 「分组」选择 auto 时显示。可保持默认，也可点击「添加 Auto 分组」并拖动调整顺序。自定义时至少选择 1 个分组且不可重复，数量上限以窗口提示为准（默认 5 个）。 | 「继承全局 Auto 顺序」 |
| 跨分组重试 | 基本信息 | 当前分组调用失败时，是否按顺序改用下一个分组重试。 | 「分组」选择 auto 时显示，按需开启或关闭，仅对 auto 分组生效。说明末尾的「请求策略」链接（仅 Root 可见）指向站点的相关系统设置。 | 选择 auto 时自动开启 |
| 过期时间 | 基本信息 | 密钥的失效时间。 | 选填。可直接选择日期和时间，或点击「永不」「1 个月」「1 天」「1 小时」，后三项从当前时间起计算。系统不校验所选时间是否已过，选择过去的时间会导致密钥保存后无法调用。 | 空，即「永不过期」 |
| 数量 | 基本信息 | 一次创建的密钥数量。 | 仅在创建时显示，最小为 1。创建多个密钥时，第一个使用所填名称，其余在名称后追加 7 个字符的随机后缀，追加后的名称同样受名称长度限制；创建中途失败时停止，已创建的密钥保留。每个账户的密钥总数有上限（默认 1000 个），超出时提示「已达到最大令牌数量限制 (…)」。 | 1 |
| 额度 (…) | 额度设置 | 该密钥可使用的额度上限。括号内为站点的额度单位，如「额度 ($)」。 | 关闭「无限配额」后显示，填写数值，不可为负数；超过最大值时提示「额度值超出有效范围，最大值为 …」。额度用尽后，该密钥无法调用。 | 10 |
| 无限配额 | 额度设置 | 是否取消该密钥自身的用量上限。 | 按需开启或关闭，关闭后在上方显示「额度」输入框。仅取消密钥自身的上限，调用时仍从账户额度中扣除；账户额度不足时，调用仍会失败。 | 开启 |
| 模型限制 | 高级设置 | 该密钥可调用的模型范围。 | 选填，可多选，候选列表仅包含账户可用的模型。未选择时可调用所有可用模型。 | 未选择，即不限制 |
| IP 白名单（支持 CIDR 表达式） | 高级设置 | 允许使用该密钥的 IP 地址或网段。 | 选填。每行填写一个 IP 地址或 CIDR 网段，如 192.168.1.0/24，不支持用逗号分隔；留空表示不限制。格式错误的行会被忽略，所有行均无效时，任何地址都无法使用该密钥。IP 地址可能被伪造，不建议将其作为唯一的安全措施。 | 空，即不限制 |
| 允许查询用户额度 | 高级设置 | 使用该密钥调用<a href="/zh/docs/api/management/token-management/usage-token-get" target="_blank" rel="noopener noreferrer">获取令牌使用情况</a>接口时，是否同时返回账户的剩余额度和已用额度。 | 按需开启或关闭，不影响模型调用。 | 开启 |
</div>

## 复制密钥并调用模型

**操作流程：**
1. 点击密钥所在行「API 密钥」列中密钥右侧的复制按钮。
2. 将密钥粘贴填写到客户端中。
3. 点击页面右上角「API 地址」。
4. 按地址说明选择需要的 API 地址，点击地址右侧的复制按钮。
5. 将 API 地址粘贴填写到客户端中。

**调用方式：**
1. 客户端：API 地址通常不带 `/v1`，多数 OpenAI 兼容客户端的 Base URL 需填写 API 地址加 `/v1`，以客户端说明为准。
2. 请求：请求地址为 API 地址加接口路径，例如聊天接口为 API 地址加 `/v1/chat/completions`，示例如下。

```bash
curl https://your-host/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{"model":"模型名称","messages":[{"role":"user","content":"你好"}]}'
```

- 将 `https://your-host` 替换为复制的 API 地址，`sk-xxxxxxxx` 替换为 API 密钥，`模型名称` 替换为可用的模型名称。<br/>该命令适用于 macOS、Linux 终端和 Windows 的 Git Bash。
- 可请求 API 地址加 `/v1/models`，获取该密钥可用模型信息：<br/>见<a href="/zh/docs/api/ai-model/models/list/listmodels" target="_blank" rel="noopener noreferrer">列出模型（原生 OpenAI 格式）</a>。其他接口和参数见 <a href="/zh/docs/api/ai-model/chat/openai/createchatcompletion" target="_blank" rel="noopener noreferrer">ChatCompletions 格式</a> 等 API 文档。

<Callout type="warn" title="注意保管密钥">
  - 获得 API 密钥的任何人都可以用它消耗账户额度。
  - 请勿将密钥发送到聊天群，或包含在截图、公开的代码仓库中。
  - 怀疑密钥泄露时，请立即删除该密钥并重新创建。
</Callout>

## 导入到 CC Switch 或聊天应用

- API 密钥-填入 CC Switch

![API 密钥-填入 CC Switch 页面](/assets/guide/feature-guide/general-api-key-import-cc-switch.png)

<a href="/zh/docs/apps/cc-switch" target="_blank" rel="noopener noreferrer">CC Switch</a> 是管理 Claude Code、Codex、Gemini CLI 配置的桌面工具，使用前需在电脑上安装。

**导入 CC Switch 操作流程：**
1. 选择密钥所在行末尾 ⋯ 菜单第一层的「CC Switch」，打开「填入 CC Switch」窗口。
2. 选择「应用」：Claude、Codex 或 Gemini。
3. 按需填写相应配置信息。
4. 点击「打开 CC Switch」。
5. 浏览器会请求打开 CC Switch，确认后 CC Switch 会带入 API 地址、所选密钥和模型配置信息。

**导入 其他聊天应用 操作流程：**
1. 点击所选密钥后的「⋯」打开菜单。
2. 选择「聊天」中的其他聊天应用进行导入配置使用。

<Callout type="info" title="提示">
- 网页应用在新标签页中打开；桌面应用和浏览器扩展需先安装，由浏览器唤起或直接接收密钥。
- 侧边栏的「聊天」自动使用最新创建的已启用密钥。
</Callout>

## 编辑、禁用或删除密钥

- API 密钥-更新 API 密钥

![API 密钥-更新 API 密钥页面](/assets/guide/feature-guide/general-api-key-update.png)

**编辑操作流程：**
1. 点击密钥所在行的编辑图标。
2. 按需修改「更新 API 密钥」窗口中的设置。
3. 点击「保存更改」。

**禁用或启用操作流程：**
1. 点击密钥所在行的电源图标：已启用的密钥显示为「禁用」，其他状态的密钥显示为「启用」。
2. 操作立即生效，无确认窗口。

<Callout type="info" title="提示">
「已过期」「已耗尽」的密钥不可直接启用，处理方法见 [API 密钥状态](#api-密钥状态)。
</Callout>

**删除操作流程：**
1. 点击密钥所在行末尾的 ⋯，选择「删除」。
2. 核对密钥名称，点击「删除」，一次删除多个密钥见[批量操作](#批量操作)。

<Callout type="warn" title="注意">
  删除后无法恢复，正在使用该密钥的程序和客户端将立即无法调用。如需暂时停用，请使用「禁用」。
</Callout>

**配置项说明：**

「更新 API 密钥」窗口的配置项与创建窗口相同，打开时显示该密钥当前的设置。各配置项的定义、填写要求、限制和默认值见[创建 API 密钥的配置项说明](#创建配置项说明)，下表仅列出与创建时不同的配置项。

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 配置项 | 「创建 API 密钥」窗口 | 「更新 API 密钥」窗口 |
| --- | --- | --- |
| 数量 | 显示，默认为 1，可一次创建多个密钥。 | 不显示，每次仅修改一个密钥。 |
| 分组 | 默认未选择，部分站点默认选择 auto。 | 显示密钥当前的分组。当前分组已不可用时，打开窗口后自动替换为可用分组，保存后生效。 |
| 过期时间、额度 (…) | 保存后按所填值生效。 | 修改后，「已过期」「已耗尽」的密钥不会自动恢复为「已启用」，需在列表中再执行「启用」。 |
</div>

<Callout type="info" title="提示">
- 密钥本身和启用状态不在编辑窗口中修改：如需更换密钥，请创建新密钥后删除旧密钥；启用或禁用请使用行内的电源图标。
</Callout>

## 状态项说明

### API 密钥状态

列表「状态」列和「状态」筛选中的四种状态：

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 状态 | 含义 | 备注 |
| --- | --- | --- |
| 已启用 | 密钥可正常用于调用。 | — |
| 已禁用 | 密钥已被手动禁用。 | 在列表中执行「启用」。 |
| 已过期 | 当前时间已超过密钥的「过期时间」。 | 不可直接启用，直接启用时提示「令牌已过期，无法启用…」。需先编辑密钥，将「过期时间」修改为未来的时间或设为「永不」，保存后再执行「启用」。 |

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="调用时提示「无效的令牌」">
**提示原文**：「无效的令牌」（英文 Invalid token）

**可能原因**：密钥错误、已删除、已禁用、已过期或额度已用尽，提示信息不区分具体原因。

**处理方法**：
1. 在列表中重新复制密钥，确认请求头为 `Authorization: Bearer sk-…`，且前后没有多余的空格或换行。
2. 检查该密钥的「状态」是否为「已启用」，「过期」列是否已过期，「额度」列是否已用尽，处理方法见 [API 密钥状态](#api-密钥状态)。
3. 确认使用的是 API 密钥。「安全与访问」中创建的「访问令牌」仅用于管理账户，不可用于调用模型（见<a href="/zh/docs/guide/feature-guide/user/personal-setting" target="_blank" rel="noopener noreferrer">个人资料与安全</a>）。
4. 如仍无法解决，请新建密钥后重试，或联系管理员。
</Accordion>

<Accordion title="调用时提示「该令牌无权访问模型 …」">
**提示原文**：「该令牌无权访问模型 …」（英文 This token has no access to model …）

**可能原因**：该密钥设置了「模型限制」，且请求的模型不在限制范围内。

**处理方法**：
1. 编辑该密钥，展开「高级设置」。
2. 在「模型限制」中添加该模型，或清空「模型限制」以允许调用所有可用模型。
3. 点击「保存更改」。
</Accordion>

<Accordion title="调用时提示「您的 IP 不在令牌允许访问的列表中」">
**提示原文**：「您的 IP 不在令牌允许访问的列表中」（英文 Your IP address is not on this token's allowlist）

**可能原因**：
- 该密钥设置了「IP 白名单」，且发起请求的机器不在白名单中。通过代理发起请求时，出口 IP 可能与本机 IP 不同。
- 白名单中有格式错误的行。格式错误的行会被忽略，所有行均无效时，任何地址都无法使用该密钥。

**处理方法**：
1. 编辑该密钥，在「高级设置」的「IP 白名单」中添加该机器的出口 IP 地址或网段，每行一个。
2. 无法确定哪一行有误时，先清空白名单，再逐行添加。
3. 点击「保存更改」。
</Accordion>

<Accordion title="调用时提示「无权访问 … 分组」或「分组 … 已被弃用」">
**提示原文**：「无权访问 … 分组」（英文 No permission to access group …）或「分组 … 已被弃用」（英文 Group … has been deprecated）

**可能原因**：该密钥指定的分组已不可用，例如管理员调整了分组设置。

**处理方法**：
1. 编辑该密钥。打开编辑窗口时，「分组」可能已自动替换为可用分组。
2. 确认「分组」中选择的是下拉列表中的可用分组。
3. 点击「保存更改」。
</Accordion>

<Accordion title="调用时提示额度不足（包括已开启「无限配额」的密钥）">
**说明**：「无限配额」仅取消该密钥自身的用量上限，调用时仍从账户额度中扣除。请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「用户额度不足」（英文 Insufficient user quota）<br/>「预扣费额度失败」（英文 Not enough quota to pre-consume） | 账户余额不足。 | 前往<a href="/zh/docs/guide/feature-guide/user/wallet" target="_blank" rel="noopener noreferrer">钱包与订阅</a>充值或兑换。 |
| 「订阅额度不足或未配置订阅」（英文 Subscription quota is insufficient or no subscription is configured） | 本次请求按订阅扣费，但订阅额度不足或没有可用的订阅。 | 前往钱包与订阅页查看订阅。 |
| token quota is not enough（仅英文） | 该密钥未开启「无限配额」，剩余额度不足以支付本次请求。 | 编辑该密钥，调高「额度」。 |
</Accordion>

</Accordions>
