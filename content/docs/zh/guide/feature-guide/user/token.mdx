左侧导航点击「API 密钥」，或直接访问 `/keys`。页面展示密钥名称、掩码密钥、启用状态、额度使用情况、分组等信息，并支持筛选、复制、编辑、启用/禁用和批量删除。行菜单还可复制连接信息、打开管理员配置的聊天预设，以及把密钥发送到受支持的客户端集成。

![API密钥信息页](/assets/guide/feature-guide/keys-info.png)

## 创建 API 密钥

1. 打开「API 密钥」，点击「创建 API 密钥」。
2. 填写密钥名称，便于区分应用或环境。
3. 按需设置额度、过期时间、模型限制、IP 限制和分组。
4. 保存后从列表中查看并复制完整密钥。

![创建API密钥页](/assets/guide/feature-guide/create-key.png)

### 配置项说明

| 设置 | 作用 |
| --- | --- |
| 名称 | API密钥名称（建议按用途命名，如「生产环境」「测试用」） |
| 分组 | 指定该令牌使用的渠道分组 |
| Auto 分组顺序 | 仅在分组为 `auto` 时显示；可以继承 Root 的全局顺序，也可以设置密钥级顺序。 |
| 跨分组重试开关 | 开启后，当前分组渠道失败时会按顺序尝试下一个分组的渠道。 |
| 过期时间 | 到期后拒绝使用该密钥 |
| 数量 | 可一次性创建多个 API 密钥（名称将添加随机后缀） |
| 额度 | 限制该密钥可消耗的额度 |
| 无限额度开关 | 开启后为此 API 密钥启用无限配额 |
| 模型限制 | 限定该令牌只能调用指定模型，留空表示不限制 |
| IP 白名单 | 支持逐行填写 IP 或 CIDR，留空表示不限制；应配合可信反向代理/CDN 使用 |

<Callout type="warn">
  API 密钥等同于密码。不要把完整密钥提交到代码仓库、截图、日志或聊天工具；怀疑泄露时应立即删除并创建新密钥。
</Callout>

## 查看和复制 API 密钥

在 API 密钥列表中点击掩码密钥，按页面提示查看和复制完整值。完整密钥属于敏感凭证，查看行为可能需要额外安全验证。

「复制连接信息」会将密钥和平台地址复制为应用导入信息；点击左侧栏「聊天」中的目标预设聊天应用，浏览器将尝试启动已安装的聊天应用，并自动跳转填充配置信息。
![查看API密钥页](/assets/guide/feature-guide/view-key.png)

## 编辑 API 密钥

在API密钥列表中找到目标密钥，点击右侧「编辑」按钮，可修改密钥的配置选项（不包括API密钥本身）。

![编辑API密钥页](/assets/guide/feature-guide/edit-key.png)

## 启用、禁用和删除API 密钥

在列表行操作中可启用、禁用或删除密钥；选择多行后可以批量删除。禁用可保留配置并停止调用，删除则不可恢复。

![删除API密钥页](/assets/guide/feature-guide/delete-key.png)

<Callout type="warn">
  删除确认后该API密钥立即失效，无法恢复。删除前请确认所选密钥，避免误删生产密钥。
</Callout>
