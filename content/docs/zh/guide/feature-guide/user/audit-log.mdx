- 从侧边栏「常规」→「审计日志」进入。
- 查看账户的登录、安全设置、API 密钥和访问令牌等操作记录。
- 审计日志只记录账户操作，不记录调用模型的用量和扣费。

<Callout type="info" title="提示">
- 普通用户仅可查看本账户的记录。管理员具有「查看其他账户审计日志」权限时，可在页面右上角切换「全部」「仅自己」（仅管理员可见）。
- 调用模型的用量和扣费见<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>。使用日志类型筛选中的「管理」「登录」已弃用，新的登录和管理操作记录在审计日志中。
- 事件中的「API 令牌」即「API 密钥」页中的密钥；「访问令牌」是在「安全与访问」页创建、用于管理账户的凭证，不可用于调用模型。
- 左侧边栏无「审计日志」页时：<br/>到「个人资料」页的「左侧边栏个人设置」区域中，开启「控制台区域」和「审计日志」并保存。
</Callout>

## 筛选审计日志

**操作流程：**
1. 点击「时间范围」，选择快捷范围；或填写「起始时间」「结束时间」后点击「确认」。
2. 按需在结果下拉框（默认「全部结果」）和分类下拉框（默认「全部分类」）中选择。
3. 按令牌标识、请求 ID 查找时，点击「展开」，填写第二行的筛选项。
4. 查看自动刷新后的列表；需要按当前条件重新查询时，点击「搜索」。
5. 需要清除筛选条件时，点击「重置」。

<Callout type="info" title="提示">
- 修改筛选条件后列表立即刷新，无需点击「搜索」。
- 默认显示全部时间的记录；刷新页面后筛选条件清空。
</Callout>

**筛选项说明：**

筛选区分两行，第二行默认收起，点击「展开」后显示。下表按筛选区中的顺序排列。

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 筛选项 | 所属区域 | 定义 | 填写要求和限制 | 默认值 |
| --- | --- | --- | --- | --- |
| 时间范围 | 第一行 | 按操作发生的时间筛选，起止时间均包含在内。 | 快捷范围：「今天」「7 天」（含今天）、「本周」（周日至周六）、「30 天」（含今天）、「本月」；手动填写时精确到秒，填好后点击「确认」。可只填起止之一，不限时间跨度。起始时间晚于结束时间时提示「结束时间必须晚于开始时间」，列表不刷新。 | 空，即不限时间 |
| 结果 | 第一行 | 按操作结果筛选。 | 单选：「全部结果」「成功」「失败」。 | 「全部结果」 |
| 分类 | 第一行 | 按记录的分类筛选。 | 单选：「全部分类」「登录」「账户安全」「操作审计」「访问令牌」，各分类的事件见[事件分类](#事件分类)。 | 「全部分类」 |
| 令牌标识 | 第二行 | 访问令牌的标识，用于查找某个访问令牌发起的请求。 | 选填。需填写完整的 64 位标识（由数字和小写字母 a～f 组成），可从「访问令牌」分类记录的详情中复制；仅匹配「访问令牌」分类的记录。填写不完整时，列表提示「加载审计记录失败」。 | 空 |
| 请求 ID | 第二行 | 某次操作的请求编号。 | 选填，按完整 ID 匹配，可从详情的「请求」区域复制。 | 空 |
| 用户名（仅管理员可见） | 第二行 | 按记录所属的账户筛选。 | 仅在「全部」视图中显示。按完整用户名匹配，匹配的是记录产生时的用户名。 | 空 |
</div>

## 查看审计详情

- 审计日志-日志详情

2. 查看事件、结果、操作人和请求信息。

## 事件分类

各分类包含的事件如下，事件名称以「事件」列中的显示为准：

<div className="[&_table]:min-w-[48rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 分类 | 事件 | 产生的操作 | 备注 |
| --- | --- | --- | --- |
| 登录 | 登录成功（通过 …） | 使用密码、两步验证、Passkey、微信、Telegram 或第三方账号登录成功。 | 仅记录成功的登录，登录失败不记录。 |
| 账户安全 | 账户密码变更 | 修改密码。 | 修改成功和失败都会记录。 |
| 账户安全 | 开始设置两步验证、启用了两步验证、关闭了两步验证、重新生成了两步验证备用码 | 设置或关闭两步验证，重新生成备用码。 | — |
| 账户安全 | 注册了一个 Passkey、解绑了一个 Passkey | 添加或删除 Passkey。 | — |
| 账户安全 | 账户绑定请求、账户绑定、账户解绑、重发邮箱确认码 | 绑定邮箱、微信和第三方账号，解绑第三方账号。 | — |
| 账户安全 | 完成了安全验证 | 执行敏感操作前完成安全验证。 | — |
| 账户安全 | 创建了访问令牌、重命名了访问令牌、修改了访问令牌权限、撤销了访问令牌 | 在「安全与访问」页管理访问令牌。 | — |
| 账户安全 | 创建 API 令牌「…」、更新 API 令牌「…」、删除 API 令牌「…」、批量删除 API 令牌、查看 API 令牌「…」的密钥、批量查看 API 令牌密钥 | 在「API 密钥」页创建、编辑、启用或禁用、删除密钥，或查看、复制完整密钥。 | 「API 令牌」即 API 密钥。 |
| 访问令牌 | 访问令牌 | 使用访问令牌调用账户管理接口。 | 每次请求记录一条，包括被拒绝的请求；被拒绝时详情中显示「失败原因」。 |
| 操作审计 | 更新用户、增加用户「…」的额度、修改系统设置等管理员操作（仅管理员可见） | 管理员在管理页面执行的操作。 | 记在执行操作的管理员名下，普通用户的列表中无此类记录。例外：Root 以外的管理员重置订阅套餐额度时，受影响的用户会看到「管理员重置订阅套餐 …（ID: …）额度」。 |
</div>

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="出现不认识的登录记录">
**可能原因**：
- 本人在其他设备或浏览器上登录过。
- 密码或第三方账号已泄露，他人登录了该账户。

**处理方法**：
1. 打开该记录的「日志详情」，查看「IP」「客户端」和登录方式。
2. 确认不是本人操作时，立即修改密码。
3. 在「安全与访问」页撤销不认识的登录会话和访问令牌。
4. 开启两步验证或 Passkey。
5. 如仍无法解决，请联系管理员。
</Accordion>

<Accordion title="某个操作未留下记录">
**可能原因**：
- 登录失败不记录，仅记录成功的登录。
- 调用模型、充值、兑换额度和每日签到不在审计日志中，记录在使用日志中。
- 修改语言、侧边栏等个人设置不记录。
- 管理员对账户执行的操作记在管理员名下，普通用户的列表中无此类记录。
- 审计日志启用前的登录和管理记录仍在使用日志中，类型为「登录」「管理」。
- 筛选条件过严。

**处理方法**：
1. 点击「重置」清除筛选条件后重新查找。
2. 在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中将类型选择为「登录」或「管理」，查找较早的记录。
</Accordion>

<Accordion title="看不到「全部 / 仅自己」或「用户名」筛选">
**提示原文**：「审计访问权限已变更，现仅显示本人的记录。」（英文 Audit access changed. Showing only your records.）

**可能原因**：
- 普通用户仅可查看本账户的记录，不显示这两项。
- 管理员未被授予「查看其他账户审计日志」权限，或该权限已被收回。

**处理方法**：
1. 管理员需要查看其他账户的记录时，请联系 Root 授予「查看其他账户审计日志」权限。
</Accordion>

<Accordion title="筛选时提示「加载审计记录失败」">
**提示原文**：「加载审计记录失败」（英文 Failed to load audit records）

**可能原因**：
- 「令牌标识」填写不完整，或含有大写字母。
- 网络中断或服务端出错。

**处理方法**：
1. 从「访问令牌」分类记录的详情中复制完整的「令牌标识」，重新填写。
2. 点击提示旁的「重试」。
3. 如仍失败，请联系管理员。
</Accordion>

<Accordion title="「访问令牌」分类的记录很多">
**说明**：使用访问令牌调用账户管理接口时，每个请求都会记录一条，包括被拒绝的请求。

**处理方法**：
1. 在记录详情的「请求」区域查看「令牌标识」，确认是哪个访问令牌发起的请求。
2. 按「令牌标识」筛选，查看该访问令牌的全部请求。
3. 发现不认识的请求时，在「安全与访问」页撤销该访问令牌。
</Accordion>

<Accordion title="审计记录会保存多久">
**说明**：审计记录会一直保留，系统不会自动清理；管理员清理历史日志时只删除使用日志，不删除审计记录。
</Accordion>

</Accordions>
