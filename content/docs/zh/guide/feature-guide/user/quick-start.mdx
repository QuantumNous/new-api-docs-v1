- 第一次使用本站时，按本页的 6 个步骤完成从注册登录到第一次调用模型。
- 每一步只写最短的操作，其他选项和出错时的处理见该步链接的页面。
- 调用模型会按价格扣账户里的额度（钱包余额或订阅额度）。

<Callout type="info" title="提示">
- 新注册的账户默认没有额度，也没有 API 密钥。管理员设置了注册赠送额度时，注册后即有额度；部分站点在注册时自动创建一个 API 密钥。
- 可用的登录方式、充值方式、订阅套餐和模型均由管理员配置，各站点不同。某一步找不到入口时，请联系管理员。
- 额度的单位由站点决定。
</Callout>

## 几个基本概念

界面上同一样东西可能有几种叫法，下表列出本指南使用的名称和界面上的其他叫法。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 名称 | 含义 | 界面上的其他叫法 |
| --- | --- | --- |
| API 密钥 | 程序或客户端调用模型时用的凭证，以 `sk-` 开头。 | 「令牌」，如提示「无效的令牌」。 |
| 访问令牌 | 在脚本中管理账户用的凭证，以 `nap_` 开头，不可用于调用模型，见<a href="/zh/docs/guide/feature-guide/user/security#创建和管理访问令牌" target="_blank" rel="noopener noreferrer">安全与访问</a>。 | — |
| 额度 | 账户里可以消费的数值，调用模型时按价格扣除。钱包余额和订阅额度都是额度。 | 「余额」「配额」「资金」，如「当前余额」「无限配额」「添加资金」。 |
| 分组 | 管理员划分的线路和价格档位，决定可以调用哪些模型、按什么倍率计费。 | 分组名称和倍率，如「default」「1x」。 |
| 游乐场 | 在网页中直接与模型对话的页面，使用账户的额度，不需要 API 密钥。 | 「Playground」，如「使用 Playground 或你的客户端验证路由」。 |
</div>

## 完成第一次调用

<Steps>

<Step>

### 注册或登录

**操作流程：**
1. 点击站点右上角的「登录」，打开登录页。
2. 已有账户时，使用账号密码、第三方账号或 Passkey 登录。
3. 没有账户时，点击登录页的「注册」或首页的「开始使用」，按页面要求填写后点击「创建账户」，再用新账户登录。

<Callout type="info" title="提示">
- 登录后默认显示「概览」页。页面顶部的「设置引导」与本页第 3～5 步对应，顺序不同不影响使用；完成后刷新浏览器页面，步骤前才显示对勾，见<a href="/zh/docs/guide/feature-guide/user/overview#按设置引导开始使用" target="_blank" rel="noopener noreferrer">概览</a>。
- 各种登录方式、注册时的邮箱验证和出错时的处理，见<a href="/zh/docs/guide/feature-guide/user/auth" target="_blank" rel="noopener noreferrer">注册与登录</a>。
</Callout>

</Step>

<Step>

### 查看模型和价格

**操作流程：**
1. 点击顶部导航的「模型广场」。
2. 在搜索框中输入关键词，或在左侧「筛选」栏中选择分组、供应商等条件。
3. 点击模型卡片右下角的「详情」，在「概览」的「按分组定价」中查看账户可用的分组和价格。
4. 点击模型名称右侧的复制按钮，复制模型名称备用。

<Callout type="info" title="提示">
- 站点未设置为登录后才能查看时，未登录也可查看。登录后按账户可用的分组和专属倍率显示，看到的模型和价格可能与登录前不同。
- 实际扣费按调用时所用的分组计算，价格的读法见<a href="/zh/docs/guide/feature-guide/user/pricing#读懂模型价格" target="_blank" rel="noopener noreferrer">模型广场与排行榜</a>。
</Callout>

</Step>

<Step>

### 添加额度

**操作流程：**
1. 点击侧边栏「个人」→「钱包」。
2. 按站点提供的方式，选择下表中的一种添加额度。
3. 在「当前余额」或「我的订阅」中确认额度已到账。

**添加方式：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 方式 | 操作 | 详细说明 |
| --- | --- | --- |
| 兑换码 | 在「添加资金」底部的「输入您的兑换码」中粘贴兑换码，点击「兑换额度」。 | <a href="/zh/docs/guide/feature-guide/user/wallet#兑换码" target="_blank" rel="noopener noreferrer">兑换码</a> |
| 在线充值 | 在「添加资金」中选择或填写数量，点击付款方式，在「确认付款」窗口中点击「确认付款」，再在支付页面完成付款。 | <a href="/zh/docs/guide/feature-guide/user/wallet#在线充值" target="_blank" rel="noopener noreferrer">在线充值</a> |
| 订阅套餐 | 在「订阅套餐」中点击套餐的「立即订阅」，点击「使用余额支付」或其他支付方式完成购买。 | <a href="/zh/docs/guide/feature-guide/user/wallet#订阅计划" target="_blank" rel="noopener noreferrer">订阅计划</a> |
</div>

<Callout type="info" title="提示">
- 钱包中没有可用的方式时，表示管理员尚未配置，请联系管理员获取额度或兑换码。
- 付款后余额未增加、兑换失败时，查看<a href="/zh/docs/guide/feature-guide/user/wallet#常见问题" target="_blank" rel="noopener noreferrer">钱包</a>的常见问题。
- 订阅额度不计入「概览」页的「剩余额度」。只购买了订阅、钱包余额为 0 时，「设置引导」的「2. 添加额度」在第一次成功调用后才显示对勾。
</Callout>

</Step>

<Step>

### 创建 API 密钥

**操作流程：**
1. 点击侧边栏「常规」→「API 密钥」。
2. 点击页面右上角「创建 API 密钥」。
3. 填写「名称」，其他设置保持默认。
4. 点击「保存更改」。
5. 点击新密钥所在行「API 密钥」列中密钥右侧的复制按钮。

<Callout type="info" title="提示">
- 保持默认设置时，该密钥不限额度、不限模型、永不过期，调用时从账户额度中扣除。需要限制额度、模型或 IP 时，见 <a href="/zh/docs/guide/feature-guide/user/token#创建-api-密钥" target="_blank" rel="noopener noreferrer">API 密钥</a>。
- 只在游乐场中使用时，可跳过本步。
</Callout>

<Callout type="warn" title="注意保管密钥">
获得 API 密钥的任何人都可以用它消耗账户额度，请勿发送到聊天群，或包含在截图、公开的代码仓库中。
</Callout>

</Step>

<Step>

### 发送第一个请求

以下三种方式任选一种。

**方式一：在游乐场中发送**

1. 点击侧边栏「聊天」→「游乐场」。
2. 点击输入框右下方的分组与模型选择器，选择分组和模型。
3. 在输入框中输入内容，点击「发送」。

**方式二：用 curl 命令发送**

1. 打开 macOS、Linux 的终端，或 Windows 的 Git Bash。Windows 的 PowerShell 和命令提示符无法直接运行该命令。
2. 复制下面的命令，按下表替换其中三处内容后运行。

```bash
curl https://your-host/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -d '{"model":"模型名称","messages":[{"role":"user","content":"你好"}]}'
```

<div className="[&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 命令中的内容 | 替换为 | 获取位置 |
| --- | --- | --- |
| `https://your-host` | API 地址 | 在「API 密钥」页点击右上角「API 地址」，点击所需地址右侧的复制按钮。 |
| `sk-xxxxxxxx` | API 密钥 | 第 4 步复制的 API 密钥。 |
| `模型名称` | 模型名称 | 第 2 步复制的模型名称。 |
</div>

**方式三：复制概览页的示例命令发送**

1. 点击侧边栏「常规」→「概览」。
2. 点击「首个 API 请求」右上角「复制」。
3. 在终端中粘贴并运行命令，无需替换任何内容。

<Callout type="info" title="提示">
- 终端返回包含模型回复的 JSON 时，表示调用成功；返回错误时，按提示原文在<a href="/zh/docs/guide/feature-guide/user/faq" target="_blank" rel="noopener noreferrer">常见问题</a>中查找原因。
- 「首个 API 请求」的命令已填好 API 地址、列表中最前面的已启用密钥和第一个可用模型，无需替换，适用的终端与上面的 curl 命令相同。设置引导已收起时，先点击「显示设置引导」或页面标题右侧的「设置引导」，见<a href="/zh/docs/guide/feature-guide/user/overview#复制示例命令发送第一个请求" target="_blank" rel="noopener noreferrer">概览</a>。
- API 地址的选择和在其他客户端中调用的方法，见<a href="/zh/docs/guide/feature-guide/user/token#复制密钥并调用模型" target="_blank" rel="noopener noreferrer">复制密钥并调用模型</a>。
- 游乐场不使用 API 密钥，调用同样从账户额度中扣除，见<a href="/zh/docs/guide/feature-guide/user/playground" target="_blank" rel="noopener noreferrer">游乐场</a>。
</Callout>

</Step>

<Step>

### 在使用日志中查看扣费

**操作流程：**
1. 点击侧边栏「常规」→「使用日志」。
2. 点击「搜索」刷新列表。
3. 找到类型为「消耗」的记录，查看「费用」列。
4. 点击该记录「详情」列的摘要，在「日志详情」中查看「Token 明细」和「计费详情」。

<Callout type="info" title="提示">
- 页面标题显示为「通用日志」。默认仅显示今天的记录，页面不会自动刷新。
- 游乐场的调用在「令牌」列显示 `playground-` 加分组名称，如 `playground-default`。
- 调用失败的请求不扣费。找不到记录时，见<a href="/zh/docs/guide/feature-guide/user/log#常见问题" target="_blank" rel="noopener noreferrer">使用日志</a>的常见问题。
</Callout>

</Step>

</Steps>

<Callout type="info" title="提示">
任一步出错时，先查看该步链接页面的常见问题；调用失败、余额对不上等跨页面的问题见<a href="/zh/docs/guide/feature-guide/user/faq" target="_blank" rel="noopener noreferrer">常见问题</a>。
</Callout>

- 首页、模型广场、排行榜等页面的顶部栏只有顶部导航、语言、主题切换、通知和「登录」（已登录时为头像）；窄屏时仅显示主题切换、头像和菜单按钮，顶部导航和「登录」收在菜单按钮中。
</Callout>

- 侧边栏由两层设置决定：管理员关闭的页面对所有用户隐藏；在此基础上，可在「个人资料」页的「左侧边栏个人设置」中再隐藏，见<a href="/zh/docs/guide/feature-guide/user/personal-setting#设置左侧边栏显示的页面" target="_blank" rel="noopener noreferrer">设置左侧边栏显示的页面</a>。
- 收起后侧边栏只显示图标，鼠标悬停显示页面名称；展开或收起的状态保存在当前浏览器中。
- 屏幕宽度小于 768px（如手机）时侧边栏默认隐藏，点击侧边栏开关后从左侧滑出，点击页面后自动收起。
- 模型广场和排行榜不在侧边栏中，从顶部导航进入。
</Callout>
