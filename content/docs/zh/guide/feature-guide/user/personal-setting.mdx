## 设置通知和行为偏好

- 个人资料-通知方式

![个人资料-通知方式页面](/assets/guide/feature-guide/personal-profile-settings-notification-method.png)

**操作流程：**
1. 在「设置」区域的「通知方式」中选择「邮箱」「Webhook」「Bark」或「Gotify」。
2. 填写所选方式下方显示的填写项。
3. 在「接收哪些通知」中开启或关闭「余额不足提醒」，按需填写「提醒阈值 (…)」。
4. 在「偏好设置」中按需开启或关闭「接受未定价模型」。
5. 点击「保存设置」。

<Callout type="info" title="提示">
- 「通知方式」「接收哪些通知」「偏好设置」共用底部的「保存设置」。所选方式的必填项为空或格式错误时整体保存失败，同时修改的其他开关也不会保存。
- 仅保存所选通知方式的填写项，切换方式并保存后，其他方式已填写的内容被清空。
- 管理员关闭站点的余额不足提醒时，普通用户的「设置」区域只显示「目前没有可接收的通知」和「偏好设置」。
- 通知地址需能被站点服务器访问，指向内网或本机的地址可能被站点的安全策略拦截；发送失败时页面不提示。同一类通知短时间内多次触发时，部分通知可能不发送。
</Callout>

<Callout type="warn" title="注意">
开启「接受未定价模型」后，可调用管理员尚未配置价格的模型，可能产生意外的高额消耗。该项默认关闭，不建议开启。
</Callout>

**通知方式说明：**

截图依次为选择「邮箱」「Bark」「Gotify」「Webhook」时显示的填写项（左上、右上、左下、右下）。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 通知方式 | 需填写的项 | 填写要求和限制 |
| --- | --- | --- |
| 邮箱 | 通知邮箱 | 选填，占位文字为「留空以使用账户邮箱」。留空时发送到账户绑定的邮箱，账户未绑定邮箱时不发送。格式错误时提示「无效的邮箱地址」。 |
| Webhook | Webhook 地址、Webhook 密钥 | 「Webhook 地址」必填，需为有效的网址，如 `https://example.com/webhook`；为空时提示「Webhook 地址不能为空」，格式错误时提示「无效的 Webhook 地址」。「Webhook 密钥」选填，填写后每条通知附带签名，供接收方校验来源。通知内容为 JSON 格式。 |
| Bark | Bark 推送 URL | 必填，以 http:// 或 https:// 开头，可使用模板变量 `{{title}}`、`{{content}}`，发送时替换为通知的标题和正文。为空时提示「Bark 推送 URL 不能为空」，格式错误时提示「无效的 Bark 推送 URL」。 |
| Gotify | Gotify 服务器 URL、Gotify 应用令牌、消息优先级 | 「Gotify 服务器 URL」必填，以 http:// 或 https:// 开头，为空时提示「Gotify 服务器地址不能为空」。「Gotify 应用令牌」必填，在 Gotify 服务器中创建应用后复制，为空时提示「Gotify 令牌不能为空」。「消息优先级」为 0（最低）～10（最高），超出范围时按 5 保存；输入框中的数值即保存后使用的优先级，请按需填写。下方「设置说明」列出三个步骤和「Gotify 文档」链接。 |
</div>

## 设置界面语言

**操作流程：**
1. 点击「语言偏好」区域的「界面语言」下拉框。
2. 选择要使用的语言。

<Callout type="info" title="提示">
- 选择后立即保存并切换界面，无需点击保存，提示「语言偏好已保存」；设置同步到该账户登录的所有设备。
- 可选简体中文、English、Français、Русский、日本語、Tiếng Việt、繁體中文。
- 调用接口时返回的错误消息仅有简体中文、繁体中文和英文三种，选择其他语言时显示英文。
</Callout>

## 每日签到领取额度

**操作流程：**
1. 在「每日签到」区域点击「立即签到」。
2. 站点开启了人机验证时，在弹出的「安全验证」窗口中完成人机验证。
3. 在日历中查看已签到的日期和获得的额度。

<Callout type="info" title="提示">
- 仅在管理员开启签到功能后显示，见<a href="/zh/docs/guide/feature-guide/system-settings/settings-billing#签到奖励" target="_blank" rel="noopener noreferrer">计费与支付配置</a>。
- 每天仅可签到一次，按服务器的日期计算。奖励在管理员设置的范围内随机，直接加入「当前余额」，并在使用日志中产生一条「系统」记录。
- 今天已签到时，按钮显示「已签到」并置灰，标题旁显示「已签到」和「今天 +…」，区域默认收起，点击标题可展开。
</Callout>

**字段说明：**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 字段 | 定义 | 填写要求和限制 | 备注 |
| --- | --- | --- | --- |
| 累计签到 | 历史签到的总次数。 | 由系统自动统计。 | — |
| 本月获得 | 日历当前所显示月份获得的奖励合计。 | 由系统自动统计。 | 切换月份后随之变化。 |
| 累计获得 | 历史获得的奖励合计。 | 由系统自动统计。 | — |
| 日历 | 每天的签到情况。 | 点击左右箭头切换月份。 | 今天高亮显示，已签到的日期下方有绿点，鼠标悬停显示「已签到」和获得的额度。 |
</div>

## 设置左侧边栏显示的页面

**操作流程：**
1. 在「左侧边栏个人设置」区域中，开启或关闭区域开关和模块开关。
2. 点击「保存更改」。

<Callout type="info" title="提示">
- 侧边栏由两层设置决定：管理员关闭的页面对所有用户隐藏，在本区域开启也不显示；本区域仅可在此基础上再隐藏，见<a href="/zh/docs/guide/feature-guide/system-settings/settings-site#侧边栏模块" target="_blank" rel="noopener noreferrer">站点与品牌配置</a>。
- 关闭区域开关后，其下的模块开关置灰，保存后该区域的页面全部隐藏。
- 「重置为默认」仅把开关全部恢复为开启，需再点击「保存更改」才生效。
- 仅隐藏侧边栏入口，不授予或撤销权限。页面右上角头像菜单中的「个人资料」始终显示。
- Root 账户不显示该区域，侧边栏由管理员的系统设置决定。
</Callout>

## 常见问题

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="收不到余额不足提醒">
**可能原因**：
- 管理员关闭了站点的余额不足提醒，或账户关闭了「余额不足提醒」。
- 余额原本已低于阈值。每次跨过阈值只提醒一次，充值到阈值以上后才会再次提醒。
- 选择了「邮箱」，未填写「通知邮箱」，且账户未绑定邮箱。
- 通知地址无法从站点服务器访问，或被站点的安全策略拦截。
- 同一类通知短时间内多次触发，部分通知未发送；或邮件被归入垃圾邮件。

**处理方法**：
1. 确认「余额不足提醒」已开启，核对「提醒阈值 (…)」。
2. 选择「邮箱」时，填写「通知邮箱」，或在<a href="/zh/docs/guide/feature-guide/user/security" target="_blank" rel="noopener noreferrer">安全与访问</a>页绑定邮箱。
3. 确认 Webhook、Bark 或 Gotify 地址可从公网访问，或改用其他通知方式并保存。
4. 如仍收不到，请联系管理员检查站点的通知设置。
</Accordion>

<Accordion title="「设置」区域只显示「目前没有可接收的通知」">
**提示原文**：「目前没有可接收的通知」（英文 No notifications are available to you right now）

**可能原因**：管理员关闭了站点的余额不足提醒。

**处理方法**：
1. 需要余额提醒时，请联系管理员。
</Accordion>

<Accordion title="保存设置时提示「Webhook 地址不能为空」等错误">
**说明**：请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「Webhook 地址不能为空」（英文 Webhook URL cannot be empty）<br/>「无效的 Webhook 地址」（英文 Invalid Webhook URL） | 选择 Webhook 时未填写地址，或地址格式错误。 | 填写完整的网址。 |
| 「Bark 推送 URL 不能为空」（英文 Bark push URL cannot be empty）<br/>「无效的 Bark 推送 URL」（英文 Invalid Bark push URL） | Bark 推送 URL 为空或格式错误。 | 填写以 http:// 或 https:// 开头的完整网址。 |
| 「Gotify 服务器地址不能为空」（英文 Gotify server URL cannot be empty）<br/>「无效的 Gotify 服务器地址」（英文 Invalid Gotify server URL）<br/>「Gotify 令牌不能为空」（英文 Gotify token cannot be empty） | Gotify 服务器 URL 或应用令牌未填写，或格式错误。 | 补全服务器 URL 和应用令牌。 |
| 「URL 必须以 http:// 或 https:// 开头」（英文 URL must start with http:// or https://） | 网址缺少 http:// 或 https://。 | 在网址前补上 https://。 |
| 「无效的邮箱地址」（英文 Invalid email address） | 「通知邮箱」格式错误。 | 修正邮箱，或留空使用账户邮箱。 |
| 「提醒阈值不能为负数」（英文 Reminder threshold cannot be negative） | 阈值为负数。 | 填写 0 或正数，或留空。 |
| 「无法更新设置」（英文 Failed to update settings） | 网络中断或登录已过期。 | 刷新页面后重试。 |
</Accordion>

<Accordion title="看不到「每日签到」">
**可能原因**：管理员未开启签到功能，该功能默认关闭。

**处理方法**：
1. 需要签到时，请联系管理员。
</Accordion>

<Accordion title="签到时提示「今日已签到」等错误">
**说明**：请根据提示原文判断原因：

| 提示原文 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 「今日已签到」（英文 Already checked in today） | 今天已签到，按服务器的日期计算。 | 次日再签到。 |
| 「签到功能未启用」（英文 Check-in feature is not enabled） | 管理员已关闭签到功能。 | 刷新页面；需要签到时联系管理员。 |
| 「Turnstile token 为空」（英文 Turnstile token is empty） | 站点的人机验证未正确配置。 | 联系管理员。 |
| 「Turnstile 校验失败，请刷新重试！」（英文 Turnstile verification failed, please refresh and try again!） | 人机验证未通过。 | 刷新页面后重新签到。 |
| 「签到失败，请稍后重试」（英文 Check-in failed, please try again later）<br/>「签到失败」（英文 Check-in failed） | 网络中断或服务端出错。 | 稍后重试。 |
</Accordion>

<Accordion title="签到成功后余额未立即变化">
**说明**：奖励已加入余额，余额显示可能有短暂延迟。

**处理方法**：
1. 刷新页面后查看「当前余额」。
2. 在<a href="/zh/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">使用日志</a>中将类型选择为「系统」，查看签到记录。
</Accordion>

<Accordion title="侧边栏中的某个页面不见了">
**可能原因**：
- 在「左侧边栏个人设置」中关闭了对应的模块或区域，并已保存。
- 管理员在系统设置中隐藏了该页面。
- 「绘图日志」「任务日志」两个开关都关闭时，侧边栏才不显示「任务日志」；只关闭一个时，页内对应的标签消失。

**处理方法**：
1. 在「左侧边栏个人设置」中开启对应的区域和模块，点击「保存更改」；也可点击「重置为默认」后再点击「保存更改」。
2. 侧边栏中无「个人资料」时，点击页面右上角的头像，选择「个人资料」进入本页。
3. 开关已开启仍不显示时，请联系管理员。
</Accordion>

<Accordion title="界面语言已切换，接口返回的错误消息仍为英文">
**说明**：接口返回的错误消息仅有简体中文、繁体中文和英文三种，选择其他界面语言时显示英文。

**处理方法**：
1. 需要中文错误消息时，在「界面语言」中选择「简体中文」或「繁體中文」。
</Accordion>

<Accordion title="调用模型时提示「模型 … 的价格尚未由管理员配置…」">
**提示原文**：「模型 … 的价格尚未由管理员配置，暂时无法使用，请联系站点管理员开启该模型」（英文 Model … has not been priced by the administrator yet. Please contact the site administrator to enable this model.）

**可能原因**：管理员尚未为该模型配置价格，且账户未开启「接受未定价模型」。

**处理方法**：
1. 联系管理员为该模型配置价格。
2. 确需立即使用时，在「偏好设置」中开启「接受未定价模型」并点击「保存设置」，注意可能产生意外的高额消耗。
</Accordion>

<Accordion title="如何修改显示名称、用户名、邮箱或分组">
**说明**：本页不可修改显示名称、用户名和分组；邮箱在「安全与访问」页绑定或更改。

**处理方法**：
1. 绑定或更改邮箱：打开<a href="/zh/docs/guide/feature-guide/user/security" target="_blank" rel="noopener noreferrer">安全与访问</a>，在「账户绑定」中操作。
2. 修改显示名称、用户名或分组，请联系管理员。
</Accordion>

<Accordion title="页面上无「左侧边栏个人设置」">
**说明**：Root 账户不显示该区域，侧边栏由管理员的系统设置决定；其他账户均显示。
</Accordion>
