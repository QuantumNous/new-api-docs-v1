在这里可以进行查看、编辑和添加令牌等操作。

## 什么是 API 令牌

API 令牌是用于调用 New API 服务的凭证。每个令牌可以设置不同的权限和额度限制，方便你管理不同应用或项目的 API 访问。

## 查看令牌

![查看令牌](/assets/guide/api-token.png)

在令牌列表中，你可以看到：
- **令牌名称**：便于识别不同用途的令牌
- **状态**：启用/禁用
- **已用额度**：该令牌已消耗的配额
- **剩余额度**：该令牌还可使用的配额
- **创建时间**：令牌的创建日期
- **操作**：编辑、删除、复制令牌

## 添加令牌

![添加令牌](/assets/guide/create-api-token.png)

创建新令牌时，可以配置：

### 基本信息
- **令牌名称**：给令牌起一个有意义的名称（如"生产环境"、"测试用"）
- **额度限制**：设置该令牌的最大可用额度，用完后将无法继续调用

### 权限设置
- **模型权限**：选择该令牌可以访问哪些 AI 模型
- **分组权限**：如果配置了渠道分组，可以指定令牌使用哪个分组

### 使用建议

1. **分项目创建**：为不同项目创建独立的令牌，便于追踪使用情况
2. **合理设置额度**：根据项目需求设置合理的额度限制，避免超支
3. **定期检查**：定期查看令牌使用情况，及时调整额度或禁用不用的令牌
4. **最小权限原则**：只给令牌分配必要的模型权限，提高安全性

## 安全建议

- **不要公开令牌**：不要在公开代码、GitHub 仓库中硬编码令牌
- **使用环境变量**：在代码中通过环境变量读取令牌
- **及时禁用**：如果令牌泄露，请立即禁用并创建新令牌
- **定期轮换**：建议定期更换令牌，降低安全风险
