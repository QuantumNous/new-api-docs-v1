---
title: 用户管理
---

这里可以管理 New API 的注册用户，包括查看用户信息、编辑用户权限、管理用户额度等。

![用户管理](/assets/guide/user-management.png)

## 主要功能

### 1. 查看用户列表
用户列表显示所有注册用户的信息：
- **用户 ID**：系统分配的唯一标识
- **用户名**：用户的登录名
- **邮箱**：用户的邮箱地址
- **角色**：普通用户 / 管理员
- **状态**：启用 / 禁用
- **余额**：用户当前的账户余额
- **已用额度**：用户累计消耗的额度
- **注册时间**：用户的注册日期

### 2. 编辑用户
点击"编辑"按钮可以修改用户信息：
- **修改角色**：将用户设置为管理员或普通用户
- **调整余额**：手动增加或减少用户余额
- **设置额度**：为用户设置额度上限
- **修改分组**：指定用户使用的渠道分组

### 3. 禁用/启用用户
- **禁用用户**：禁用后该用户无法登录和调用 API
- **启用用户**：重新启用被禁用的用户

### 4. 删除用户
删除用户会同时删除该用户的所有令牌和使用记录，操作不可恢复，请谨慎使用。

## 使用场景

### 企业内部管理
- 为不同部门或项目创建独立用户
- 为每个用户分配独立的额度
- 通过分组控制不同用户可访问的模型

### 付费服务运营
- 管理付费用户的余额和权限
- 查看用户的消费情况
- 处理用户的充值和退款

### 安全管理
- 及时禁用异常用户
- 监控高消费用户
- 定期清理不活跃用户

## 管理建议

1. **定期检查**：定期查看用户列表，关注异常消费情况
2. **合理分配**：根据用户需求合理分配额度，避免浪费
3. **权限最小化**：谨慎授予管理员权限，避免误操作
4. **备份数据**：删除用户前确认是否需要备份其使用数据
