在这里可以查看 New API 的总体统计数据，帮助你了解系统的使用情况和运行状态。

![数据看板](/assets/guide/dashboard.png)

## 主要数据指标

数据看板展示以下关键信息：

### 用户统计
- **总用户数**：系统中注册的用户总数
- **活跃用户**：最近一段时间内有 API 调用的用户数
- **新增用户**：今日或本周新注册的用户数

### 令牌统计
- **总令牌数**：系统中创建的 API 令牌总数
- **启用令牌**：当前处于启用状态的令牌数量
- **禁用令牌**：已被禁用的令牌数量

### 渠道统计
- **总渠道数**：配置的 AI 模型渠道总数（如 OpenAI、Claude 等）
- **正常渠道**：运行正常的渠道数量
- **异常渠道**：出现错误或不可用的渠道数量

### 使用统计
- **总请求数**：系统处理的 API 请求总数
- **成功请求**：成功完成的请求数量
- **失败请求**：失败或出错的请求数量
- **总消耗额度**：所有用户消耗的额度总和

### 财务统计
- **总收入**：用户充值的总金额
- **总支出**：调用上游 API 的总成本
- **当前余额**：系统账户的当前余额

## 使用建议

1. **定期检查**：建议每天查看数据看板，及时发现异常情况
2. **关注异常渠道**：如果有渠道显示异常，及时检查配置或联系服务商
3. **监控成本**：关注总支出和总收入的比例，确保系统盈利或成本可控
4. **用户增长**：通过新增用户和活跃用户数据，了解系统的增长趋势

## 数据刷新

数据看板的统计数据会定期自动刷新，通常每 5-10 分钟更新一次。如需查看实时数据，可以刷新页面。
