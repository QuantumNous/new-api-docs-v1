---
title: 钱包
---

在这里可以进行充值，兑换码兑换和查看 AFF 邀请链接。支付方式由管理员在系统设置->支付设置中配置。

![钱包](/assets/guide/wallet.png)

## 主要功能

### 1. 账户余额
显示你当前的账户余额，这个余额用于调用 API 时扣费。余额不足时，API 调用会失败。

### 2. 在线充值
点击"充值"按钮，选择充值金额和支付方式：
- **支付宝**：扫码支付（需管理员配置 EPay）
- **微信支付**：扫码支付（需管理员配置 EPay）
- **Stripe**：信用卡支付（需管理员配置 Stripe）

充值成功后，余额会自动到账。

### 3. 兑换码兑换
如果你有兑换码（由管理员发放），可以在这里输入兑换码进行兑换：
1. 在"兑换码"输入框中输入兑换码
2. 点击"兑换"按钮
3. 兑换成功后，对应的额度会自动添加到你的账户

### 4. AFF 邀请链接
如果管理员开启了邀请奖励功能，你可以：
- 复制你的专属邀请链接
- 分享给其他人注册
- 当被邀请人充值时，你可能会获得返佣奖励（具体规则由管理员设置）

## 使用建议

1. **及时充值**：建议保持账户有足够余额，避免 API 调用中断
2. **记录兑换码**：兑换码通常只能使用一次，兑换前请确认输入正确
3. **关注优惠**：留意管理员发布的充值优惠活动
4. **查看消费记录**：定期在"使用日志"中查看你的 API 消费情况

## 注意事项

- 充值金额通常不支持退款，请根据实际需求充值
- 兑换码有效期和使用次数限制由管理员设置
- 邀请奖励规则可能随时调整，以管理员公告为准
