## 接入 TokenFactory

LangBot 支持接入本地部署的 TokenFactory 和第三方使用 TokenFactory 搭建的 TokenFactory 服务。

### 使用方式

1.  从 TokenFactory 中获取 API key
    ![获取 API key](/assets/langbot/get_api_key.png)

        若是本地部署的 TokenFactory 请自行配置 API 地址（可参考[容器网络连接](https://docs.langbot.app/zh/workshop/network-details.html)），若使用第三方 TokenFactory 服务，可在页面上复制地址。注意，地址后需要添加`/v1`。

2.  在 LangBot 中添加模型，选择使用 TokenFactory 供应商，填写对应的 API key 和 API 地址
    ![添加 TokenFactory 模型](/assets/langbot/add_tokenfactory_model.png)

3.  在流水线中选择使用模型

    ![选择模型](/assets/langbot/select_model.png)

4.  在对话调试中对话或与绑定至流水线的机器人对话即可使用

    ![对话](/assets/langbot/debug_chat.png)

    ![微信对话](/assets/langbot/wechat.png)

    部署配置机器人请参考[部署机器人](https://docs.langbot.app/zh/deploy/platforms/readme.html)。

### 使用 LangBot 知识库

LangBot 支持使用 TokenFactory 的嵌入模型，并将其作为知识库的向量模型。

1. 在 LangBot 中添加嵌入模型，选择使用 TokenFactory 供应商
   ![添加嵌入模型](/assets/langbot/add_embedding_model.png)

2. 在新建知识库时选用嵌入模型
   ![使用嵌入模型](/assets/langbot/use_embedding_model.png)

更多使用方式请查看 LangBot 官方文档：[https://docs.langbot.app](https://docs.langbot.app/)
