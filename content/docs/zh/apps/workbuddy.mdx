## 统一接入参数

| 配置项 | 填写内容 |
| --- | --- |
| API Base URL | `https://apihub.agnes-ai.com/v1` |
| API Key | `YOUR_API_KEY` |
| 模型 | `agnes-2.0-flash` |
| 协议 | OpenAI Chat Completions |

## 配置说明

不同版本的入口名称可能显示为 `Other`、`Custom` 或“自定义提供商”。

## 验证与排查

配置完成后发送一条测试消息。认证失败时重新复制 API Key；模型不存在时检查模型权限；连接失败时确认 Base URL 只填写到 `/v1`。
