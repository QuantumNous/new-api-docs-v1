New API Discord コミュニティへようこそ！ここでは、他の開発者と経験を共有し、アイデアを交換できます。

## 📜 コミュニティルール

良好なコミュニティの雰囲気を維持するため、以下のルールを遵守してください。

<Callout type="warn" title="重要なお知らせ">
  以下のルールに違反した場合、Discord コミュニティから削除される可能性があります。メンバーの皆様はよくお読みになり、遵守してください。
</Callout>

1. コミュニティの管理者は、皆様に技術サポートを提供する義務を一切負いません。問題がある場合は、[issue](/ja/docs/support/feedback-issues) を提出してください。
2. Discord コミュニティの内容は、New API のオープンソースプロジェクトの使用、デプロイ、開発、フィードバックに焦点を当てるべきであり、アカウント取引、購入ガイド、または購入希望に関する情報を投稿しないでください。
3. 本コミュニティはオープンソースコミュニティの交流のみを目的としています。プロジェクト情報は公式リポジトリ、ドキュメント、コミュニティチャネルを通じて入手してください。
4. New API は GNU AGPLv3 オープンソースライセンスを採用しており、ライセンスを遵守すれば無料で利用できます。詳細は[プロジェクト紹介](/ja/docs/guide/wiki/basic-concepts/project-introduction)をご覧ください。
5. 本プロジェクトを使用する際は、関連する法令、アップストリームのサービス規約、プラットフォームルール、およびコンテンツセキュリティ要件を遵守する必要があります。
6. コミュニティでの議論は、合法的なライセンス、コンプライアンスに準拠したデプロイ、および正当なエンジニアリング問題を中心に展開されるべきであり、関連するメッセージとコミュニティメンバーの管理はコミュニティルールに従って処理されます。

<Callout title="ヒント">
  機能に関する提案やバグのフィードバックがある場合は、GitHubで直接issueを提出することをお勧めします。そうすることで、問題をより効果的に追跡し、解決できます。
</Callout>

## 🤝 New API Discord コミュニティに参加する

<Callout type="info" title="参加前にアンケートを完了してください">
  上記のコミュニティルールをよくお読みになった上で、以下のアンケート検証を完了してください。すべて正解した場合にのみ、Discord の招待リンクが表示されます。送信前に確認が表示されます。確認後、一問でも間違えると、このブラウザーでは再回答できません。再読み込みや言語の変更でもリセットされません。
</Callout>
