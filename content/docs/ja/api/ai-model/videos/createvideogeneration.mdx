ビデオシリーズモデル向けのビデオ生成タスクを送信します。

**エンドポイント**：`POST /v1/video/generations`

## 生成モード

| モード | 必須パラメータ | 説明 |
| --- | --- | --- |
| テキストからビデオ | `model` + `prompt` | `images`、`metadata.video_urls` は渡さない |
| 画像からビデオ | `model` + `prompt` + `images` | `images` に画像1枚 |
| ビデオからビデオ | `model` + `prompt` + `metadata.video_urls` | ビデオ1本 |
| 複数参照画像 | `images` に複数 | 各画像を参照素材として使用 |
| 複数参照ビデオ | `metadata.video_urls` に複数 | 各ビデオを参照素材として使用 |

## `images` と `metadata.video_urls` の記入ルール

- **単一画像 / 単一ビデオ**：配列に URL を1つだけ指定
- **複数参照**：順番に複数の URL を指定し、`prompt` で各素材の用途を説明することを推奨
- **テキストからビデオ**：`images` や `metadata.video_urls` は渡さない
- URL はパブリックアクセス可能であること（HTTP/HTTPS）
- 画像形式：`.png`、`.jpg`、`.jpeg`、`.webp`
- ビデオ形式：`.mp4`、`.mov`、`.webm`

## テキストからビデオの例

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "夕暮れの海岸線、映画的な光、スローモーションのプッシュイン、岩に打ち寄せる波",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```
