動画生成タスクの状態と結果を照会します。完了後は `output.video_url` から生成されたビデオのURLを取得できます。

**エンドポイント**：`GET /v1/video/generations/{task_id}`

`{task_id}` はタスク作成時に返される `id` フィールドです。

## タスクの状態

| status | 意味 |
| --- | --- |
| `queued` | キューイング中 |
| `in_progress` | 生成中 |
| `completed` | 成功 |
| `failed` | 失敗 |

## リクエスト例

```bash
curl -X GET "__apiBaseUrl__/v1/video/generations/task_abc123" \
  -H "Authorization: Bearer <YOUR_API_KEY>"
```

## 成功レスポンス例

```json
{
  "id": "task_abc123",
  "object": "video.generation",
  "model": "Seedance 2.0/uP",
  "status": "completed",
  "progress": 100,
  "created_at": "2026-06-17T08:00:00Z",
  "completed_at": "2026-06-17T08:01:30Z",
  "output": {
    "video_url": "https://cdn.example.com/output/task_abc123.mp4"
  },
  "error": null
}
```
