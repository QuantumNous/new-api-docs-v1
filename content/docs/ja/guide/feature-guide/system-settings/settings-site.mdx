- Root のみアクセスできます。サイドバーの「管理者」→「システム設定」を開き、左側のナビゲーションで「サイトとブランド」配下のセクションを選択します。
- サイト名とアドレス、公開ページのコンテンツ、法的文書、システムのお知らせ、トップナビゲーション、サイドバーモジュールを設定できます。
- システム名、お知らせ、このサイトについて、ホームページのコンテンツ、利用規約、プライバシーポリシーはログインせずに閲覧できます。

<Callout type="info" title="ヒント">

- このページの「システムのお知らせ」は、サイト全体に表示する通知です。コンソールの構造化されたお知らせ一覧は、<a href="/ja/docs/guide/feature-guide/system-settings/settings-content" target="_blank" rel="noopener noreferrer">コンソールコンテンツ設定</a>の「お知らせ」で管理します。
- トップナビゲーションとサイドバーモジュールの基本的な役割は、各リンクの表示を切り替えることです。「モデル広場」や「ランキング」を無効にすると、サーバー側でも対応するデータの取得を拒否します。詳細は[注意事項](#注意事項)を参照してください。

</Callout>

## サイトとブランドの設定概要

「サイトとブランド」は 4 つのセクションに分かれています。左側のナビゲーションの「サイトとブランド」配下で切り替えられ、既定では「システム情報」が開きます。

**セクションの説明**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| セクション | 用途 | セクション内のタブ |
| --- | --- | --- |
| [システム情報](#システム情報) | サイトの基本情報、アドレス、公開ページのコンテンツ、法的文書を設定します。 | — |
| [システムのお知らせ](#システムのお知らせ) | 通知センターに表示するサイト全体のお知らせを設定します。 | — |
| [トップナビゲーション](#トップナビゲーション) | トップナビゲーションの組み込みリンクの表示と、ログインの要否を設定します。 | — |
| [サイドバーモジュール](#サイドバーモジュール) | サイドバーの各エリアとモジュールの表示を設定します。 | — |

</div>

<Callout type="info" title="ヒント">

- アドレス形式のエラーが表示される、保存後も古い内容が表示される、特定のアカウントでサイドバーのリンクが想定どおりに表示されない場合は、[よくある質問](#よくある質問)を参照してください。

</Callout>

## 設定セクション

ここでは、左側のナビゲーションに表示される順に 4 つのセクションを紹介します。各セクションの保存ボタンと設定の反映タイミングについては、[保存と反映](#保存と反映)を参照してください。

### システム情報

- サイトとブランド - システム情報

![サイトとブランド - システム情報ページ](/assets/guide/feature-guide/system-settings-site-brand-system-information.png)

**操作手順**

1. システム名、サーバーアドレス、非同期タスクの公開アドレスを入力します。
2. 必要に応じて、ロゴ URL、ドキュメントリンク、フッター、「このサイトについて」、ホームページのコンテンツを入力します。
3. ユーザーの同意が必要な場合は、利用規約とプライバシーポリシーを入力します。
4. ページ上部の「変更を保存」をクリックします。

<Callout type="warn" title="注意">

- これらの内容は未ログインのユーザーにも公開されます。API Key、クライアントシークレット、内部ネットワークのアドレス、管理者の内部情報など、公開すべきでない情報は入力しないでください。
- 「非同期タスクの公開アドレス」は、エンドユーザーがブラウザーからアクセスできる公開アドレスである必要があります。ここで検証するのはアドレスの形式までです。
- アドレスが誤っている場合やノード間でシークレットが一致しない場合は、タスクの成果物のアドレスにアクセスできないか、検証に失敗します。詳細は[注意事項](#注意事項)を参照してください。

</Callout>

**法的文書のルール**

- 利用規約またはプライバシーポリシーに内容を設定すると、ログインページ、登録ページ、フッターに対応するリンクが表示されます。
- 認証ページでは、設定済みの文書への同意を示すチェックボックスをオンにする必要があります。
- フィールドを空にすると、対応するリンクと同意要件が無効になります。

<Callout type="info" title="ヒント">

この機能では、現在の文書の内容や外部リンクを公開できます。法的文書のバージョン管理、署名記録、履歴の保存は対象外です。監査可能な規約のバージョン管理や再同意の仕組みが必要な場合は、New API の外部で対応するプロセスを整備してください。

</Callout>

### システムのお知らせ

- サイトとブランド - システムのお知らせ

![サイトとブランド - システムのお知らせページ](/assets/guide/feature-guide/system-settings-site-brand-system-announcement.png)

システムのお知らせの表示は、コンテンツの有無で切り替わります。内容を設定すると、通知センターの「通知」タブに表示されます。

**操作手順**

1. 「お知らせの内容」に本文を入力します。
2. ページ上部の「通知を保存」をクリックします。
3. 公開を停止する場合は、「お知らせの内容」を空にして保存します。

<Callout type="info" title="ヒント">

  このセクションの「システムのお知らせ」と「コンソールコンテンツ › お知らせ」は、それぞれ固有の用途に使います。前者ではサイト全体に表示する通知を 1 件設定し、後者では個別に有効化・無効化できる構造化されたお知らせの一覧を管理します。

</Callout>

### トップナビゲーション

- サイトとブランド - トップナビゲーション

![サイトとブランド - トップナビゲーションページ](/assets/guide/feature-guide/system-settings-site-brand-top-navigation.png)

**操作手順**

1. 各リンクの表示スイッチをオンまたはオフにします。
2. 「モデル広場」や「ランキング」の閲覧にログインが必要な場合は、対応する「モデルの閲覧にログインを要求」または「ランキングの閲覧にログインを要求」をオンにします。
3. ページ上部の「ナビゲーションを保存」をクリックします。

<Callout type="info" title="ヒント">

- 対応するリンクがオフの場合、その配下のスイッチは切り替えられません。
- 「ドキュメント」リンクは、「システム情報」の「ドキュメントリンク」で設定した URL に移動します。
- ページ上部の「デフォルトに戻す」をクリックすると、すべてのリンクを表示し、ログインを要求しない状態にフォームが戻ります。この設定を適用するには「ナビゲーションを保存」をクリックします。

</Callout>

**設定項目の説明**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 設定項目 | 定義 | 入力要件と制限 | デフォルト値 |
| --- | --- | --- | --- |
| ホーム | システムの概要を掲載したランディングページです。 | スイッチで切り替えます。 | オン |
| コンソール | ユーザーダッシュボードとクォータ管理へのリンクです。 | スイッチで切り替えます。 | オン |
| ドキュメント | ドキュメントや外部ナレッジベースへのリンクです。 | スイッチで切り替えます。 | オン |
| このサイトについて | プラットフォームを説明する静的ページです。 | スイッチで切り替えます。オフにしても、URL からアクセスできます。 | オン |
| モデル広場 | 公開モデルカタログと料金のページです。 | スイッチで切り替えます。オフにすると、サーバーはモデル料金データの取得を拒否します（Root を除く）。 | オン |
| モデルの閲覧にログインを要求 | 料金カタログの閲覧には事前に認証が必要です。 | 「モデル広場」がオンの場合のみ切り替えられます。未ログインのユーザーがリンクをクリックすると、ログインページにリダイレクトされます。 | オフ |
| ランキング | 実際の利用量データに基づく公開ランキングページです。 | スイッチで切り替えます。オフにすると、サーバーはランキングデータの取得を拒否します。 | オン |
| ランキングの閲覧にログインを要求 | ランキングページの閲覧には事前に認証が必要です。 | 「ランキング」がオンの場合のみ切り替えられます。未ログインのユーザーがリンクをクリックすると、ログインページにリダイレクトされます。 | オフ |

</div>

### サイドバーモジュール

- サイトとブランド - サイドバーモジュール

![サイトとブランド - サイドバーモジュールページ](/assets/guide/feature-guide/system-settings-site-brand-sidebar-module.png)

サイドバーの組み込みリンクの表示は、エリア単位とモジュール単位で切り替えられます。

**操作手順**

1. エリアのスイッチをオンまたはオフにします。
2. オンにしたエリア内で、各モジュールをオンまたはオフにします。
3. ページ上部の「サイドバーモジュールを保存」をクリックします。

<Callout type="info" title="ヒント">

- エリア全体をオフにすると、その配下にあるすべてのモジュールのスイッチが操作できなくなります。エリアを再度オンにすると、各モジュールは個別のスイッチの設定に従って表示されます。
- ページ上部の「デフォルトに戻す」をクリックすると、フォームのすべての項目がオンに戻ります。この設定を適用するには「サイドバーモジュールを保存」をクリックします。
- このページでは、表示可能なモジュールを設定します。サイドバーを個人設定する権限を持つユーザーは、表示可能なモジュールのうち、自分の「チャットエリア」「コンソールエリア」「マイページ」にあるものを非表示にできます。「管理者エリア」のモジュールはサイト全体の設定に従います。
- Root のサイドバーには、サイト全体の設定が適用されます。

</Callout>

**モジュールの説明**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| エリア | エリアの説明 | モジュール |
| --- | --- | --- |
| チャットエリア | Playground での実験とリアルタイムの対話。 | プレイグラウンド、チャット |
| コンソールエリア | ダッシュボード、トークン、利用状況の分析。 | データダッシュボード、トークン管理、利用ログ、監査ログ、画像生成ログ、タスクログ |
| マイページ | ウォレットの管理と個人設定。 | ウォレット、プロフィール、セキュリティとアクセス |
| 管理者エリア | サイト全体の設定と管理ツール。 | チャネル、モデル、引き換えコード、ユーザー、システム設定、サブスクリプション管理 |

</div>

## 保存と反映

保存方法については<a href="/ja/docs/guide/feature-guide/system-settings/system-setting#保存方法" target="_blank" rel="noopener noreferrer">システム設定の概要</a>、設定の反映と複数インスタンス間の同期ルールについては<a href="/ja/docs/guide/feature-guide/system-settings/system-setting#反映範囲と複数インスタンス間の同期" target="_blank" rel="noopener noreferrer">適用範囲と複数インスタンス間の同期</a>、ブラウザーに新しい値が表示されるタイミングについては<a href="/ja/docs/guide/feature-guide/system-settings/system-setting#フロントエンドの表示とキャッシュ" target="_blank" rel="noopener noreferrer">フロントエンドの表示とキャッシュ</a>を参照してください。特に記載がない場合、保存リクエストを処理したノードは新しい値を直ちに使用します。他のノードにはシステム設定の同期によって約 3 秒以内に反映されます（最長で 1 同期周期、デフォルトは 60 秒）。同期周期は環境変数 `SYNC_FREQUENCY` で秒単位で設定できます。デフォルトは 60 秒です。変更後は New API を再起動してください。各設定項目で新しい値が読み込まれるタイミングを以下に示します。

**ブランド、アドレス、ページコンテンツ**

<div className="[&_table]:min-w-[36rem] [&_th]:whitespace-nowrap">

| 設定項目 | 保存方法 | 反映タイミング |
| --- | --- | --- |
| システム名、ロゴ URL、フッター、ドキュメントリンク | ページ上部の「変更を保存」で、変更したフィールドだけを送信します。「リセット」でフォームを元に戻せます。 | ページを再読み込みすると新しい値が表示されます。保存操作を行ったブラウザーでも再読み込みが必要です。 |
| サーバーアドレス | ページ上部の「変更を保存」をクリックします。送信前に末尾の `/` を取り除きます。 | 次にこのアドレスを使用するリクエストから、新しい値が適用されます。保存操作を行ったブラウザーは自動で更新されます。 |
| 非同期タスクの公開アドレス | ページ上部の「変更を保存」をクリックします。送信前に末尾の `/` を取り除きます。値が入力されている場合は、サーバー側で形式を検証します。 | 次回以降のタスク照会では、新しいアドレスを基に成果物の URL が生成されます。発行済みの URL には、発行時のアドレスが使われます。 |
| このサイトについて | ページ上部の「変更を保存」をクリックします。 | 次に「このサイトについて」ページを開いたときに読み込まれます。 |
| ホームページのコンテンツ | ページ上部の「変更を保存」をクリックします。 | 次にホームページを開いたとき、まずブラウザーにキャッシュされたコンテンツが表示され、その後、自動で最新のコンテンツに更新されます。組み込みのホームページに戻すには、フィールドを空にします。 |
| 利用規約、プライバシーポリシー | ページ上部の「変更を保存」をクリックします。 | 文書の本文は開いたときに読み込まれ、ページを再読み込みしない場合は約 10 分間キャッシュされます。ログインページ、登録ページ、フッターのリンクはページの再読み込み後に更新されます。 |

</div>

**お知らせ、ナビゲーション、サイドバー**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

| 設定項目 | 保存方法 | 反映タイミング |
| --- | --- | --- |
| システムのお知らせ | 「通知を保存」で内容全体を書き込みます。 | 通知センターのシステムのお知らせはブラウザーにキャッシュされます。ページを再読み込みすると新しい内容が取得されます。内容が少しでも変わると、再び未読として表示されます。 |
| トップナビゲーション | 「ナビゲーションを保存」で設定全体を書き込みます。「デフォルトに戻す」はフォームに適用されます。 | 保存操作を行ったブラウザーは自動で更新されます。他のブラウザーではページを再読み込みすると反映されます。「モデル広場」と「ランキング」の表示設定とログイン要件は、次のリクエストからサーバー側で適用されます。 |
| サイドバーモジュール | 「サイドバーモジュールを保存」で設定全体を書き込みます。「デフォルトに戻す」はフォームに適用されます。 | 保存操作を行ったブラウザーは自動で更新されます。他のブラウザーではページを再読み込みすると反映されます。設定の適用範囲はサイドバーの表示に限られます。 |

</div>

**補足**

- **項目単位の書き込み**では、「システム情報」の変更されたフィールドのみが送信されます。保存に成功した項目ごとに「設定を更新しました」と表示されます。変更がない場合は「保存する変更はありません」と表示されます。
- **一括書き込み**では、「システムのお知らせ」「トップナビゲーション」「サイドバーモジュール」の設定をセクションごとにまとめて保存します。変更がある場合にのみ送信し、通知を表示します。
- **未保存の変更**が「システム情報」にある状態でセクションを離れようとすると、「未保存の変更」の確認ダイアログが表示されます。「移動する」または「このページにとどまる」を選択できます。

## 注意事項

- **フッターは入力された HTML をそのまま表示します。** 信頼できないスクリプト、イベントハンドラー属性、第三者による挿入コードを含めないでください。
- **「このサイトについて」、ホームページ、法的文書本文に埋め込まれる HTML** では、DOMPurify が `<script>` などのタグを削除するため、スクリプトは実行されません。スタイルや iframe の動作にも分離とサンドボックスによる制限が適用されます。任意のスクリプトに依存する処理は組み込まないでください。
- **外部 URL の埋め込み**は、埋め込み先の `X-Frame-Options` や CSP、混合コンテンツ、証明書の問題によって表示がブロックされることがあります。New API でこれらの制限を回避することはできません。
- **メニューとアクセス制御**において、「ホーム」「コンソール」「ドキュメント」「このサイトについて」とサイドバーモジュールは、リンクを非表示にしても URL からアクセスできます。「モデル広場」をオフにすると、サーバーはモデル料金データの取得を拒否します（Root を除く）。「ランキング」をオフにすると、サーバーはランキングデータの取得を拒否します。「モデルの閲覧にログインを要求」または「ランキングの閲覧にログインを要求」をオンにすると、未ログインのユーザーからの該当アクセスが拒否されます。
- **非同期タスクの公開アドレス**はタスクの成果物の URL の生成にのみ使われるため、インターネットからアクセス可能である必要があります。複数インスタンスで運用する場合は、すべてのノードで同じ `CRYPTO_SECRET` を設定してください。未設定の場合は `SESSION_SECRET` が使用されます。どちらも未設定の場合は起動するたびにシークレットがランダムに生成され、再起動後は発行済みの成果物 URL が検証に失敗します。

<Accordion title="「非同期タスクの公開アドレス」でアドレス形式のエラーが表示される">

**表示メッセージ**は「認証情報、クエリパラメーター、フラグメントを含まない HTTP(S) の絶対 URL を入力してください」です（英語では「Enter an absolute HTTP(S) URL without credentials, query parameters, or fragments」）。

**考えられる原因**は、アドレスが `http://` または `https://` で始まっていないか、クエリパラメーター（`?`）、フラグメント（`#`）、ユーザー情報（`@`）、制御文字、バックスラッシュ、前後の空白が含まれていることです。

**対処方法**

1. 絶対 URL に変更してください。`https://media.example.com/prefix` のようにパスプレフィックスを指定でき、ポートも指定できます。
2. 専用のアドレスが不要な場合は空欄にし、「サーバーアドレス」を使用します。

</Accordion>

<Accordion title="システム名、ロゴ、フッターを保存した後も古い内容が表示される">

**説明**  
保存操作を行ったブラウザーでは、すでに読み込まれているサイト情報を更新するためにページの再読み込みが必要です。

**対処方法**

1. ページを再読み込みします。
2. 複数インスタンスで運用している場合は、数秒待ってから再読み込みします。それでも古い値が表示される場合は、最大で 1 同期周期（デフォルトは 60 秒）待ちます。

</Accordion>

<Accordion title="サイドバーモジュールの保存後、特定のアカウントでリンクの表示が想定と異なる">

**説明**  
サイドバーの表示は 2 段階で決まります。このページの設定で表示可能なリンクが決まり、ユーザーはプロフィールでさらにリンクを非表示にできます。

**考えられる原因**

- 該当するアカウントのプロフィールにある「左サイドバーの個人設定」で、そのモジュールが非表示になっている。
- モジュールが属するエリア全体が、このページでオフになっている。

**対処方法**

1. このページで、エリアとモジュールのスイッチを確認します。
2. 該当するユーザーに、<a href="/ja/docs/guide/feature-guide/user/personal-setting#左サイドバーに表示するページを設定する" target="_blank" rel="noopener noreferrer">プロフィール</a>でサイドバー設定を確認してもらいます。

</Accordion>

</Accordions>
