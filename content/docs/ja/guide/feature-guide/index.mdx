---

New API は、AI モデルのインターフェースを一元的に管理・配信するシステムです。複数の大規模モデルを統一された形式で呼び出すことができ、OpenAI や Claude などの形式に対応しています。個人での利用や企業内でのチャネルの管理・配信に利用でき、プレイグラウンド、OpenAI 互換 API、モデルとチャネルのルーティング、使用ログ、課金、サブスクリプション、システム運用などの機能を提供します。

- 本ガイドは、ロールと機能に応じて、ユーザーガイド、管理者ガイド、システム設定ガイドの 3 部に分かれています。

### システムのホームページ

ホームページは、サイトを開くと最初に表示されるページです。上部のナビゲーションやページ内のボタンから、コンソール、モデルカタログ、ランキング、ドキュメントなどのページに移動できます。

- 機能ガイドの概要：システムのホームページ

![機能ガイドの概要：システムのホームページ画面](/assets/guide/feature-guide/homepage.png)

スーパー管理者（Root）は、「システム設定」→「サイトとブランド」→「システム情報」の「ホームページの内容」に URL、HTML、または Markdown を入力して、ホームページの表示内容を差し替えることができます。このフィールドを空にすると、標準のホームページに戻ります。[「サイトとブランドの設定」→](/ja/docs/guide/feature-guide/system-settings/settings-site#システム情報)

- 機能ガイドの概要：ホームページの内容の設定

![機能ガイドの概要：ホームページの内容の設定画面](/assets/guide/feature-guide/homepage-content-settings.png)

### ロールについて

プラットフォームでは、アカウントのロールに応じて、アクセスできるメニューと操作権限が決まります。ロールは次の 3 種類です。

- **一般ユーザー** <br/>
アカウント登録時のデフォルトのロールです。プレイグラウンド、チャット、概要、ダッシュボード、API キー、使用ログ、監査ログ、タスクログ、ウォレット、プロフィール、セキュリティとアクセスなど、プラットフォームで公開されている個人向け機能を利用できます。<br/>上部ナビゲーション、サイドバーのモジュール、チェックインなどの機能への入り口は、スーパー管理者（Root）が設定します。[「サイトとブランドの設定」→](/ja/docs/guide/feature-guide/system-settings/settings-site)

- **管理者（Admin）** <br/>
Admin は一般ユーザーの権限に加え、デフォルトでチャネル、モデル、ユーザー、引き換えコード、サブスクリプションなどの管理リソースにアクセスできます。<br/>チャネルなどのリソースでは、権限が読み取り、操作、通常の書き込み、機密情報の書き込み、キーの表示などに分かれています。スーパー管理者（Root）は、ユーザー管理で管理者（Admin）アカウントの「管理者権限」を設定し、デフォルトの権限を上書きできます。[「管理者権限」→](/ja/docs/guide/feature-guide/admin/user#管理者権限)

- **スーパー管理者（Root）** <br/>
Root はすべての権限を持ちます。**システム情報**、**プラグイン**、**リクエスト処理**、**システム設定**にもアクセスでき、モデルの価格を変更できます。<br/>システム設定は、サイトとブランド、認証、課金と決済、モデル、リクエストポリシー、セキュリティと制限、コンソールのコンテンツ、運用の 8 つの設定領域に分かれています。[「システム設定の概要」→](/ja/docs/guide/feature-guide/system-settings/system-setting)

## ユーザーガイド

一般ユーザー、Admin、Root を対象に、アカウントの登録とログイン、API キーの作成、モデルの呼び出しから、ログの確認や個人アカウントの管理まで、よく使う操作を説明します。初めて利用する場合は、まず[クイックスタート](/ja/docs/guide/feature-guide/user/quick-start)をお読みください。

### クイックスタート

登録とログインから初めてのモデル呼び出しまでを 6 つのステップで進めながら、コンソールのトップバーとサイドバーの使い方を確認します。

- 基本概念を理解する
- 初めてモデルを呼び出す
- コンソールの画面構成を確認する

[詳細を見る →](/ja/docs/guide/feature-guide/user/quick-start)

### 登録とログイン

アカウントを登録し、アカウント名とパスワード、外部アカウント、またはパスキーを使ってログインし、ログイン時の認証を完了します。パスワードを忘れた場合は、メールでリセットできます。

- アカウント名とパスワードでログインする
- 外部アカウントまたはパスキーでログインする
- ログイン時の認証を完了する
- アカウントを登録する
- 忘れたパスワードをリセットする
- ログインセッションを確認し、ログアウトする

[詳細を見る →](/ja/docs/guide/feature-guide/user/auth)

### プレイグラウンド

ブラウザーでグループとモデルを選び、パラメーターを調整しながらモデルと対話して、応答をテストできます。API 経由でモデルを呼び出すための URL、認証方法、SDK の使用例、対応エンドポイントも確認できます。

- メッセージを送信して応答を確認する
- リクエストパラメーターを調整する
- 会話を管理する
- API の URL と認証
- SDK の使用例
- 対応エンドポイント

[詳細を見る →](/ja/docs/guide/feature-guide/user/playground)

### チャット

New API の設定を各種 AI チャットアプリに簡単にインポートし、テストや日常の利用に役立てることができます。

- チャットプリセットからワンクリックで設定をインポートする
- API キーからワンクリックで設定をインポートする
- チャットアプリを手動で設定する

[詳細を見る →](/ja/docs/guide/feature-guide/user/chat-apps)

### 概要

アカウントのクォータ、使用量、リクエスト数を確認し、セットアップガイドとコマンド例に沿って初めてのモデル呼び出しを実行できます。管理者が公開したお知らせ、API 情報、よくある質問、稼働状況も確認できます。

- セットアップガイドに沿って利用を開始する
- コマンド例をコピーして最初のリクエストを送信する
- クォータと使用量を確認する
- お知らせ、API 情報、よくある質問、稼働時間を確認する

[詳細を見る →](/ja/docs/guide/feature-guide/user/overview)

### ダッシュボード

期間を指定して、モデルの呼び出し回数、トークン消費量、クォータ消費量を確認できます。呼び出しの内訳を API キー別、グループ別、モデル別に確認したり、グラフのデフォルト表示を設定したりすることもできます。

- データを絞り込む
- グラフのデフォルト表示を設定する
- モデル呼び出しの分析結果を確認する
- 呼び出しの振り分け状況を確認する
- ユーザー統計を確認する（管理者のみ閲覧可能）

[詳細を見る →](/ja/docs/guide/feature-guide/user/dashboard)

### API キー

モデルの呼び出しに使う API キーを作成、コピー、管理できます。キーごとにクォータ、有効期限、利用可能なモデル、接続元 IP アドレスを制限でき、CC Switch などのクライアントにワンクリックでインポートできます。

- API キーを作成する
- キーをコピーしてモデルを呼び出す
- CC Switch またはチャットアプリにインポートする
- キーを編集、無効化、または削除する

[詳細を見る →](/ja/docs/guide/feature-guide/user/token)

### 使用ログ

モデル呼び出しごとの使用量と課金額のほか、チャージや返金などによるクォータの増減履歴を確認できます。条件による絞り込みやエクスポートができ、ログの詳細で課金の内訳を照合できます。

- ログを絞り込んで統計を確認する
- ログの詳細を確認する
- ログをエクスポートする

[詳細を見る →](/ja/docs/guide/feature-guide/user/log)

### 監査ログ

アカウントへのログイン、セキュリティ設定、API キー、アクセストークンなどに関する操作履歴を参照し、各操作の日時、操作元、結果を確認できます。

- 監査ログを絞り込む
- 監査ログの詳細を確認する
- イベントの分類

[詳細を見る →](/ja/docs/guide/feature-guide/user/audit-log)

### タスクログ

動画や音楽などの非同期タスクと Midjourney の画像生成タスクについて、状態、進捗、生成結果、失敗の原因を確認できます。タイムアウトと返金のルールについても説明します。

- タスクを絞り込む
- タスクの詳細と生成物を確認する
- 画像生成ログを確認する
- プロンプト、画像、失敗の原因を確認する
- 失敗したタスクの返金を確認する

[詳細を見る →](/ja/docs/guide/feature-guide/user/task-log)

### ウォレット

残高と使用量の確認、オンラインでのチャージ、コードによるクォータの引き換え、サブスクリプションプランの購入、課金設定の選択、紹介報酬の振り替え、注文履歴の確認ができます。支払い方法、チャージ金額、サブスクリプションプラン、紹介報酬は、いずれも管理者が設定します。

- オンラインでチャージする
- 引き換えコード
- 注文履歴を確認する
- サブスクリプションプラン
- 課金設定を選択する
- 紹介報酬を振り替える

[詳細を見る →](/ja/docs/guide/feature-guide/user/wallet)

### プロフィール

アカウント情報と使用量を確認し、通知方法や各種動作、表示言語、左サイドバーに表示するページを設定できます。毎日のチェックインでクォータを受け取ることもできます。

- 通知と動作の設定を変更する
- 表示言語を設定する
- 毎日のチェックインでクォータを受け取る
- 左サイドバーに表示するページを設定する

[詳細を見る →](/ja/docs/guide/feature-guide/user/personal-setting)

### セキュリティとアクセス

パスワードの変更、メールアドレスや外部アカウントの連携、2 段階認証やパスキーの有効化、ログインセッションやアクセストークンの管理ができます。IP アドレスを記録するかどうかの設定や、アカウントの削除もここで行います。

- セキュリティ確認を完了する
- パスワードを変更または設定する
- メールアドレスと外部アカウントを連携する
- 2 段階認証を有効化または無効化し、バックアップコードを再生成する
- パスキーを有効化する、または登録を解除する
- ログインセッションを管理する
- アクセストークンを作成・管理し、アクセス履歴を確認する
- IP アドレスを記録するかどうかを設定する
- アカウントを削除する

[詳細を見る →](/ja/docs/guide/feature-guide/user/security)

### モデルカタログとランキング

このサイトで利用できるモデルと料金、各モデルの性能と呼び出し例を確認できます。使用量に基づくモデル別・プロバイダー別のランキングも閲覧できます。

- モデルを検索して絞り込む
- ビューと料金表示を切り替える
- モデル料金の見方を理解する
- モデルの詳細を確認する
- ランキングを確認する

[詳細を見る →](/ja/docs/guide/feature-guide/user/pricing)

### よくある質問

表示されたメッセージの文面や症状を手掛かりに、呼び出しの失敗、クォータと料金、アカウントとログイン、画面と表示など、複数のページにまたがる問題の原因と対処方法を調べることができます。

- 呼び出しの失敗
- クォータと料金
- アカウントとログイン
- 画面と表示

[詳細を見る →](/ja/docs/guide/feature-guide/user/faq)

## 管理者ガイド

Admin と Root を対象に、日常の管理に使う 9 つのページを説明します。このうち、課金式、システム情報、プラグイン管理、リクエスト処理は Root 専用です。システムレベルの設定項目は、後述のシステム設定ガイドで説明します。

### 課金式（Root 専用）

料金設定エディターで課金式を使い、モデルの料金を設定します。トークン単価、段階料金の適用条件、呼び出し 1 回あたりの料金、リクエストルールを定義し、料金の見積もりとリクエストのシミュレーションで検証できます。クォータの事前差し引き、精算、保存時の検証ルールについても説明します。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/billing-expression)

### チャネル管理

AI サービスプロバイダー、プラグイン、ゲートウェイ、カスタムチャネルを設定し、認証情報、モデル、グループ、ルーティングのマッピング、優先度を管理します。複数のキーの利用やパラメーターの上書きに加え、テスト、残高照会、上流モデルの更新、一括操作ができます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/channel)

### モデル管理

モデル情報、名前のマッチング、モデルカタログでの表示、プロバイダー、事前入力用グループを管理し、上流のモデル情報を同期できます。Root はモデルの料金変更や価格の同期も行えます。デプロイサービスが設定されている場合は、io.net のモデルデプロイも管理できます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/model)

### ユーザー管理

ユーザーアカウント、ステータス、ロール、グループ、クォータ、ログインに使用する連携情報、サブスクリプション、パスキー、2FA を確認・管理します。Root は Admin アカウントの「管理者権限」を設定できます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/user)

### 引き換えコード管理

クォータの引き換えコードを作成、表示、編集、有効化、無効化、削除できます。一括コピー、一括削除、無効なコードの削除にも対応しています。作成時には、引き換えコードを TXT または Markdown ファイルとして保存できます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/redemption)

### サブスクリプション管理

サブスクリプションプランを作成・管理し、有効期間、クォータのリセット周期、グループのアップグレードと元のグループへの復帰、支払い方法を設定します。プランの有効化・無効化や、サブスクリプションのクォータの一括リセットも行えます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/subscription)

### システム情報（Root 専用）

インスタンスの各ノードの状態、リソース指標、ノードごとの同期状態、バックグラウンドのシステムタスクを確認できます。接続が途絶えたインスタンスの記録や、過去のシステムタスクを削除することもできます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/system-info)

### プラグイン管理（Root 専用）

タスク、チャネル、リクエスト処理の 3 種類のプラグインを管理します。公式およびコミュニティのプラグインマーケットの閲覧、ローカルプラグインのアップロード、プラグインの詳細とサンドボックスの確認ができます。プラグインの有効化・無効化やチャネルとの関連付けも管理できます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/task-plugins)

### リクエスト処理（Root 専用）

上流に送信する前にリクエストを検査または変更できます。リクエスト処理インスタンスを追加し、適用範囲、対象モデル、実行順序を設定します。サンプルリクエストで試行してから、チャネルにインスタンスを追加できます。

[詳細を見る →](/ja/docs/guide/feature-guide/admin/request-processing)

グループは、チャネル、ユーザー、API キー、課金設定に共通するルーティングと課金の単位です。メインナビゲーションには独立した項目として表示されなくなりました。呼び出しと課金の記録については[使用ログ](/ja/docs/guide/feature-guide/user/log)を、画像生成の記録とユーザーの非同期タスクについては[タスクログ](/ja/docs/guide/feature-guide/user/task-log)を参照してください。

## システム設定ガイド

システム設定は、インスタンス全体を設定するための Root 専用のワークスペースです。設定は役割に応じて 8 つの領域に分かれています。各領域に共通する設定の保存方法、反映の仕組み、検証の範囲は、概要ページで説明します。

### システム設定の概要

システム設定へのアクセス方法と必要な権限、8 つの設定領域、設定の保存と反映の仕組み、複数インスタンス間の同期、機密性の高い設定と監査記録、変更時に必要な検証について説明します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/system-setting)

### サイトとブランドの設定

サイトの識別情報、公開コンテンツと法的文書、システムのお知らせ、上部ナビゲーション、サイドバーのモジュールを設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-site)

### 認証の設定

アカウント登録、ログイン、OAuth、パスキー、ボット対策、カスタム OAuth ID プロバイダーを設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-auth)

### 課金と決済の設定

クォータと通貨の表示、モデル別・グループ別の料金、決済ゲートウェイ、チェックイン報酬を設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-billing)

### モデルの設定

モデル全体の動作、プロバイダーごとのプロトコルへの対応、io.net のモデルデプロイサービスを設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-models)

### リクエストポリシーの設定

セッションの維持とリトライ、チャネルのヘルスチェックと自動無効化を設定します。リクエストの処理に関する判定記録についても説明します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-request-policies)

### セキュリティと制限の設定

モデルへのリクエストのレート制限、SSRF 対策、API キーの数の上限を設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-security)

### コンソールのコンテンツ設定

ダッシュボード、お知らせ、API の URL、よくある質問、Uptime Kuma、チャットプリセット、画像生成を設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-content)

### 運用設定

動作モード、モデルの性能指標、メールとクォータの通知、Worker プロキシ、ログのメンテナンス、パフォーマンス保護、バージョンチェックを設定します。

[詳細を見る →](/ja/docs/guide/feature-guide/system-settings/settings-operations)
