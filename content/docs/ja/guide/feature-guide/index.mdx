New API は、統一されたAIモデルインターフェース管理および配布システムです。複数の大規模モデルを統一された形式で呼び出すことをサポートし、OpenAIやClaudeなどの形式に対応しています。個人または企業内部でのチャネル管理と配布に利用でき、プレイグラウンド、OpenAI互換インターフェース、モデルとチャネルルーティング、使用量ログ、課金、サブスクリプション、システム運用などの機能を提供します。

- このガイドは、役割に応じてユーザーガイドと管理者ガイドの2つのパートに分かれています。

### 役割の説明

プラットフォームは、アカウントの役割に基づいてメニューアクセスと操作権限を制御します。以下の3つの役割に分かれています。

- **一般ユーザー** <br/>
登録後のデフォルトの役割で、プレイグラウンド、チャットプリセット、概要、ダッシュボード、APIキー、ログ、ウォレット、プロフィールなどのプラットフォームが提供する個人機能を利用できます。<br/>トップナビゲーション、サイドバーモジュール、チェックインなどのエントリは、スーパー管理者（Root）によって設定・制御されます。[「サイトとブランド設定」→](/ja/docs/guide/feature-guide/system-settings/settings-site)

- **管理者（Admin）** <br/>
一般ユーザーの権限に加え、Adminはデフォルトでチャネル、モデル、ユーザー、引き換えコード、サブスクリプションなどの管理リソースにアクセスできます。<br/>チャネルなどのリソースは、読み取り、操作、通常書き込み、機密書き込み、キー表示などのアクションも区別され、スーパー管理者（Root）は管理者（Admin）アカウントに対して権限オーバーライドを設定し、利用可能な権限を管理できます。[「サイトとブランド設定」→](/ja/docs/guide/feature-guide/system-settings/settings-site)

- **スーパー管理者（Root）** <br/>
Rootはすべての権限を持ち、さらに**システム情報** `/system-info` と**システム設定** `/system-settings/site` にアクセスできます。<br/>システム設定は、サイトとブランド、認証、課金と支払い、モデルとルーティング、セキュリティと制限、コンソールコンテンツ、運用保守の7つの設定領域に分かれています。

## ユーザーガイド

一般ユーザー、Admin、Rootに適用され、登録、APIキーの作成、モデルの呼び出し、ログの表示、個人アカウントの管理などの一般的なプロセスをカバーします。

登録、アカウントパスワードログイン、パスワードリセット、Passkey、サードパーティOAuth、ログインセッション管理について学びます。

- アカウントパスワードログイン
- PasskeyとサードパーティOAuthログイン
- 登録プロセス
- ログインセッション管理
- パスワードリセット

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/auth)

### 概要とダッシュボード

概要ページでは、クイックスタートウィザード、APIリクエスト例、残高と使用量の概要、パフォーマンスヘルス、お知らせ、FAQ、稼働状況などのモジュール情報を提供します。<br/>
ダッシュボードでは、モデル呼び出し分析、トラフィック分散、ユーザー分析（adminとrootのみ）を提供します。

- クイックスタートウィザード
- 使用量とヘルスステータス
- API情報、お知らせ、FAQ、稼働時間
- モデル呼び出し分析
- トラフィック分散
- ユーザー統計

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/dashboard)

### プロフィールとセキュリティ

アカウント情報、バインド情報、通知と行動設定、セキュリティ設定、2FA管理、Passkey管理、ログインセッション管理などの個人設定を表示または管理します。

- アカウント情報の表示
- アカウントバインド情報の管理
- 通知と行動設定
- インターフェース言語設定
- 個人の左サイドバーのパーソナライズ表示設定
- 毎日チェックイン
- セキュリティ設定
- 2段階認証（2FA）の有効化または無効化
- Passkeyパスワードレスログインの有効化または無効化
- ログインセッション管理

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/personal-setting)

### APIキー

APIキーを管理します。APIキーはゲートウェイAPIを呼び出すための認証情報であり、クォータ、有効期限、モデル制限、グループ、自動グループ順序、グループ間リトライ、IPホワイトリストなどのパラメータを個別に設定できます。

- APIキーの作成
- APIキーの表示とコピー
- APIキーの編集
- APIキーの有効化、無効化、削除

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/token)

### APIとプレイグラウンドの使用

プレイグラウンドを使用してAIモデルをオンラインでテストおよび体験します。または、APIキーとOpenAI互換インターフェースを使用して、Claude、Gemini、Responses、画像、音声などのエンドポイントを呼び出します。

- プレイグラウンド
- APIアドレスと認証
- SDKの例
- サポートされているインターフェースエンドポイント

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/api)

### チャットアプリケーション連携

New API は、複数のAIチャットアプリケーションへの設定の迅速なインポートをサポートしており、テストや日常使用に便利です。<br/>

- New API のチャット連携には3つの方法があります。
1. チャットプリセットの一括インポート設定
2. APIキーの一括インポート設定
3. チャットアプリケーションの手動設定

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/chat-apps)

- 使用ログ
- 描画ログ
- 非同期タスクログ
- タスクステータスとバックグラウンド処理
- インターフェースリファレンス：ログクエリインターフェース、非同期生成とタスクインターフェース

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/log)

### ウォレットとサブスクリプション

ウォレット残高の表示と管理、オンラインでの残高チャージ、引き換えコードによる残高引き換え、注文履歴の表示、サブスクリプションプラン、招待報酬の表示と受け取り、課金設定の選択を行います。支払い方法、金額、割引、報酬、プラン、課金ルールはすべてプラットフォーム管理者が設定します。

- 残高と使用量の表示
- オンラインチャージ
- 引き換えコード
- サブスクリプションプラン
- サブスクリプションプランの購入
- サブスクリプションステータスの表示
- 課金設定の選択
- 招待報酬
- 注文履歴
- 一般的な制限

[詳細ドキュメントを見る →](/ja/docs/guide/feature-guide/user/wallet)

### モデル広場とランキング
