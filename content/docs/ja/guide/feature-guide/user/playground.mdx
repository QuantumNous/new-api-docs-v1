- サイドバーの「チャット」→「プレイグラウンド」からアクセスします。
- Web ページでモデルと対話し、モデルの応答やリクエストパラメーターをテストできます。
- モデルを呼び出すと、料金に応じてアカウントのクォータ（ウォレット残高またはサブスクリプションのクォータ）が差し引かれます。

<Callout type="info" title="ヒント">

- プレイグラウンドでは、ログイン中のアカウントでモデルを呼び出します。API キーは使用しないため、キーのクォータ、モデル制限、IP 制限は適用されず、どのキーの使用済みクォータにも加算されません。
- チャット履歴はログインアカウントごとに現在のブラウザーにのみ保存され、サーバーには送信されません。
- 左のサイドバーに「プレイグラウンド」が表示されない場合<br/>「プロフィール」ページの「左サイドバーの個人設定」で「チャットエリア」と「プレイグラウンド」を有効にして保存します。
</Callout>

## メッセージを送信して応答を確認する

**操作手順**

1. 入力欄右下のグループとモデルの選択ボタンをクリックし、左側の「モデルグループ」でグループを選び、右側でモデルを選びます。
2. 必要に応じて入力欄の下にあるパラメーターアイコンをクリックし、「パラメーター設定」でパラメーターを有効にして調整します。詳しくは、[リクエストパラメーターを調整する](#リクエストパラメーターを調整する)を参照してください。
3. 入力欄に質問、指示、またはプロンプトを入力します。
4. 「送信」をクリックするか、Enter を押してリクエストを送信します。
5. チャット欄に順次表示されるモデルの応答を確認します。生成を中断するには「停止」をクリックします。

<Callout type="info" title="ヒント">

- グループを切り替えたとき、選択中のモデルが新しいグループに含まれていない場合は、新しいグループの先頭のモデルが自動で選択されます。
- 推論モデルの思考過程は応答の上に表示されます。生成中は「思考中...」、完了後は「… 秒間思考しました」と表示され、クリックで展開または折りたたみができます。
- 「停止」をクリックしても、すでに出力された内容はチャットに残ります。
- 入力欄の下にある「添付」と「検索」は、現在開発中です。クリックするとそれぞれ「機能開発中」「検索機能開発中」と表示されます。ファイルや画像の送信、Web 検索は利用できません。
</Callout>

**設定項目**

グループとモデルの選択画面は左右 2 列に分かれています。下の表は左から右の順に並んでいます。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 設定項目 | 定義 | 入力要件と制限 | デフォルト値 |
| --- | --- | --- | --- |
| グループ | モデルの呼び出しに使用するグループです。利用可能なモデルと課金倍率が決まります。 | 左側の「モデルグループ」で選択します。アカウントが所属するグループを含め、そのアカウントに利用権限のあるグループのみが表示されます。サイトの設定で許可されている場合は、`auto`（システムが利用可能なグループを自動で選択）も表示されます。一覧にはグループ名のみが表示されます。 | `default`。このグループがない場合は、一覧の先頭のグループが選択されます。以降は前回の選択が引き継がれます。 |
| モデル | このチャットで呼び出すモデルです。 | 右側の一覧から選択します。「モデルを検索...」で名前を検索でき、一致するモデルがない場合は「モデルが見つかりません。」と表示されます。一覧には選択したグループで利用可能なモデルが表示され、API キーの「モデル制限」は適用されません。 | `gpt-4o`。一覧にない場合は、一覧の先頭のモデルが選択されます。以降は前回の選択が引き継がれます。 |

## リクエストパラメーターを調整する

**操作手順**

1. 入力欄の下にあるパラメーターアイコンをクリックし、「パラメーター設定」を開きます。アイコンにカーソルを合わせると「パラメーター」と表示されます。
2. リクエストに含めるパラメーターの右側にあるスイッチをオンにします。
3. スライダーをドラッグするか、数値を入力します。

<Callout type="info" title="ヒント">

- リクエストとともに送信されるのは、有効にしたパラメーターのみです。パラメーターの値とスイッチの状態は現在のブラウザーに保存され、次回開いたときに引き継がれます。
- モデルによっては一部のパラメーターに対応していません。送信後にエラーが発生した場合は、該当するパラメーターを無効にして再試行してください。
- プレイグラウンドには、システムプロンプトを指定する設定やストリーミング出力を無効にする設定はありません。応答は常に順次出力されます。
</Callout>

**設定項目**

「パラメーター設定」ウィンドウには区分がなく、各パラメーターの右側にスイッチがあります。下の表はウィンドウに表示される順に並んでいます。

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 設定項目 | 定義 | 入力要件と制限 | デフォルト値 |
| --- | --- | --- | --- |
| 温度 | 出力のランダム性と創造性を調整します。 | スライダーをドラッグして、0.1～1 の範囲で 0.1 刻みに調整します。 | 0.7、有効 |
| Top P | 累積確率に基づいてトークンの選択範囲を制限します。 | スライダーをドラッグして、0.1～1 の範囲で 0.1 刻みに調整します。 | 1、有効 |
| 頻度ペナルティ | 同じ表現の繰り返しを抑えます。 | スライダーをドラッグして、-2～2 の範囲で 0.1 刻みに調整します。 | 0、有効 |
| 存在ペナルティ | 新しい話題を取り上げるよう促します。 | スライダーをドラッグして、-2～2 の範囲で 0.1 刻みに調整します。 | 0、有効 |
| 最大トークン数 | 応答の長さを制限します。 | 0～200000 の整数を入力します。範囲外の値は、最も近い有効値に自動で補正されます。 | 4096、無効 |
| 乱数シード | 対応モデルの応答の再現性を高めます。 | 0～2147483647 の整数を入力します。未入力の場合は「未設定」と表示され、有効にしていても送信されません。 | 未設定、無効 |
</div>

## チャットを管理する

**再生成の手順**

1. 再生成したいメッセージにカーソルを合わせます。
2. メッセージの下にある再生成アイコンをクリックします。アイコンにカーソルを合わせると「再生成」と表示されます。

**編集の手順**

1. メッセージの下にある編集アイコンをクリックします。
2. テキスト欄で内容を編集します。
3. ユーザーメッセージを編集した場合は、「保存して送信」をクリックすると、編集後の内容で応答が再生成されます。変更だけを保存する場合は「保存」をクリックします。

**削除の手順**

1. メッセージの下にある削除アイコンをクリックします。

**チャット履歴を消去する手順**

1. 入力欄の下にあるごみ箱アイコンをクリックします。アイコンにカーソルを合わせると「チャット履歴を消去」と表示されます。
2. 「チャット履歴を消去しますか？」ウィンドウで「消去」をクリックします。

<Callout type="warn" title="注意">
消去したチャット履歴は復元できません。消去の対象はメッセージのみで、グループ、モデル、パラメーターはそのまま保持されます。
</Callout>

<Callout type="info" title="ヒント">

- メッセージを送信するたびに、チャット内の既存のメッセージもコンテキストとしてモデルに送信されます。思考過程は送信されません。新しい話題を始める前に、チャット履歴を消去してください。
- 応答の生成中は、再生成、編集、削除、チャット履歴の消去はできません。
- 画面幅が狭い場合は、メッセージの操作がメッセージ下部の ⋯ メニューにまとまります。
</Callout>

## API アドレスと認証

ゲートウェイの OpenAI 互換 URL は通常、以下のとおりです。

```text
https://your-host/v1
```

API キーを Bearer トークンとして使用します。

```http
Authorization: Bearer sk-your-api-key
```

以下はチャット補完の例です。

```bash
curl https://your-host/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-api-key" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"你好"}]}'
```

## SDK のサンプル

### Python（OpenAI SDK）

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://your-host/v1",
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

### Claude ネイティブ形式

```bash
curl https://your-platform.com/v1/messages \
  -H "x-api-key: sk-xxxxxxxx" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model": "claude-3-5-sonnet-20241022", "max_tokens": 1024, "messages": [{"role": "user", "content": "Hello"}]}'
```

### Gemini ネイティブ形式

```bash
curl "https://your-platform.com/v1beta/models/gemini-1.5-pro:generateContent?key=sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"contents": [{"parts": [{"text": "Hello"}]}]}'
```

## 対応エンドポイント

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| インターフェース | パス | 説明 |
| --- | --- | --- |
| チャット補完 | `POST /v1/chat/completions` | OpenAI Chat Completions 互換インターフェースです。`model` と `messages` が必須で、ストリーミング応答と通常の応答に対応します。 |
| テキスト補完 | `POST /v1/completions` | 従来のテキスト補完インターフェースです。`prompt` と `model` が必須です。 |
| ベクトル埋め込み | `POST /v1/embeddings` | テキストまたはテキストの配列をベクトルに変換します。`input` が必須で、チャネルアダプターがアップストリームの形式に変換します。 |
| 画像生成 | `POST /v1/images/generations` | プロンプトに基づいて画像を生成します。利用できるモデル、サイズ、品質、枚数は、リクエストパラメーターと設定済みのチャネルによって異なります。 |
| 画像編集 | `POST /v1/images/edits` | 入力画像をプロンプトに基づいて編集します。JSON と `multipart/form-data` のリクエストに対応します。 |
| 旧版の編集インターフェース | `POST /v1/edits` | 旧版のパスは保持されていますが、現在は利用できません。画像編集には `/v1/images/edits` を使用してください。 |
| 音声文字起こし | `POST /v1/audio/transcriptions` | 音声をテキストに変換します。OpenAI Audio API の形式で、対応する音声認識チャネルに転送します。 |
| 音声翻訳 | `POST /v1/audio/translations` | 音声の内容を認識し、翻訳したテキストを出力します。 |
| 音声合成 | `POST /v1/audio/speech` | 入力テキストを音声に変換します。 |
| リランキング | `POST /v1/rerank` | `query` に対する関連度に基づいて、候補の `documents` を並べ替えます。クエリと文書リストには空でない値が必要です。 |
| モデレーション | `POST /v1/moderations` | テキストなどの入力をモデレーションします。モデルを指定しない場合は、デフォルトのモデレーションモデル候補が使用されます。 |
| Responses API | `POST /v1/responses` | OpenAI Responses 形式のインターフェースです。入力、ツール、応答イベントなどに対応します。 |
| Responses WebSocket | `GET /v1/responses`（WebSocket） | Responses インターフェースに WebSocket で接続し、接続後に `response.create` イベントを送信して応答を作成します。最初の `response.create` イベントを受信した時点でチャネルが選択されます。API キーの渡し方はリアルタイム対話と同じです。 |
| Responses の圧縮 | `POST /v1/responses/compact` | Responses リクエストのコンテキストを圧縮します。 |
| Codex Web 検索 | `POST /v1/alpha/search` | Codex の独立した Web 検索形式に対応するインターフェースです。現在、この機能に対応する Sub2API、New API、Codex、高度なカスタムチャネルのみが処理できます。 |
| DeepSeek 検索 | `POST /v1/tools/search` | DeepSeek の検索インターフェースです。リクエストボディをそのまま転送し、応答もそのまま返します。チャネルの選択には常に `deepseek-search` モデルを使用し、リクエスト単位で課金します。トークン数はカウントしません。現在、DeepSeek、New API、Sub2API、高度なカスタムチャネルのみが処理できます。 |
| DeepSeek Web ページ取得 | `POST /v1/tools/fetch` | DeepSeek の Web ページ取得インターフェースです。チャネルの選択には常に `deepseek-fetch` モデルを使用し、リクエスト単位で課金します。転送方法と利用可能なチャネルは DeepSeek 検索と同じです。 |
| Claude Messages | `POST /v1/messages` | Anthropic Claude Messages 互換インターフェースです。`model` とメッセージの内容が必須です。必要に応じて New API がアップストリームのプロトコルに変換します。`/v1/messages/count_tokens` は現在無効です。 |
| リアルタイム対話 | `GET /v1/realtime`（WebSocket） | OpenAI Realtime 形式の双方向リアルタイム通信インターフェースです。通常、モデルはクエリパラメーターで指定します。API キーは Bearer トークンまたは WebSocket サブプロトコルで渡せます。 |
| Gemini ネイティブ形式でのモデル呼び出し | `POST /v1beta/models/{model}:{action}` | Gemini ネイティブ形式のインターフェースです。`generateContent`、`streamGenerateContent`、埋め込み関連の操作などのモデル操作パスに対応します。`:countTokens` は現在未対応で、404 を返します。 |
| Gemini 互換形式でのモデル呼び出し | `POST /v1/models/{model}:{action}` | `/v1` プレフィックスで Gemini 形式のモデル操作リクエストを受け付けます。Gemini Relay が解析と変換を行います。 |
| モデル一覧 | `GET /v1/models` | デフォルトでは、OpenAI 形式でモデル一覧を返します。`x-api-key` と `anthropic-version` の両方のリクエストヘッダーがある場合は Claude 形式、`x-goog-api-key` リクエストヘッダーまたは `key` クエリパラメーターがある場合は Gemini 形式で返します。 |
| モデルの詳細 | `GET /v1/models/{model}` | 指定したモデルの情報を取得します。モデルが存在しない場合は `model_not_found` エラーオブジェクトを返します（HTTP ステータスコードは 200）。 |
| Gemini モデル一覧 | `GET /v1beta/models` | 利用可能なモデル一覧を Gemini 形式で返します。レスポンスフィールドには `models` と `nextPageToken` が含まれます。 |
| OpenAI 形式のモデル一覧 | `GET /v1beta/openai/models` | Gemini 互換の名前空間で、OpenAI 形式のモデル一覧を返します。 |
</div>

<Accordion title="モデル一覧が空、または「送信」が使えない">
**表示メッセージ**

「playground のモデルの読み込みに失敗しました」（英語では Failed to load playground models）または「playground のグループの読み込みに失敗しました」（英語では Failed to load playground groups）。メッセージが表示されない場合もあります。

**考えられる原因**

- 選択したグループに利用可能なモデルがありません。
- アカウントに利用可能なグループがなく、グループとモデルの選択欄を使用できません。
- 入力欄が空か、モデル一覧を読み込み中です。

**対処方法**

1. グループとモデルの選択欄の左側で、別のグループに切り替えます。
2. ブラウザーでページを再読み込みし、再試行します。
3. 解決しない場合は、モデルやグループを利用できるよう管理者に依頼してください。
</Accordion>

<Accordion title="送信後に「エラー」と「リクエストでエラーが発生しました: …」が表示される">
**説明**

エラーが発生した応答は、赤い「エラー」枠に表示されます。「リクエストでエラーが発生しました: 」に続いてサーバーから返されたメッセージが表示され、その下に「再試行」「編集」「削除」があります。エラーが発生した応答が会話に残っていると、次のメッセージの送信時に、その応答もコンテキストとしてモデルに送信されます。新しいメッセージを送信する前に「再試行」または「削除」をクリックしてください。表示されたメッセージに応じて、以下の対処方法を確認してください。

| 表示メッセージ | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| 「このグループにアクセスする権限がありません」（英語では No permission to access this group） | 管理者によるグループ設定の変更などにより、選択したグループがアカウントで利用できなくなっています。 | ブラウザーでページを再読み込みし、グループを選び直します。 |
| 「グループ … のモデル … に利用可能なチャネルがありません（distributor）」（英語では No available channel for model … under group … (distributor)） | 選択したグループでは、そのモデルに対応するチャネルが一時的に利用できません。 | グループまたはモデルを切り替えます。解決しない場合は、管理者にお問い合わせください。 |
| 「ユーザークォータが不足しています。残りのクォータ: …」（英語では Insufficient user quota, remaining quota: …）<br/>「クォータの事前引き落としに失敗しました。ユーザーの残りのクォータ: …、事前引き落としに必要なクォータ: …」（英語では Not enough quota to pre-consume for this request: … remaining, … required） | アカウントの残高が不足しています。 | <a href="/ja/docs/guide/feature-guide/user/wallet" target="_blank" rel="noopener noreferrer">ウォレット</a>でチャージまたはクォータの引き換えを行います。 |
| 「サブスクリプションのクォータが不足しているか、サブスクリプションが設定されていません: …」（英語では Subscription quota is insufficient or no subscription is configured: …） | このリクエストはサブスクリプションのクォータから差し引かれますが、クォータが不足しているか、利用可能なサブスクリプションがありません。 | <a href="/ja/docs/guide/feature-guide/user/wallet#サブスクリプションプラン" target="_blank" rel="noopener noreferrer">ウォレット</a>でサブスクリプションを確認します。 |
| 上流サービスから返されたその他のエラー（多くは英語） | 上流サービスが混雑しているか、レート制限または障害が発生しています。 | しばらく待ってから「再試行」をクリックするか、モデルやグループを切り替えます。 |
</Accordion>

<Accordion title="「モデルの価格が設定されていません」と表示される">
**表示メッセージ**

「モデル … の価格が管理者によって設定されていないため、現在は利用できません。サイト管理者に連絡して、このモデルを有効にしてもらってください」（英語では Model … has not been priced by the administrator yet. Please contact the site administrator to enable this model.）

**説明**

モデル一覧には、利用可能なモデルがグループごとに表示されます。価格の設定状況は確認されません。価格が未設定のモデルにメッセージを送信すると、オレンジ色の「モデルの価格が設定されていません」カードが表示され、料金は発生しません。管理者アカウントには「モデル … の価格が設定されていません。「システム設定 → 運用設定」で自己利用モードを有効にするか、「システム設定 → グループとモデルの価格設定」でこのモデルの価格を設定してください」と表示されます。カードには、管理者にのみ表示される「設定を開く」ボタンもあります。このボタンをクリックすると、システム設定のモデル価格設定ページが新しいタブで開きます。このページにアクセスできるのは Root のみです。

**対処方法**

1. グループとモデルの選択欄で、別のモデルを選択します。
2. このモデルを使用する必要がある場合は、管理者に価格の設定を依頼してください。
</Accordion>

<Accordion title="送信後に応答がない、または応答が空">
**考えられる原因**

- モデルが応答本文を返していません。たとえば、思考過程のみが返された場合は「… 秒間思考しました」だけが表示されます。
- 「最大トークン数」が有効になっており、設定値が小さすぎます。
- 上流サービスから長時間応答がなく、「応答中...」と表示され続けています。

**対処方法**

1. 「応答中...」と表示され続けている場合は、「停止」をクリックします。
2. 「パラメーター設定」で「最大トークン数」を無効にするか、設定値を増やします。
3. 直前のユーザーメッセージの下にある再生成アイコンをクリックするか、モデルを変更して再試行します。
</Accordion>

<Accordion title="会話履歴が見つからない">
**考えられる原因**

- 会話履歴は現在のブラウザーにのみ保存されます。別のブラウザーやデバイス、またはプライベートブラウジングウィンドウを使用しています。
- ブラウザーのサイトデータを削除しました。
- ログインアカウントを切り替えました。会話履歴はアカウントごとに保存されます。
- 会話欄には直近の 24 件のメッセージのみが表示されます。それより前のメッセージも現在のブラウザーに保存されており、メッセージを送信するたびにコンテキストとしてモデルに送信されます。
- メッセージが 100 件を超えると、直近の 100 件のみが保持されます。
- サイトが旧バージョンからアップグレードされた後は、旧バージョンで保存した会話履歴は保持されません。

**対処方法**

1. 以前使用していたブラウザーで同じアカウントにログインし、会話履歴を確認します。
2. 長期保存が必要な内容は、メッセージの下にあるコピーアイコンを使って別途保存してください。
</Accordion>

<Accordion title="利用ログにプレイグラウンドの呼び出しが見つからない、または API キーの使用済みクォータが変わらない">
**説明**

プレイグラウンドでは API キーを使用しません。呼び出しにかかる料金はアカウントのクォータから差し引かれ、API キーの使用済みクォータには計上されません。成功した呼び出しは利用ログに「消費」として記録され、「トークン」列には `playground-default` のように、`playground-` に選択したグループ名を付けた名前が表示されます。呼び出しに失敗した場合は、料金は発生しません。サイトでエラーログの記録が有効になっていない場合、失敗したリクエストは記録されません。

**対処方法**

1. <a href="/ja/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">利用ログ</a>の「トークン名」に `playground-default` などの完全な名前を入力します。
2. 呼び出しが行われた時間帯に絞り込み、「検索」をクリックします。
</Accordion>

<Accordion title="「プレイグラウンド」をクリックすると「概要」ページに戻る">
**考えられる原因**

管理者が「プレイグラウンド」を無効にしています。

**対処方法**

1. API キーを使用してモデルを呼び出します。詳細は [API アドレスと認証](#api-アドレスと認証)を参照してください。
2. プレイグラウンドを使用する必要がある場合は、管理者にお問い合わせください。
</Accordion>

<Accordion title="「添付」または「検索」をクリックすると「機能は開発中です」と表示される">
**表示メッセージ**

「機能は開発中です」（英語では Feature in development）または「検索機能は開発中です」（英語では Search feature in development）

**説明**

「添付」メニューの「ファイルをアップロード」「写真をアップロード」「スクリーンショット」「写真を撮る」と、「検索」はいずれも未実装です。プレイグラウンドでは、ファイルや画像の送信、ウェブ検索は利用できません。

**対処方法**

1. テキストのみを送信します。
2. ファイルや画像を送信する必要がある場合は、その機能に対応するクライアントから API を呼び出してください。
</Accordion>

</Accordions>
