左側のナビゲーションで「APIキー」をクリックするか、直接 `/keys` にアクセスしてください。ページには、キー名、マスクされたキー、有効化ステータス、クォータ使用状況、グループなどの情報が表示され、フィルタリング、コピー、編集、有効化/無効化、一括削除がサポートされています。行メニューからは、接続情報のコピー、管理者設定のチャットプリセットのオープン、およびサポートされているクライアント統合へのキーの送信も可能です。

![API密钥信息页](/assets/guide/feature-guide/keys-info.png)

## APIキーの作成

1. 「APIキー」を開き、「APIキーの作成」をクリックします。
2. アプリケーションや環境を区別しやすいように、キー名を入力します。
3. 必要に応じて、クォータ、有効期限、モデル制限、IP制限、グループを設定します。
4. 保存後、リストから完全なキーを確認し、コピーします。

![创建API密钥页](/assets/guide/feature-guide/create-key.png)

### 設定項目の説明

| 設定 | 機能 |
| --- | --- |
| 名前 | APIキー名（「本番環境」「テスト用」など、用途に応じて命名することをお勧めします） |
| グループ | このトークンが使用するチャネルグループを指定します |
| 自動グループ順序 | グループが `auto` の場合にのみ表示されます。Rootのグローバル順序を継承することも、キーレベルの順序を設定することもできます。 |
| グループ間リトライの切り替え | 有効にすると、現在のグループチャネルが失敗した場合、次のグループのチャネルが順番に試行されます。 |
| 有効期限 | 期限切れ後、このキーの使用を拒否します |
| 数量 | 複数のAPIキーを一度に作成できます（名前にランダムなサフィックスが追加されます） |
| クォータ | このキーが消費できるクォータを制限します |
| 無制限クォータの切り替え | 有効にすると、このAPIキーに無制限のクォータが適用されます |
| モデル制限 | このトークンが指定されたモデルのみを呼び出せるように制限します。空欄の場合、制限なしを意味します。 |
| IPホワイトリスト | IPまたはCIDRを1行ずつ入力できます。空欄の場合、制限なしを意味します。信頼できるリバースプロキシ/CDNと組み合わせて使用する必要があります。 |

<Callout type="warn">
  APIキーはパスワードと同等です。完全なキーをコードリポジトリ、スクリーンショット、ログ、またはチャットツールにコミットしないでください。漏洩が疑われる場合は、直ちに削除し、新しいキーを作成してください。
</Callout>

## APIキーの表示とコピー

APIキーリストでマスクされたキーをクリックし、ページプロンプトに従って完全な値を確認およびコピーします。完全なキーは機密性の高い認証情報であり、表示には追加のセキュリティ認証が必要になる場合があります。

「接続情報をコピー」は、キーとプラットフォームアドレスをアプリケーションのインポート情報としてコピーします。左サイドバーの「チャット」にある対象のプリセットチャットアプリケーションをクリックすると、ブラウザはインストールされているチャットアプリケーションを起動しようとし、自動的に設定情報を入力してジャンプします。
![查看API密钥页](/assets/guide/feature-guide/view-key.png)

## APIキーの編集

APIキーリストで対象のキーを見つけ、右側の「編集」ボタンをクリックすると、キーの設定オプション（APIキー自体は除く）を変更できます。

![编辑API密钥页](/assets/guide/feature-guide/edit-key.png)

## APIキーの有効化、無効化、および削除

リストの行操作でキーを有効化、無効化、または削除できます。複数行を選択すると一括削除が可能です。無効化すると設定は保持され、呼び出しは停止しますが、削除すると元に戻せません。

![删除API密钥页](/assets/guide/feature-guide/delete-key.png)

<Callout type="warn">
  削除確認後、このAPIキーは直ちに無効になり、復元できません。削除する前に、選択したキーを確認し、本番環境のキーを誤って削除しないようにしてください。
</Callout>
