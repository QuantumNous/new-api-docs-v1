アカウント登録、パスワード忘れ時のリセット、アカウントとパスワードでのログイン、Passkeyおよび複数のサードパーティOAuthによるワンクリックログインをサポートしています。初めてご利用になる場合は、まず登録を完了してください。

## ログイン

### アカウントとパスワードでのログイン

1.  プラットフォームのホームページを開き、右上の「ログイン」ボタンをクリックするか、直接 `/sign-in` にアクセスします。
2.  ユーザー名またはメールアドレスとパスワードを入力します。
3.  ページにCloudflare Turnstileが表示された場合、人間認証を完了する必要があります。
4.  まず、ユーザー規約とプライバシーポリシーを読み、同意することを確認してから、「ログイン」をクリックします。
5.  アカウントで2FAが有効になっている場合、ログイン時にワンタイム認証コードまたはバックアップコードの入力が追加で必要になります。

![ログインページ](/assets/guide/feature-guide/login.png)

### PasskeyとサードパーティOAuthログイン

ログインページには、プラットフォームで有効になっているGitHub、Discord、LinuxDOなどのサードパーティプラットフォームまたはPasskeyのアイコンが表示されます。サードパーティアカウントまたはPasskeyを使用してログインするには：
1.  ユーザー規約とプライバシーポリシーを読み、同意することをクリックします。
2.  ページ下部にある対応するプラットフォームのアイコン（GitHub、Discord、LinuxDOなど）またはPasskeyアイコンをクリックします。
3.  サードパーティアカウントを使用する場合、サードパーティの認証ページにリダイレクトされ、認証を完了します。Passkeyを使用する場合、ブラウザまたはデバイスの指示に従って認証を完了します。

![OAuthログインページ](/assets/guide/feature-guide/login.png)

<Callout type="info">
  PasskeyとサードパーティOAuthログイン方法、および人間認証を有効にするかどうかは、プラットフォームのスーパー管理者（Root）が「システム設定」→「認証」で有効にします。有効になっていない方法はログインページには表示されません。
</Callout>

## 登録

### 登録フロー

1.  ログインページで「登録」をクリックするか、直接 `/sign-up` にアクセスします。
2.  ユーザー名、パスワード、確認用パスワードを入力します。
3.  プラットフォームの設定でメール認証が要求される場合、メールアドレスを入力し、認証コードを送信して、受信した認証コードを入力します。
4.  プラットフォームでCloudflare Turnstileが有効になっている場合、人間認証を完了する必要があります。
5.  まず、ユーザー規約とプライバシーポリシーを読み、同意することを確認してから、「アカウント作成」をクリックして登録を完了します。

![登録ページ](/assets/guide/feature-guide/register.png)

<Callout type="info">
  パスワード登録、OAuth登録、メール認証、およびメールのドメイン/エイリアス制限を許可するかどうかは、すべてRootの認証設定によって決定されます。
</Callout>

### ログインセッション管理

ログインに成功すると、独立したセッションが確立されます。ログイン済みのユーザーは、左サイドバーの「プロフィール」→「ログインセッション」エリアをクリックして、現在および他のデバイスでのログインセッションを表示したり、個別のセッションを取り消したり、一度に他のすべてのセッションからログアウトしたりできます。現在のセッションを取り消すと、ログインページに戻ります。

![ログインセッションページ](/assets/guide/feature-guide/login-session.png)

## パスワードのリセット

1.  ログインページで「パスワードを忘れた場合」をクリックします。
2.  アカウントに関連付けられているメールアドレスを入力し、送信します。
3.  システムから送信されたリセットリンクを開きます。
4.  リセットページで新しいパスワードを設定し、再度ログインします。

![パスワード忘れページ](/assets/guide/feature-guide/forgot-password.png)
