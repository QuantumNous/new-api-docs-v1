- New API の設定はさまざまな AI チャットアプリにすばやくインポートでき、テストや日常の利用に便利です。

## チャットアプリとの連携方法

- New API とチャットアプリを連携する方法は次の 3 つです。
1. **チャットプリセットから設定をワンクリックでインポートする**
2. **API キーから設定をワンクリックでインポートする**
3. **チャットアプリを手動で設定する**

### 事前準備

1. New API にログインし、「API キー」ページでキーを作成します。
2. キーが有効で、利用可能なクォータが十分に残っており、有効期限が切れていないことを確認します。また、現在の IP アドレス、グループ、モデルに関する制限で、今回の呼び出しが許可されていることを確認します。

<Callout type="info" title="ヒント">
  **API キーの作成方法と使用方法については、<a href="/ja/docs/guide/feature-guide/user/token" target="_blank" rel="noopener noreferrer">API キー</a>のページを参照してください。**
</Callout>

### チャットプリセットから設定をワンクリックでインポートする

- チャット：チャットプリセットからのワンクリックインポート

![チャット：チャットプリセットから設定をワンクリックでインポートする画面](/assets/guide/feature-guide/chat-chat-presets-one-click-configuration-import.png)

**操作手順：**
1. 左サイドバーの「チャット」の右にある矢印をクリックし、プラットフォームに設定されているチャットプリセットを展開します。
2. 使用するチャットプリセットをクリックします。
3. ブラウザーにチャットアプリを開くかどうかを確認するメッセージが表示されたら、「開く」をクリックします。
4. 対象のアプリに自動的に切り替わり、設定情報が入力されます。

<Callout type="info" title="ヒント">
  - サイドバーの「チャット」では、有効なキーのうち最後に作成されたものが自動的に使用されます。別のキーを使用する場合は、[API キーから設定をワンクリックでインポートする](#api-キーから設定をワンクリックでインポートする)を参照してください。
  - 名前の右に外部リンクアイコンがないものは Web アプリです。クリックすると、このサイトのページ内で開きます。それ以外はデスクトップアプリなので、あらかじめコンピューターにインストールしてください。
  - ブラウザー拡張機能（「FluentRead」など）はサイドバーには表示されません。「API キー」ページの ⋯ →「チャット」からのみ使用できます。
  - チャットプリセットは、Root が「システム設定」→「コンソールコンテンツ」→「チャットプリセット」で管理します。
</Callout>

### API キーから設定をワンクリックでインポートする

- チャット：API キーからのワンクリックインポート

![チャット：API キーから設定をワンクリックでインポートする画面](/assets/guide/feature-guide/chat-api-key-one-click-configuration-import.png)

**操作手順：**
1. 左サイドバーの「API キー」をクリックします。
2. 使用する API キーの行を探します。
3. その行の ⋯ →「チャット」→ 対象のチャットアプリの順にクリックします。
4. ブラウザーが新しいウィンドウでインストール済みの外部アプリを起動しようとしたら、「開く」をクリックします。
5. 対象のアプリに切り替わり、指定したキーで設定がワンクリックでインポートされます。

<Callout type="info" title="ヒント">
  - インポートに使用されるのは、⋯ をクリックした行のキーです。行頭のチェックボックスにチェックを入れる必要はありません（スクリーンショットのチェックは説明用です）。インポート時にはキーの状態は確認されません。無効なキー、有効期限切れのキー、クォータを使い切ったキーもインポートできますが、そのキーでの API 呼び出しは失敗します。
  - Web アプリは新しいタブで開きます。ブラウザー拡張機能（「FluentRead」など）は API アドレスとキーを直接受け取ります。あらかじめ拡張機能をインストールして有効にしてください。
</Callout>

### チャットアプリを手動で設定する

ワンクリックインポートに対応していないアプリは、手動で設定できます。

- New API から次の設定情報を取得します。<br/>

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| 設定項目 | 説明 | 取得場所 |
| --- | --- | --- |
| API Base URL | API のベース URL | 「API キー」ページ右上の「API アドレス」に表示されるアドレスに `/v1` を追加します（例：`https://api.example.com/v1`）。正確な形式はアプリの説明に従ってください。 |
| API Key | API キー | 「API キー」ページ |
| 利用可能なモデル | 対応モデルの一覧 | モデル広場でキーが属するグループを指定して絞り込み、利用可能なモデルを確認します。 |
</div>

**操作手順：**
1. 対象のアプリで「設定」または「構成」を開きます。
2. 「カスタム API」または「OpenAI 互換 API」の設定欄を探します。
3. API Base URL と API Key を入力します。
4. 設定を保存すると利用できます。

<Callout type="info" title="ヒント">
  1. OpenAI 互換 API に対応するほとんどのアプリは、カスタム API アドレスを指定することで New API に接続できます。
  2. 完全なエンドポイント URL が必要な場合は、`https://api.example.com/v1/chat/completions` を使用します。追加するパスは、アプリの設定手順に従ってください。
  3. **動作確認済みの AI アプリの一覧と設定ガイドについては、<a href="/ja/docs/apps" target="_blank" rel="noopener noreferrer">AI アプリ</a>のページを参照してください。**
</Callout>

## よくある質問

<Accordions type="multiple" className="[&_h3]:font-semibold [&_h3[data-state=open]]:bg-fd-muted [&_[role=region]>div]:border-t [&_[role=region]>div]:pt-3 [&_[role=region]>div]:pb-3 [&_[role=region]>div]:ps-9 [&_[role=region]>div]:text-sm [&_[role=region]>div]:leading-6 [&_[role=region]>div]:text-fd-muted-foreground [&_[role=region]_strong]:text-fd-foreground [&_[role=region]_p]:my-2 [&_[role=region]_ol]:my-1 [&_[role=region]_ul]:my-1 [&_[role=region]_li]:my-0.5 [&_[role=region]_table]:table-fixed [&_[role=region]_th:nth-child(1)]:w-[40%] [&_[role=region]_th:nth-child(2)]:w-[30%]">

<Accordion title="サイドバーにチャットプリセットが表示されない">
**補足**：「API キー」ページの ⋯ メニューにある「チャット」も、サイトにチャットプリセットが設定されている場合にのみ表示されます（デフォルトでプリセットが用意されています）。

**考えられる原因**：
- 「プロフィール」ページの「左サイドバーの個人設定」で、「チャットエリア」または「チャット」が有効になっていません。
- 管理者が「チャット」を無効にしたか、すべてのチャットプリセットを削除しました。
- 管理者がチャットプリセットを変更した後、ページがまだ再読み込みされていません。

**対処方法**：
1. 「プロフィール」ページの「左サイドバーの個人設定」で「チャットエリア」と「チャット」の両方を有効にし、保存します。
2. ブラウザーでページを再読み込みします。
3. それでも表示されない場合は、管理者にチャットプリセットの設定を確認してください。
</Accordion>

<Accordion title="チャットを開くと「No enabled API keys found」と表示される">
**メッセージ原文**：No enabled API keys found. Create or enable one first.（英語のみ）。Web アプリでは、ページ内に「チャットを開けません」と同じ英文が表示されます。

**考えられる原因**：サイドバーの「チャット」では有効なキーのみが使用されますが、アカウントに「有効」なキーがありません。

**対処方法**：
1. 「API キー」ページで API キーを作成するか、無効になっているキーを有効にします。
2. 「有効期限切れ」または「クォータを使い切った」状態のキーは、先に有効期限またはクォータを変更してから「有効化」を実行します。
</Accordion>

<Accordion title="デスクトップアプリが起動しない">
**考えられる原因**：
- 対象のアプリがインストールされていないか、対応するカスタムプロトコルが OS に登録されていません。
- ブラウザーが外部アプリを開く許可を待っています。

**対処方法**：
1. 対象のアプリをインストールし、対応するカスタムプロトコルが OS に登録されていることを確認します。
2. ブラウザーに外部アプリを開くかどうかを確認するメッセージが表示されたら、許可します。
</Accordion>

<Accordion title="Web アプリのプリセットを開くと画面が空白になる、または読み込みが拒否される">
**考えられる原因**：サイドバーの Web アプリは、このサイトのページ内に表示されます。対象サイトが CSP または `X-Frame-Options` で他のページへの埋め込みを禁止している可能性があります。

**対処方法**：
1. 「API キー」ページで、使用するキーの ⋯ →「チャット」からアプリを新しいタブで開きます。
2. または、アプリを手動で設定します。[チャットアプリを手動で設定する](#チャットアプリを手動で設定する)を参照してください。
</Accordion>

<Accordion title="FluentRead への接続後にキーが無効になる">
**補足**：「FluentRead」は、「API キー」ページの ⋯ →「チャット」にのみ表示されます。表示されたメッセージに応じて原因を確認してください。

| メッセージ原文 | 考えられる原因 | 対処方法 |
| --- | --- | --- |
| 「未检测到 FluentRead 扩展。请确保已安装并激活。」（FluentRead 拡張機能が検出されません。インストールされ、有効になっていることを確認してください。） | FluentRead 拡張機能がインストールされていないか、無効になっています。 | 拡張機能をインストールして有効にしてから、もう一度試してください。 |
| 「API 密钥已发送至 FluentRead。」（API キーを FluentRead に送信しました。）と表示されても、呼び出しに失敗する | 拡張機能に保存された API アドレスまたはキーが正しくありません。 | 拡張機能に API アドレスと API キー全体（先頭の `sk-` は 1 つだけ）を手動で入力するか、別のプリセットを使用してください。 |
</Accordion>

<Accordion title="リクエストに対して認証エラーまたはアクセス拒否が返される">
**考えられる原因**：認証ヘッダーの形式、モデル名、キーの状態、グループの権限、または IP 制限が要件を満たしていません。Claude や Gemini へのリクエストでは、それぞれに対応するパスやリクエストヘッダーが使われていない可能性もあります。

**対処方法**：
1. 認証ヘッダーの形式とモデル名を確認します。
2. 「API キー」ページで、キーの状態、グループ、IP 制限を確認します。
3. Claude や Gemini へのリクエストでは、それぞれに対応するパスとリクエストヘッダーを使用していることも確認します。
</Accordion>

<Accordion title="「CC Switch」プリセットをクリックすると、このサイトのページが開く">
**考えられる原因**：「チャット」内の「CC Switch」プリセットからは設定をインポートできません。クリックすると、新しいタブでこのサイトのページが開きます。

**対処方法**：
1. 「API キー」ページの ⋯ メニュー直下にある「CC Switch」を使用します。詳しくは<a href="/ja/docs/guide/feature-guide/user/token#导入到-cc-switch-或聊天应用" target="_blank" rel="noopener noreferrer">API キー</a>を参照してください。
</Accordion>

<Accordion title="インポート後、アプリの API アドレスが正しくない">
**考えられる原因**：ワンクリックインポートでは、管理者が設定したサーバーアドレスが使用されます。未設定の場合は `http://localhost:3000` になります。

**対処方法**：
1. アプリ側のアドレスを、「API キー」ページの「API アドレス」に表示されているアドレスに変更します。
2. そこにも `http://localhost:3000` が表示されている場合は、管理者にサーバーアドレスの設定を依頼してください。
</Accordion>

</Accordions>
