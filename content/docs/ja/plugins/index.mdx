## タスクプラグインとは

タスクプラグインは、New APIゲートウェイ内で動作する単一ファイルのJavaScriptモジュールで、上流のタスク提出、結果解析、ポーリング、成果物ダウンロードとの連携に使用されます。管理者はプラグインを通じて画像、動画、音楽などの生成能力を拡張でき、各上流のためにゲートウェイを再コンパイルする必要はありません。

プラグインはリクエストとレスポンスを統一されたデータ構造に変換する役割を担います。New APIホストは認証、チャネル選択、HTTPリクエスト、タスクの永続化、再試行、ポーリング、課金決済を担当します。プラグインは使用量の実績のみを報告し、ユーザーが支払うべき価格を独自に決定することはありません。

<Callout title="バージョンステータス">
  現在のプラグインリポジトリでは、Task Plugin API v1はまだ正式リリースされていない契約としてマークされています。本ドキュメントは、現在のプラグインリポジトリとNew APIの実装に基づいて記述されています。インストールする前に、お使いのゲートウェイのバージョンがプラグインが宣言するフィールドと機能をサポートしていることを確認してください。`apiVersion: 1` だけで互換性を判断することはできません。
</Callout>

## 組み込みプラグインとカスタムバージョン

| タイプ                 | ソース                    | 管理方法                                             |
| -------------------- | ----------------------- | ---------------------------------------------------- |
| 組み込みプラグイン（Factory）  | New APIプログラムに付属     | 個別に削除または無効化できません。同じキーのカスタムバージョンで上書き可能です。      |
| 上書きバージョン（Override） | インストールまたはアップロードされた同じキーのプラグイン | 有効化すると組み込みバージョンを上書きします。上書きバージョンを無効化または削除すると、組み込みプラグインが復元されます。 |
| サードパーティプラグイン           | インストールまたはアップロードされた新しいキーのプラグイン | 無効化または削除すると、対応するプラグイン機能は利用できなくなります。                     |

タスクプラグインのマスターON/OFFスイッチは、組み込みプラグインを含むプラグインシステム全体を制御します。これをオフにすると、プラグインサービスは直ちに停止します。進行中のタスクは、その後タイムアウトクリーンアップによって処理されます。アップグレード、無効化、削除を行う前に、関連するチャネルと未完了のタスクを確認する必要があります。

## 誰が使用できるか

- **Root（スーパー管理者）**：インストール、アップロード、アップグレード、有効/無効化、削除、マーケットソースの設定、実行デバッグ。
- **プラグインバインド権限を持つ管理者**：チャネル管理で利用可能なプラグインを選択し、チャネルをバインドします。これはプラグイン管理権限とは異なります。
- **APIユーザー**：自身のインスタンスのAPIキーを使用して、公開されているモデルとインターフェースを呼び出します。プラグイン管理権限は必要ありません。

タスクプラグインはゲートウェイ自体を拡張します。AIコーディングアシスタント用の拡張機能については、[Skills](/ja/docs/skills)を参照してください。

## 推奨設定順序

1. [プラグインマーケット](/ja/plugins)でプラグインのモデル、インターフェース、最新バージョン、移行手順を確認します。
2. [プラグインをインストール](/ja/docs/plugins/installation)し、その後[チャネルをバインド](/ja/docs/plugins/configuration)します。
3. プラグインが報告するフィールドに従って、[使用量と課金を設定](/ja/docs/plugins/billing)します。
4. [呼び出しガイド](/ja/docs/plugins/usage)に従ってタスクを提出し、ステータスと成果物を確認します。
