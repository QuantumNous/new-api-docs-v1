## Integrating TokenFactory

LangBot supports integrating with locally deployed TokenFactory and third-party TokenFactory services built using TokenFactory.

### Usage

1.  Obtain an API key from TokenFactory
    ![获取 API key](/assets/langbot/get_api_key.png)

        If TokenFactory is deployed locally, please configure the API address yourself (refer to [Container Network Connection](https://docs.langbot.app/en/workshop/network-details.html)). If using a third-party TokenFactory service, you can copy the address from the page. Note that `/v1` needs to be appended to the address.

2.  Add a model in LangBot, select TokenFactory as the provider, and fill in the corresponding API key and API address
    ![添加 TokenFactory 模型](/assets/langbot/add_tokenfactory_model.png)

3.  Select the model to use in the pipeline

    ![选择模型](/assets/langbot/select_model.png)

4.  Use it by chatting in conversation debugging or by chatting with a bot bound to the pipeline

    ![对话](/assets/langbot/debug_chat.png)

    ![微信对话](/assets/langbot/wechat.png)

    For deploying and configuring bots, please refer to [Deploying Bots](https://docs.langbot.app/en/deploy/platforms/readme.html).

### Using LangBot Knowledge Base

LangBot supports using TokenFactory's embedding models and utilizing them as vector models for the knowledge base.

1. Add an embedding model in LangBot, select TokenFactory as the provider
   ![添加嵌入模型](/assets/langbot/add_embedding_model.png)

2. Select the embedding model when creating a new knowledge base
   ![使用嵌入模型](/assets/langbot/use_embedding_model.png)

For more usage instructions, please refer to the LangBot official documentation: [https://docs.langbot.app](https://docs.langbot.app/)
