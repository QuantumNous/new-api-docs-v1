- View account information, configure notification methods and preferences, set the interface language, choose which pages appear in the left sidebar, and check in daily to earn quota.
- Manage your password, account linking, two-step verification, Passkeys, login sessions, and access tokens on the <a href="/en/docs/guide/feature-guide/user/security" target="_blank" rel="noopener noreferrer">Security & Access</a> page.

<Callout type="info" title="Tip">

- Your account display name appears in large text at the top of the page. If you haven’t set a display name, your username appears instead.
- The site determines the quota unit.
- “Daily Check-in” appears only when an administrator enables the check-in feature.
- If “Personal Profile” is missing from the left sidebar, click your avatar in the upper-right corner and select “Personal Profile.”<br/>In “Left Sidebar Personal Settings,” turn on “Personal Center Section” and “Personal Settings,” then save. If these two toggles aren’t available, an administrator has hidden the page. Contact your administrator.
</Callout>

The top of the page shows account information and usage. Below it are the “Settings,” “Language Preferences,” “Daily Check-in,” and “Left Sidebar Personal Settings” sections, where you can do the following.

- [Set the interface language](#set-the-interface-language)
- [Check in daily to earn quota](#check-in-daily-to-earn-quota)
- [Choose which pages appear in the left sidebar](#choose-which-pages-appear-in-the-left-sidebar)

If you aren’t receiving notifications, can’t see Daily Check-in, or are missing a page from the sidebar, see the [FAQ](#faq).

## Configure Notification and Behavior Preferences

- Personal Profile – Notification Method

![Personal Profile notification method page](/assets/guide/feature-guide/personal-profile-settings-notification-method.png)

**Steps**

1. Under “Notification Method” in the “Settings” section, select “Email,” “Webhook,” “Bark,” or “Gotify.”
2. Fill in the fields displayed below the selected method.
3. Under “Which Notifications to Receive,” turn “Low Balance Alert” on or off and enter a “Reminder Threshold (…)” as needed.
4. Under “Preferences,” turn “Accept Unpriced Models” on or off as needed.
5. Click “Save Settings.”

<Callout type="info" title="Tip">

- “Notification Method,” “Which Notifications to Receive,” and “Preferences” share the “Save Settings” button at the bottom. If a required field for the selected method is empty or invalid, the entire save fails, including any changes to other toggles.
- Only the fields for the selected notification method are saved. If you switch methods and save, any values entered for other methods are cleared.
- If an administrator disables low balance alerts for the site, regular users only see “No notifications are available to you right now” and “Preferences” in the “Settings” section.
- The site server must be able to reach the notification address. The site’s security policy may block addresses pointing to a private network or localhost. The page does not show an error if delivery fails. If the same type of notification is triggered several times in a short period, some notifications may be skipped.
</Callout>

<Callout type="warn" title="Caution">
Turning on “Accept Unpriced Models” lets you call models that an administrator hasn’t priced yet, which may result in unexpectedly high charges. This setting is off by default. We recommend leaving it off.
</Callout>

**Notification methods**

The screenshots show the fields for “Email,” “Bark,” “Gotify,” and “Webhook,” in that order from top left to top right, then bottom left to bottom right.

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| Notification method | Fields | Requirements and limitations |
| --- | --- | --- |
| Email | Notification Email | Optional. The placeholder reads “Leave blank to use your account email.” If left blank, notifications go to the email address linked to the account. If no address is linked, no notifications are sent. An incorrectly formatted address triggers “Invalid email address.” |
| Webhook | Webhook URL, Webhook Secret | “Webhook URL” is required and must be a valid URL such as `https://example.com/webhook`. An empty field triggers “Webhook URL cannot be empty.” An incorrectly formatted URL triggers “Invalid Webhook URL.” “Webhook Secret” is optional. If set, each notification includes a signature that the recipient can use to verify its origin. Notifications use JSON format. |
| Bark | Bark Push URL | Required. The URL must start with http:// or https://. You can use the template variables `{{title}}` and `{{content}}`, which are replaced with the notification title and body when the notification is sent. An empty field triggers “Bark push URL cannot be empty.” An incorrectly formatted URL triggers “Invalid Bark push URL.” |
| Gotify | Gotify Server URL, Gotify App Token, Message Priority | “Gotify Server URL” is required and must start with http:// or https://. An empty field triggers “Gotify server URL cannot be empty.” “Gotify App Token” is required. Create an app on the Gotify server and copy its token. An empty field triggers “Gotify token cannot be empty.” “Message Priority” ranges from 0 (lowest) to 10 (highest). Out-of-range values are saved as 5. Enter the priority you want notifications to use. The “Setup Instructions” below list three steps and link to the “Gotify Documentation.” |
</div>

The “Settings” section has three parts, “Notification Method,” “Which Notifications to Receive,” and “Preferences.” The fields for each notification method are listed above. The following table lists the options in the order they appear on the page.

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">

This option is hidden if an administrator disables low balance alerts for the site. | On |

</div>

## Set the Interface Language

**Steps**

1. Open the “Interface Language” dropdown in the “Language Preferences” section.
2. Select the language you want to use.

<Callout type="info" title="Tip">

- Your selection is saved immediately, the interface switches languages, and “Language preference saved” appears. The setting syncs across all devices signed in to the account.
- Available languages are 简体中文, English, Français, Русский, 日本語, Tiếng Việt, and 繁體中文.
- API error messages are available only in Simplified Chinese, Traditional Chinese, and English. If you choose another interface language, API error messages appear in English.
</Callout>

## Check In Daily to Earn Quota

**Steps**

1. In the “Daily Check-in” section, click “Check In Now.”
2. If the site has human verification enabled, complete it in the “Security Verification” dialog.
3. Use the calendar to see the dates you checked in and the quota you earned.

<Callout type="info" title="Tip">

- This section appears only when an administrator enables check-in. See <a href="/en/docs/guide/feature-guide/system-settings/settings-billing#check-in-rewards" target="_blank" rel="noopener noreferrer">Billing and Payment Configuration</a>.
- You can check in once per day, based on the server’s date. The reward is chosen at random within the range set by the administrator, added directly to “Current Balance,” and recorded as a “System” entry in the usage log.
- If you’ve already checked in today, the button is disabled and reads “Checked In.” “Checked In” and “Today +…” appear next to the heading. The section is collapsed by default. Click the heading to expand it.
</Callout>

**Field descriptions**

<div className="[&_table]:min-w-[36rem] [&_td:first-child]:whitespace-nowrap [&_th]:whitespace-nowrap">
| Field | Definition | Requirements and limitations | Notes |
| --- | --- | --- | --- |
| Total Check-ins | The total number of check-ins to date. | Tracked automatically. | — |
| Earned This Month | The total rewards earned in the month currently displayed in the calendar. | Tracked automatically. | Updates when you switch months. |
| Total Earned | The total rewards earned to date. | Tracked automatically. | — |
| Calendar | Check-in status for each day. | Click the left and right arrows to switch months. | Today is highlighted. A green dot appears below each date you checked in. Hover over the date to see “Checked In” and the quota earned. |
</div>

## Choose Which Pages Appear in the Left Sidebar

**Steps**

1. In “Left Sidebar Personal Settings,” turn section and module toggles on or off.
2. Click “Save Changes.”

<Callout type="info" title="Tip">

- Two levels of settings determine what appears in the sidebar. This section lists only the sections and pages that the administrator has enabled. You can hide any of the listed items. See <a href="/en/docs/guide/feature-guide/system-settings/settings-site#sidebar-modules" target="_blank" rel="noopener noreferrer">Site and Branding Configuration</a>.
- Turning off a section toggle disables its module toggles. Once you save, all pages in that section are hidden.
- “Reset to Default” turns all toggles back on. Click “Save Changes” to apply the reset.
- These settings only hide sidebar entries. Access permissions stay the same. “Personal Profile” always appears in the avatar menu in the upper-right corner.
- This section is hidden for the Root account. System settings determine the Root account’s sidebar.
</Callout>

<Accordion title="I’m not receiving low balance alerts">
**Possible causes**

- An administrator disabled low balance alerts for the site, or “Low Balance Alert” is off for the account.
- The balance was already below the threshold. Each drop below the threshold triggers only one alert. The balance must be topped up above the threshold before another alert can be sent.
- “Email” is selected, “Notification Email” is blank, and the account has no linked email address.
- The notification address is unreachable from the site server or is blocked by the site’s security policy.
- The same type of notification was triggered several times in a short period, so some notifications were skipped, or the email went to spam.

**Steps to resolve**

1. Confirm that “Low Balance Alert” is on and check the “Reminder Threshold (…).”
2. If “Email” is selected, fill in “Notification Email” or link an email address on the <a href="/en/docs/guide/feature-guide/user/security" target="_blank" rel="noopener noreferrer">Security & Access</a> page.
3. Confirm that the Webhook, Bark, or Gotify address is reachable from the public internet, or switch to another notification method and save.
4. If you still aren’t receiving alerts, ask your administrator to check the site’s notification settings.
</Accordion>

<Accordion title="The Settings section only shows “No notifications are available to you right now”">
**Message** “No notifications are available to you right now”

**Possible cause** An administrator disabled low balance alerts for the site.

**Steps to resolve**

1. If you need low balance alerts, contact your administrator.
</Accordion>

<Accordion title="Saving settings returns “Webhook URL cannot be empty” or another error">
Use the exact message to identify the cause.

| Message | Possible cause | Steps to resolve |
| --- | --- | --- |
| “Webhook URL cannot be empty”<br/>“Invalid Webhook URL” | Webhook is selected and the URL is missing or incorrectly formatted. | Enter the full URL. |
| “Bark push URL cannot be empty”<br/>“Invalid Bark push URL” | The Bark push URL is missing or incorrectly formatted. | Enter the full URL starting with http:// or https://. |
| “Gotify server URL cannot be empty”<br/>“Invalid Gotify server URL”<br/>“Gotify token cannot be empty” | The Gotify server URL or app token is missing or incorrectly formatted. | Enter the complete server URL and app token. |
| “URL must start with http:// or https://” | The URL is missing http:// or https://. | Add https:// to the beginning of the URL. |
| “Invalid email address” | The “Notification Email” format is invalid. | Correct the email address or leave it blank to use the account email. |
| “Reminder threshold cannot be negative” | The threshold is negative. | Enter 0 or a positive number, or leave it blank. |
| “Failed to update settings” | The network connection was interrupted or the login session expired. | Refresh the page and try again. |
</Accordion>

<Accordion title="I can’t see Daily Check-in">
**Possible cause** An administrator hasn’t enabled the check-in feature, which is off by default.

**Steps to resolve**

1. If you need to check in, contact your administrator.
</Accordion>

<Accordion title="Checking in returns “Already checked in today” or another error">
Use the exact message to identify the cause.

| Message | Possible cause | Steps to resolve |
| --- | --- | --- |
| “Already checked in today” | You already checked in today, based on the server’s date. | Check in again the following day. |
| “Check-in feature is not enabled” | An administrator disabled check-in. | Refresh the page. If you need to check in, contact your administrator. |
| “Turnstile token is empty” | The site’s human verification is configured incorrectly. | Contact your administrator. |
| “Turnstile verification failed, please refresh and try again!” | Human verification failed. | Refresh the page and try checking in again. |
| “Check-in failed, please try again later”<br/>“Check-in failed” | The network connection was interrupted or a server error occurred. | Try again later. |
</Accordion>

<Accordion title="My balance didn’t update immediately after a successful check-in">
The reward has been added to your balance. The displayed balance may take a moment to update.

**Steps to resolve**

1. Refresh the page and check “Current Balance.”
2. In <a href="/en/docs/guide/feature-guide/user/log" target="_blank" rel="noopener noreferrer">Usage Logs</a>, select “System” as the log type to see the check-in entry.
</Accordion>

<Accordion title="A page is missing from the sidebar">
**Possible causes**

- The corresponding module or section was turned off in “Left Sidebar Personal Settings,” and the change was saved.
- An administrator hid the page in system settings.
- Turning off both “Drawing Logs” and “Task Logs” hides “Task Logs” from the sidebar. Turning off just one hides only its tab on the page.

**Steps to resolve**

1. In “Left Sidebar Personal Settings,” turn on the corresponding section and module, then click “Save Changes.” You can also click “Reset to Default” and then “Save Changes.”
2. If “Personal Profile” is missing from the sidebar, click your avatar in the upper-right corner and select “Personal Profile.”
3. If the corresponding toggle is missing or the page is still hidden after you turn the toggle on, an administrator has hidden the page. Contact your administrator.
</Accordion>

<Accordion title="API error messages are still in English after I change the interface language">
API error messages are available only in Simplified Chinese, Traditional Chinese, and English. If you choose another interface language, API error messages appear in English.

**Steps to resolve**

1. To receive API error messages in Chinese, select “简体中文” or “繁體中文” under “Interface Language.”
</Accordion>

<Accordion title="Calling a model returns “Model … has not been priced by the administrator yet…”">
**Message** “Model … has not been priced by the administrator yet. Please contact the site administrator to enable this model.”

**Possible cause** An administrator hasn’t configured a price for the model, and “Accept Unpriced Models” is off for the account.

**Steps to resolve**

1. Ask your administrator to configure a price for the model.
2. If you need to use the model immediately, turn on “Accept Unpriced Models” under “Preferences” and click “Save Settings.” This may result in unexpectedly high charges.
</Accordion>

<Accordion title="How do I change my display name, username, email address, or group?">
The display name, username, and group are read-only on this page. You can link or change your email address on the “Security & Access” page.

**Steps to resolve**

1. To link or change your email address, open <a href="/en/docs/guide/feature-guide/user/security" target="_blank" rel="noopener noreferrer">Security & Access</a> and go to “Account Linking.”
2. To change your display name, username, or group, contact your administrator.
</Accordion>

<Accordion title="Left Sidebar Personal Settings is missing from the page">
This section is hidden for the Root account, whose sidebar is determined by system settings. The section appears for all other accounts.
</Accordion>
