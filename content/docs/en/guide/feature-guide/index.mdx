New API is a unified AI model interface management and distribution system. It supports converting various large models into a unified calling format, compatible with formats like OpenAI and Claude. It can be used by individuals or enterprises for internal management and channel distribution, offering capabilities such as a playground, OpenAI-compatible interfaces, model and channel routing, usage logs, billing, subscriptions, and system operations.

- This guide is divided into two parts based on roles: User Guide and Admin Guide.

### Role Description

The platform controls menu access and operation permissions based on account roles, which are divided into three types:

- **Regular User** <br/>The default role after registration, with access to personal features open on the platform, such as Playground, Chat Presets, Overview, Data Dashboard, API Keys, Logs, Wallet, and Profile. <br/>Entries like top navigation, sidebar modules, and check-in are controlled by the Super Administrator (Root) configuration. [“Site & Branding Settings” →](/en/docs/guide/feature-guide/system-settings/settings-site)

- **Administrator (Admin)** <br/>Building upon regular user permissions, Admin can by default access management resources such as Channels, Models, Users, Redemption Codes, and Subscriptions. <br/>Resources like Channels also distinguish actions such as read, operate, normal write, sensitive write, and view key. The Super Administrator (Root) can set permission overrides for Admin accounts to manage available permissions. [“Site & Branding Settings” →](/en/docs/guide/feature-guide/system-settings/settings-site)

- **Super Administrator (Root)** <br/>Root has all permissions, with additional access to **System Info** `/system-info` and **System Settings** `/system-settings/site`. <br/>System settings are divided into seven configuration domains: Site & Branding, Authentication, Billing & Payments, Models & Routing, Security & Restrictions, Console Content, and Operations.
