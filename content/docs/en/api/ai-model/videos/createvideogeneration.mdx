Submit a video generation task for **video series models**.

**Endpoint**: `POST /v1/video/generations`

## Generation Modes

| Mode | Required Parameters | Description |
| --- | --- | --- |
| Text-to-video | `model` + `prompt` | Do not pass `images` or `metadata.video_urls` |
| Image-to-video | `model` + `prompt` + `images` | `images` contains 1 image |
| Video-to-video | `model` + `prompt` + `metadata.video_urls` | Contains 1 video |
| Multi-reference images | Multiple items in `images` | Each image serves as reference material |
| Multi-reference videos | Multiple items in `metadata.video_urls` | Each video serves as reference material |

## Rules for `images` and `metadata.video_urls`

- **Single image / single video**: Pass only 1 URL in the array
- **Multiple references**: Pass multiple URLs in order; describe each asset's purpose in `prompt`
- **Text-to-video**: Do not pass `images` or `metadata.video_urls`
- URLs must be publicly accessible (HTTP/HTTPS)
- Image formats: `.png`, `.jpg`, `.jpeg`, `.webp`
- Video formats: `.mp4`, `.mov`, `.webm`

## Text-to-Video Example

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "Sunset coastline, cinematic lighting, slow push-in shot, waves crashing on rocks",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

## Image-to-Video Example

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "Character slowly turns head, leaves swaying in the background",
    "images": [
      "https://cdn.example.com/character-front.png"
    ],
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

## Video-to-Video Example

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "Transform into cyberpunk night scene, preserve original motion trajectory",
    "duration": 8,
    "metadata": {
      "video_urls": [
        "https://cdn.example.com/source.mp4"
      ],
      "resolution": "1080p",
      "ratio": "16:9"
    }
  }'
```
