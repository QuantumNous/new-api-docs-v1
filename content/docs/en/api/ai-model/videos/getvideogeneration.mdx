Query the status and results of a video generation task. When completed, retrieve the generated video URL from `output.video_url`.

**Endpoint**: `GET /v1/video/generations/{task_id}`

`{task_id}` is the `id` field returned when creating the task.

## Task Status

| status | Meaning |
| --- | --- |
| `queued` | Queued |
| `in_progress` | Generating |
| `completed` | Success |
| `failed` | Failed |

## Request Example

```bash
curl -X GET "__apiBaseUrl__/v1/video/generations/task_abc123" \
  -H "Authorization: Bearer <YOUR_API_KEY>"
```

## Success Response Example

```json
{
  "id": "task_abc123",
  "object": "video.generation",
  "model": "Seedance 2.0/uP",
  "status": "completed",
  "progress": 100,
  "created_at": "2026-06-17T08:00:00Z",
  "completed_at": "2026-06-17T08:01:30Z",
  "output": {
    "video_url": "https://cdn.example.com/output/task_abc123.mp4"
  },
  "error": null
}
```

## Error Handling

| Scenario | Suggestion |
| --- | --- |
| Image-to-video without `images` | Add at least 1 image URL in `images` |
| Video-to-video without `metadata.video_urls` | Add at least 1 video URL in `metadata.video_urls` |
| Resource URL inaccessible | Verify public accessibility and correct format |
| Authentication failure | Check API Key |
| Generation failed | Simplify `prompt` or reduce reference assets |
